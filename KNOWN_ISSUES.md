# Известные ограничения

- Пользователь подтвердил среду 0A и первое окно 0B на Windows. Новые d20 и
  три ячейки также приняты пользователем. Профиль и проверки характеристик 1B
  проверены в облаке; их ручная приёмка на Windows ожидается.
- Рассказчик понимает только явно перечисленные команды. Это шаблоны, не нейросеть.
- Автосохранения нет. Сохраняются отправленные действия и броски, не черновик ввода.
  Сессия ограничена 2000 действиями, размер файла — 4 МБ. Для продолжения новой
  сессии сохраните текущую и перезапустите окно.
- Повествовательный эпизод пока не ведёт состояние событий и ресурсов; профиль персонажа сохраняется отдельно.
- Формат JSON v2 (с чтением v1) рассчитан на Python 3.12 и текущую схему; будущие изменения требуют
  явной миграции. Одновременная запись из нескольких окон не координируется.
- Атомарная замена защищает предыдущий файл при проверенном отказе записи;
  это не заменяет резервную копию и не является гарантией при потере питания.
- Реализовано только подмножество SRD для модификаторов и базовых проверок.
  Бои, классы, HP, владения, преимущество/помеха и ConflictSolver не реализованы.
- Учебный профиль пока не редактируется; проверка не изменяет игровую сцену.
- Научные ссылки исходных документов пока не проверены по полным текстам.
- Не создан Windows wheelhouse или portable-релиз. Перед распространением Qt-бинарников
  требуется полный комплект лицензий, уведомлений и выполнение условий LGPL.
- Сетевая политика облака блокирует doc.qt.io (403); лицензии PySide6/shiboken6
  сверены по метаданным конкретных пакетов PyPI. Сверка документации Qt для релиза впереди.
- Публикация облачного снимка и его восстановление в новой задаче не проверены.
