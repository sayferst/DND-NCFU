# Оригинальная иллюстрация меню

kingdom.png создана 2026-10-20 инструментом генерации изображений OpenAI по
заданию владельца DND-NCFU специально для проекта. Чужие иллюстрации и игровые
ассеты не использованы как исходник. Изображение не является материалом SRD.
Шрифты не поставляются: используются установленные в ОС Segoe UI/Georgia и
доступные Qt замены. Фон загружается только с диска.

SHA-256: b1c7a6d583c571b7e1476bef4d2a3692e017c31b577d080b0bba958795f13275

DND-NCFU.png и DND-NCFU.ico — оригинальная эмблема (щит, меч, кристаллы),
построенная scripts/create_app_icon.py средствами QPainter. Сторонние товарные
знаки, изображения и шрифтовые файлы не использованы. Иконка содержит размеры
16, 32, 48, 64, 128 и 256 пикселей. Заставка использует прежний kingdom.png:
параллакс и частицы рисует Qt; видеокодеки и загрузка изображений из сети не нужны.
