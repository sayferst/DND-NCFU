DND-NCFU — запуск хоста и команды владельца

НОВЫЕ BAT-ФАЙЛЫ

ОСНОВНЫЕ ТРИ КНОПКИ (обновлено 25.10.2026)

BUILD_EXE.bat — собирает личный EXE для проверки, без Inno/установщика.
Откроет dist\Personal-ДАТА-ВРЕМЯ; запускайте DND-NCFU\DND-NCFU.exe внутри.
BUILD_SETUP.bat — пересобирает Setup tester1 для тестировщика через хост.
Сначала START_HOST.bat и дождаться готовности. Результат: dist\Tester-tester1.
START_HOST.bat — запускает уже настроенный сервер; сборкой игры не занимается.

Перед сборкой закройте игру. Если Git чист и хост остановлен, новые сборщики
сначала делают git pull --ff-only. При своих правках или работающем хосте
собирают текущие локальные файлы без git pull, сообщая об этом в консоли.
Тесты и проверки EXE выполняются при каждой сборке; ошибка останавливает её.
Изменения исходников сами по себе не изменяют ранее собранные EXE/Setup,
и установленная игра тестировщика не обновляется автоматически: передайте
новый Setup, который он должен установить.

ЗАЧЕМ ХОСТ

Клиент tester1 отправляет запросы вашему шлюзу, тот проверяет допуск/бюджет,
обращается к RouterAI с вашим сохранённым ключом и возвращает текст/картинку.
Ngrok предоставляет публичный HTTPS-адрес; GitHub хранит подписанный адрес,
но сам игровой сервер на GitHub не работает. Ключ API остаётся на ПК владельца.
Без хоста игра установится и откроется; новые ответы Мастера, создание мира
и генерация картинок через общий доступ недоступны. Смена ключа хоста требует
его перезапуска, но не пересборки клиента. EXE/Setup не содержат ваш API-ключ.
Личный Setup от UPDATE_AND_BUILD_SETUP.bat работает без вашего хоста: получатель
вводит свои API-ключи. Ему всё равно нужен интернет и доступ к провайдеру.
Владельческий сервер не является частью клиентского установщика.

ПРЕЖНИЕ КОМАНДЫ (сохранены для совместимости)

CHANGE_HOST_KEY.bat — после остановки старого хоста спрашивает новый API-ключ,
сохраняет его для Мастера и Художника шлюза и запускает хост.
START_HOST.bat — обычный запуск с уже сохранённым ключом, без пересборки Setup.
UPDATE_AND_BUILD_SETUP.bat — собирает личный Setup и portable EXE с вводом
собственных ключей; правила обновления описаны выше.
Результат: dist\Personal-ДАТА-ВРЕМЯ\DND-NCFU-Setup.exe и папка DND-NCFU.
Portable EXE переносить вместе со всей папкой DND-NCFU.
Затем START_HOST.bat, дождаться готовности, и BUILD_TESTER_SETUP.bat — новый
персональный Setup для tester1. Результат: dist\Tester-tester1\DND-NCFU-Setup.exe.
Сборка запускает все обязательные проверки и может занять несколько минут.
Требуются Git, Python 3.12 x64 и Inno Setup 6. Ошибки не пропускаются.
API-ключ в EXE/Setup не записывается: клиент тестировщика обращается к хосту.
При смене ключа хоста существующий Setup продолжает работать после его перезапуска.
Установленная клиентская игра не содержит сервер и сама хост не запускает;
BAT владельца запускает сервер из папки проекта, клиенту сервер не требуется.

ОБЫЧНЫЙ ЗАПУСК

Откройте START_HOST.bat двойным щелчком в папке проекта.
Права администратора не нужны. Ключи и домен уже сохранены на вашем ПК.
Дождитесь: «Устойчивость подтверждена тремя HTTPS-проверками».
Пока тестировщик играет, оставляйте окно и компьютер включёнными.
Для остановки нажмите Ctrl+C. Если Windows спросит завершить пакетный файл,
нажмите Y и Enter. Повторный запуск — снова двойной щелчок START_HOST.bat.
Не запускайте одновременно два хоста.

ЗАПУСК ИЗ POWERSHELL — АЛЬТЕРНАТИВА ДВОЙНОМУ ЩЕЛЧКУ

Set-Location D:\Projects\DND-NCFU
.\START_HOST.bat

СОБРАТЬ SETUP ТЕСТИРОВЩИКУ

Хост оставьте открытым. Во втором окне PowerShell:

Set-Location D:\Projects\DND-NCFU
.\scripts\tester_host.cmd build tester1

После успешной сборки передайте:
D:\Projects\DND-NCFU\dist\Tester-tester1\DND-NCFU-Setup.exe
На своём ПК этот персональный Setup запускать не нужно.
Повторная сборка не сбрасывает расходы или срок существующего допуска.

ОБНОВИТЬ ПРОЕКТ — ТОЛЬКО КОГДА ЭТО НУЖНО

Остановите хост, затем в PowerShell:

Set-Location D:\Projects\DND-NCFU
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Обновление остановлено.' }

После успешного обновления снова откройте START_HOST.bat.
Сам BAT ничего не скачивает, не обновляет Git и не устанавливает программы.

ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ В POWERSHELL ИЗ ПАПКИ ПРОЕКТА

Состояние допусков и расходов:
.\scripts\tester_host.cmd list

Отозвать доступ tester1:
.\scripts\tester_host.cmd revoke tester1

Продлить tester1 на 30 дней без сброса расходов:
.\scripts\tester_host.cmd extend tester1 --days 30

Заменить RouterAI API-ключ (вводите только в локальный запрос команды):
.\scripts\tester_host.cmd key
После замены перезапустите хост.

Обновить отдельную копию ngrok, если потребуется (сначала остановите хост):
.\scripts\tester_host.cmd update-ngrok

Проверить доступность опубликованного адреса при работающем хосте:
.\scripts\tester_host.cmd diagnose-tunnel

Сохранённые настройки владельца находятся в:
%LOCALAPPDATA%\DND-NCFU-Host
Не передавайте эту папку тестировщику. Ему нужен только персональный Setup.
Бюджет RouterAI — 100 рублей на 30 дней; бесплатная квота ngrok учитывается отдельно.
