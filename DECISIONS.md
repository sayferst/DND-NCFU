# Решения проекта

## 27.10.2026 — автоматический полный корпус

Владелец явно потребовал доступ ко всем 19 000 фрагментам без действий игрока.
Вместо ограниченного индекса методов подключена поставляемая SQLite из 19 000
описательных карточек с source SHA/строками и 200 алиасами. Оригинальные правила
и hidden plot отсекаются типовым whitelist. Машинная фильтрация не выдаётся
за human review или SFT. Все три стадии ИИ получают справки автоматически.
Ранжирование CPU/FTS5, до 3/2400 UTF-8 байт, без новых запросов/зависимостей;
read-only/SHA/fallback, без влияния на старые сохранения и RNG.

## 26.10.2026 — единое новое поручение и канонический герой

Пользователь явно заменил прежние задания объединённым ТЗ. Причина: отдельные
версии/валюты/импорт в UI делали игру административным инструментом. Новый
путь schema30/UnifiedSession всегда один,6классов,атрибуты+таланты. Старые
обработчики и fixtures не переписываются; неоднозначные ranks/scout не мигрируют
автоматически. Четыре страницы вместо слияния прежних экранов,мир стартует сам.

Ресурсы/подготовка/XP зафиксированы в docs/unified/ruleset.md. Служебный старый
HeroProgress не является второй валютой: его изменение блокируется транзакцией.
Новая обёртка whitelist операций + проверяемый replay хранится целиком вJSON/SQLite.
Изменение проекции/ownership/RNG требует полного совпадения при загрузке.

24разрешённых оригинальных метода собираются в компактный index автоматически;
raw19000не считаются публичными инструкциями. Ручная библиотека удалена из UI,
developer CLI остаётся. Прежнее решение opt-in не применяется к новым играм.

LoRA выбран отдельным Transformers+PEFT NF4/BF16 контуром с pinnedQwen3-4B;
JSON-конфиг вместо YAML не добавляет runtime-зависимость. Model metadata
проверены,веса не скачаны. Основной blocker — нет допущенных реальныхSFT-пар.
Ни RouterAI весами,ни mock-benchmark не называются локальным обучением.
Owner-only localhost narrator применяется только при настоящем одобренном
manifest/hash/holdout; отсутствие/ошибка возвращают прежний RouterAI без
повторного игрового действия. Torch/данные/веса исключены из клиента.

## Разрешённые противоречия исходников

- `_OLDER` оставляет бюджет/офлайн открытыми, допускает недорогой облачный API;
  актуальны 0 ₽ и обязательный автономный режим из текущего запроса и мастера.
- Архивное ТЗ предлагает сразу SQLAlchemy/Alembic/Pydantic/Hypothesis и широкий
  импорт SRD. Добавление отложено до реальной потребности; сначала маленькие шаги.
- Старый первый запрос и мастер включают окно в этап 0. В текущей задаче 0A
  заканчивается настройкой; окно и игровой ответ принадлежат будущему 0B.
- В источниках научные ссылки местами названы «подтверждёнными»; эта сессия
  не проверяла публикации. В RESEARCH_LOG они зарегистрированы как кандидаты.

## D013 / 2026-10-16 — отдельный расчёт d20 и воспроизводимая сессия

Статус: принято. Пользователь принял первое окно и поручил добавить d20.
У каждой сессии собственный `random.Random` с seed; без задания seed используется
128-битная системная случайность. `randint(1, 20)` выдаёт целое число, UI показывает
его после расчёта. Рассказчик не выбирает результат. Seed, порядок и значения
бросков сохраняются; восстановление проверяет их и продолжает ту же последовательность.
Это общий примитив кубика, без заимствованных текстов SRD, модификаторов,
проверки сложности и правил критического успеха/урона. Соответствующие механики
SRD потребуют отдельной сверки источника и реализации.

## D020 / 2026-10-16 — homebrew и границы свободного редактора

## D021 / 2026-10-16 — валидируемое состояние и JSON v3

Статус: принято. WorldState — неизменяемая структура с неотрицательными ресурсами,
ограниченным HP, связью корзины/поручения и флагом одноразового исследования.
Действие вычисляет новый объект до применения. При ошибке вычисления состояние
и RNG не изменяются. Торговля сохраняет общую сумму денег и количество предметов.
JSON v3 сохраняет мир; v1/v2 мигрируют в памяти с начальными ресурсами, без
переигрывания старых реплик. Для регрессии сохранён fixture v2 из кода 8374ae1.
Объём мира пока мал, поэтому отдельная SQLite-схема отложена до связанных сущностей.
Полное восстановление мира из исторических текстов и защита от ручного читерства
в JSON не заявляются; для исследовательского replay нужен отдельный протокол событий.
