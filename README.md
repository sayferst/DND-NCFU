# DND-NCFU
разработка dnd для выпускной работы для скфу

Учебная текстовая RPG на Python для исследования конфликтных ситуаций.
Windows x64, i5-1135G7, 16 ГБ RAM. Обязательные расходы: 0 ₽.
Прототип работает офлайн, без API, аккаунтов, моделей и подписок.

## Что уже работает

- Создание нового героя и редактирование имени/шести характеристик во вкладке
  **«Герой»**. Свободный редактор — песочница, не полная генерация по SRD.
- Журнал, свободное поле ввода и кнопки быстрых действий. Неизвестные команды
  запрашивают уточнение; осмотр и разговор зависят от текущего места.
- d20 и проверки характеристик: например **проверить силу**, сложность 10.
- Здоровье, золото, бинты, корзина поручения; три места — ворота, дорога, рынок.
- Эпизод **«Доставка на рынок»**: поручение, исследование с риском, награда,
  покупка/продажа бинтов и лечение. Награда и находка выдаются один раз.
- Три ячейки сохраняют героя, мир, журнал и последовательность бросков.
  Перезапись и удаление требуют подтверждения. Старые v1/v2/v3 читаются.

Проверки характеристик используют подмножество SRD 5.2.1; источник и атрибуция —
[docs/SRD_RULES.md](docs/SRD_RULES.md), меню **«Справка → О программе и лицензии»**.
Сюжет, цены, награды, стартовое здоровье и лечение бинтом — авторские homebrew.
Это пока один небольшой эпизод; боёв, классов и ConflictSolver ещё нет.

Интерфейс объединён навигацией **«Раздел»**: главное меню, приключение, герой,
инвентарь, задание, карта, жители, лавка, кубики, команды, сохранения, настройки
и справка «Как играть». На старте открывается меню: загрузите ячейку или вернитесь
к новой текущей сессии. F11 — полный экран, Esc — выход из него.

Инвентарь содержит только свои вещи и их применение. Чтобы торговать, сначала
узнайте дорогу на рынок у стражника (или из поручения), придите туда и **подойдите
к торговцу**. Тогда станут известны ассортимент и цены. Деньги торговца скрыты;
при отказе выкупить предмет он скажет об этом. При уходе торговля закрывается.

Поиск/экспорт журнала, история ввода, темы и размер текста сохранены. Инструкция:
[docs/INTERFACE.md](docs/INTERFACE.md), принципы сведений игрока:
[docs/PLAYER_KNOWLEDGE.md](docs/PLAYER_KNOWLEDGE.md). Новых зависимостей нет.

## Получить обновление на свой диск D:

Сначала сохраните сессию и закройте старое окно игры. В PowerShell выполняйте
команды по одной. Если появилась ошибка — остановитесь и сохраните её текст.

```powershell
Set-Location D:\Projects\DND-NCFU
git pull --ff-only
.\.venv\Scripts\python.exe scripts\check.py
.\.venv\Scripts\python.exe scripts\run_game.py
```

`git pull --ff-only` обновляет именно файлы локального проекта на диске D:.
Рабочая ветка — `setup/development-environment`. Не удаляйте локальные изменения,
если Git отказывается обновляться. Для этого этапа новых зависимостей нет.
Ожидается **198 passed**, успешные pip check и обе проверки Ruff.
Ручную проверку нового интерфейса на Windows выполняет пользователь.

Если устанавливаете с нуля: [docs/INSTALL_WINDOWS.md](docs/INSTALL_WINDOWS.md).
При изменении зависимостей установка выполняется командой:

```powershell
.\.venv\Scripts\python.exe -m pip install --no-cache-dir --require-hashes -r requirements-dev.lock
```

Для обычного повторного запуска достаточно `scripts\run_game.py` через Python из `.venv`.

## Пройти первый эпизод

Можно нажимать кнопки под журналом или отправлять команды в игре:

```text
взять поручение
идти на дорогу
исследовать дорогу
идти на рынок
доставить корзину
подойти к торговцу
купить бинт
использовать бинт
```

В начале 12/12 здоровья, 10 золотых, 1 бинт. Доставка даёт 5 золотых.
Исследование при успехе даёт 2 золотых, при неудаче отнимает до 3 здоровья;
повторно оно не выдаёт ни награду, ни новый бросок. Бинт стоит 3, продаётся за 1
и восстанавливает до 4 здоровья. При полном здоровье бинт не тратится.

Дополнительно: **инвентарь**, **задание**, **состояние**, **торговля**,
**продать бинт**, **идти к воротам**, **осмотреться**, **поговорить**, **помощь**.
Полный сценарий приёмки — [docs/EPISODE.md](docs/EPISODE.md).

Во вкладке персонажа доступны **«Новый герой»** и **«Редактировать героя»**.
Новый герой начинает новую сессию; старые ячейки остаются. Редактирование сохраняет
здоровье, деньги, инвентарь и прогресс, а изменение профиля записывается в журнал.

## Сохранения и резервные копии

Во вкладке **«Сохранения»** у каждой из трёх ячеек есть **Сохранить / Загрузить / Удалить**. Автосохранения нет.
Сохраняются отправленные действия; черновик поля ввода не сохраняется.
При старте открывается новая сессия — для продолжения выберите «Загрузить».

Для проекта `D:\Projects\DND-NCFU` файлы находятся вне Git:
**`D:\Projects\DND-NCFU-data\saves`**. Путь показан в окне; папка создаётся при
первом сохранении. Делайте отдельную копию папки `saves`. Подробности и перенос
данных: [docs/SAVE_SLOTS.md](docs/SAVE_SLOTS.md).

## Карта проекта

- `src/rpg_vkr/domain/` — персонаж, кубик, состояние мира и проверки ресурсов.
- `src/rpg_vkr/application.py` — сессия, маршрутизация и атомарное применение действий.
- `src/rpg_vkr/ui/` — окно и редактор; `storage/slots.py` — три локальные ячейки.
- `scripts/run_game.py` — запуск; `scripts/check.py` — проверки.
- [PROJECT_STATUS.md](PROJECT_STATUS.md), [ROADMAP.md](ROADMAP.md) — статус и этапы.
- [AGENTS.md](AGENTS.md), [MASTER_CODEX_RPG_VKR_ZERO_COST.md](MASTER_CODEX_RPG_VKR_ZERO_COST.md) — инструкции.
- [DECISIONS.md](DECISIONS.md), [RESEARCH_LOG.md](RESEARCH_LOG.md) — решения и исследования.
- [TEST_PLAN.md](TEST_PLAN.md), [LICENSES_AND_ATTRIBUTIONS.md](LICENSES_AND_ATTRIBUTIONS.md).
- `docs/originals/` — неизменённые исходные документы и их SHA-256.
