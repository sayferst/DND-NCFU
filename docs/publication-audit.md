## Отбор A–D

| Категория | Подсистемы | Решение и основание |
| --- | --- | --- |
| A — реализовано и проверено локальными тестами | Session, герой, d20, конфликты, инвентарь/ресурсы, каталоги, сохранения/миграции, SQLite | Перенесены вместе с тестами и fixtures |
| A | Текущий Qt UI, вкладки, журнал, дневник, известная карта, энциклопедия, фотоальбом | Перенесены; Qt проверяется offscreen, не выдаётся за ручную Windows-проверку |
| A с внешними ограничениями | Контракты облачного мастера/художника, контекст и валидаторы, визуальный реестр | Перенесены; автоматические тесты без реальных платных моделей |
| B — ограниченное исправление | Зависимость тестов от внутренних отчётов и недоступные элементы серверной консоли | Заменены необходимые входы синтетическими, убраны серверные элементы UI |
| B | Публичный общий клиент | Встроенный персональный bootstrap запрещён; код вводится отдельно |
| C — экспериментальное | Ollama и качество конкретных моделей, общий клиент шлюза, персональные тестовые сборки | Ограничения обозначены; локальный транспорт сохранён без обещания полной автономности; общий клиент — prerelease |
| C | Полная SRD, универсальный мир, научное превосходство ИИ, автообновление | Не объявлены реализованными возможностями |
| D — внутреннее | server/, tunnel/host CLI, диагностика DNS/530, owner BAT, логи, планы и архивы исследовательских сеансов | Не перенесены; остаются в разработке |
| D | Воспроизведение личных отчётов и старых тарифов провайдера | Исключены отдельные отчётные тесты; общие контрактные проверки сохранены |

Миграционные JSON — зафиксированные примеры тестов, не каталог пользовательских
сохранений. Независимый корпус ответов перенесён в tests/fixtures; результаты
внутренних исследований и реальные отчёты не публикуются.

## Проверки и пределы

Создано отдельное окружение Python 3.12, установка из dev lock с `--require-hashes`
прошла, `pip check` успешен. Целевые Qt/контрактные проверки:143passed/29.50с;
упаковка/миграционные Git-фильтры/профили:64passed/3.87с.
Полный Linux `scripts/check.py`:1193passed/214.64с, Ruffcheck/format198файлов,
pipcheck успешен. Импорт113модулей и source Qt offscreen self-check/smoke-test
прошли с временными данными и loopback, без внешних модельных запросов.

Первая Windows CI-проверка:1192passed, один source smoke-test завершился
UnicodeEncodeError при печати русских названий в консоль cp1252. Файловый отчёт
уже сохранялся вUTF8. Исправлен только stdout: JSON теперь экранирует Unicode
вASCII. Добавлена регрессия с настоящим TextIOWrapper(cp1252). После исправления
44локальных проверки упаковки прошли, Ruff двухфайлов успешен. Нативные EXE и
оба установщика после этого исправления ещё требуют завершения Windows CI.
PR и актуальные проверки: https://github.com/sayferst/DND-NCFU/pull/1.

Скриншоты сняты с текущих Qt-виджетов на синтетической кампании без API-запросов.
Это не экспорт личной игры и не имитация скриншота Windows.

Проверка секретов охватывает публикуемые файлы и новые коммиты от main:
токены провайдеров/GitHub, приватные ключи, owner-пути, базы, DPAPI и активационные
артефакты. Строка `sk-secretkey-and-private-character-backstory` в тесте исключения
является явным синтетическим входом; реальные ключи не включаются.
Открытый Ed25519-ключ в workflow/инструкциях предоставлен владельцем для проверки подписи.
Проверка по шаблонам не является математическим доказательством отсутствия любых секретов.

Публикационная ветка не делает существующую рабочую ветку приватной. Новая лицензия
авторскому коду не назначалась. Лицензии SRD, Qt и зависимостей сохранены отдельно.
