# DND-NCFU 0.4.0 — подготовка предварительного выпуска

Статус: локальный текст для проверки, Release не опубликован и тег не создан.
Предлагаемый новый тег v0.4.0-rc.1, только после согласования. Существующие теги
0.3.1 не переназначать. Версия приложения 0.4.0 пока не объявляется stable.

## Изменения

Единый конструктор шести классов, характеристики/таланты; подключённые боевые,
магические и производственные действия; конечная экономика и события мира;
автоматический RAG; совместимость старых кампаний и миграция копии.
Обучения LoRA не было. Ограничения: возможны ошибки/обрывы модели, долгие загрузки,
ограниченная симуляция и незавершённая ручная приёмка.

## Сборка и проверяемые сведения

Проверенный исходный код: f033d94c44dbb9a1cee81fa0c8b6279cdc6f51d3.
Windows CI40739613065: все 7jobs успешны. Установка/обновление/повторная установка
и старое сохранение проверены автоматическим probe; это не ручная приёмка монитора.
Qt100/125/150/200% проверен offscreen наWindows. Коммерческой цифровой подписи нет.
Профиль CI developer: его установщик нельзя выдавать за готовую аккаунтную сборку.

Основной публичный файл должен быть аккаунтным tester Setup: `setup.exe`, Windows x64.
Перед публикацией владелец собирает его при готовом хосте, проверяет вход/создание
мира/сохранение/загрузку/неверный пароль/недоступную сеть без платных smoke-вызовов,
передаёт SHA256 точного файла. Имя файла/версия внутри/commit/profile фиксируются
в release-manifest.json. Сейчас SHA256 именно публичного tester Setup неизвестен;
выдумывать его или подставлять хэш внешнего CI ZIP нельзя.

## Условия публикации

1. Решение по правам собственного кода/распространяемых данных.
2. Подтверждённые профиль, commit, SHA256 и сканирование содержимого точного Setup.
3. Windows проверки/совместимость/повторная установка; ручная приёмка владельца.
4. Проверенный предыдущий установщик для upgrade берётся из постоянного Release
   только после сверки хэша с историческим probe, не по совпадению номера версии.
5. Отдельное разрешение владельца на публичный prerelease; stable отдельно.

Публиковать по утверждённому тегу/вручную, не при каждом feature-push. Существующий
full-system-windows.yml остаётся основной сборкой; не добавлен дублирующий выпуск.
Нельзя публиковать owner binding, private account config, API-ключи, сырые данные.
Установка и начало игры: [инструкция](../tester-guide.md).
