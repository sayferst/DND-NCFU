# 1R — меню, Хроники мира и удобство Flash

Пакет от 20 октября 2026 года меняет интерфейс. Правила действий, мастер-планировщик,
валидация игровых последствий, RNG, инвентарь и формат сохранений22 не переписаны.

## Что открыть после обновления

Игра начинается с нового главного меню. «Новая легенда» открывает существующее
создание героя; «Продолжить приключение» возвращает активного героя, а без него
открывает выбор рабочих кампаний/трёх ячеек. Выход в меню не сбрасывает сессию
и черновик реплики. Ctrl+M — меню; полный экран — через «Вид», Esc — вернуться.

В игре используйте раздел «Хроники мира» или кнопку «Хроники» рядом с навигацией.
При ширине меньше900px навигация компактнее; расчёты приключения доступны кнопкой
«Кубики» в отдельном окне. На широком экране прежняя панель расчётов справа.
Это один и тот же виджет: открытие окна не бросает кубики и не меняет историю.

Фон меню — собственная иллюстрация, включённая в проект; сетевой загрузки при
запуске нет. Иконки категорий нарисованы средствами Qt. Новых зависимостей,
пакетов шрифтов и плагинов нет. Общая палитра охватывает игру, героя, инвентарь,
карту, сохранения, настройки и создание персонажа. Цвета ролей и размер текста
журнала сохраняют прежние настройки. Системная тема использует новую тёмную
палитру; доступны также явные светлая и тёмная темы.

## Как наполняются Хроники

Это проекция существующих данных текущей кампании, а не второй независимый мир.
Источники: каталог, снимки подтверждённых взаимодействий, посещённые места,
старые публичные факты и MemoryNote. JSON-ячейка и SQLite уже сохраняют эти
источники; отдельной таблицы с дублирующими NPC не добавлено.

Слева категории с существующими известными записями, по центру поиск результатов,
справа полная карточка. Есть поиск, сортировка по имени/последней встрече, фильтры
«Рядом», «Содержит слухи», «Частично известно». Наведение показывает короткую
карточку; щелчок выбирает полную. Enter переводит к карточке. В маленьком окне
категории представлены выпадающим списком, «Открыть карточку»/Enter открывает
большое окно с прокруткой. Двойной щелчок по известному месту на карте открывает
его запись в Хрониках.

Новая запись появляется при подтверждённой встрече/наблюдении либо публичной
записи памяти. Категории: персонажи, существа, предметы, места, организации,
события. Пустые демонстрационные организации и сюжетные персонажи не добавляются.
Изменение кампании обновляет сведения и сбрасывает поиск другой кампании.

Настоящее имя из внутренней базы NPC само по себе не означает знакомства.
До публичного представления карточка показывает неизвестного персонажа/видимую
роль. Приватные планы, скрытые мотивы, кошельки NPC, точные скрытые характеристики,
невидимые места и содержимое закрытой тары не выводятся. Местонахождение NPC
показывается как последнее известное; удалённый NPC не отслеживается вживую.
Слухи помечаются отдельно. Неизвестные свойства остаются неизвестными.

Общий контракт публичного раскрытия использует уже существующие записи памяти:
`MemoryNote(kind="knowledge", private=False, subject=<ID>, text=<JSON>)`,
где JSON содержит `field` и `value`. Поддержаны public_name, role, appearance,
ancestry, background, material, properties, effects, price, faction, description.
Мастер получает это уточнение в стандартном текстовом промпте. Если вы используете
собственный master_system_prompt.local.txt, он автоматически не перезаписывается;
для той же разметки перенесите в него добавленный раздел о публичных знаниях. Запись всё равно проходит
прежнюю проверку памяти; текст художественного ответа автоматически не парсится
в канонические факты. Нет специальных правил для Весты или корзины.

Ограничение: если старый рассказ уже сообщил имя, но не оставил публичную запись
факта/памяти, Хроники могут сохранить «Неизвестно». Мы не угадываем тайны по всему
тексту диалога. Не обещается идеальный учёт любой детали, которую модель не
зафиксировала. Публичность памяти всё ещё зависит от корректной разметки мастера.

«Экспорт известных сведений» сохраняет только публичные карточки в новый JSON,
без внутренних ID и приватного состояния. Существующий файл не перезаписывается;
папка игровых ячеек запрещена как назначение. Это не резервная копия игры.
Полные игровые JSON/SQLite содержат и сведения ведущего: не публикуйте их как
экспорт знаний героя.

## Включение DeepSeek Flash

1. Из меню откройте «Настройки» → «Параметры подключения…».
2. Выберите RouterAI, введите действующий обычный API-ключ, разрешите отправку
   сцены. Ключ создаётся пользователем на https://routerai.ru/settings/keys.
   Приложение не входит в браузер и не получает ключ автоматически.
3. На Windows при желании отметьте «Запомнить ключ на этом ПК» и нажмите
   «Сохранить подключение» в настройках. Иначе ключ действует только в текущем
   процессе; можно использовать переменную `RPG_VKR_ROUTERAI_API_KEY`.
4. Отметьте «Включить ИИ-мастера DeepSeek Flash». Игра проверит ключ, месячный
   лимит и каталог; при наличии выберет `deepseek/deepseek-v4-flash-latest`.
   Если этой модели нет, платная замена автоматически не выбирается.
5. Дождитесь «Подключён». Настройте подключение до создания нового мира, если
   хотите генерацию моделью. Во время проверки отправляемая реплика остаётся
   в поле ввода; повторите отправку после проверки.

Проверка подключения делает GET метаданных, **не POST генерации**. Действуют
прежние требования месячного лимита ключа не выше2000₽ и проверки перед генерацией.
Игра не пополняет баланс и не меняет лимиты. Недоступность сети, отсутствие
настройки и исчерпание лимита различаются в статусе. Сам API необязательный и
может быть платным; офлайн-режим сохранён.

`ai-connection.json` рядом с рабочей базой хранит только провайдера, модель,
предпочтение включения и согласие. На Windows ключ по явному выбору сохраняется
в `routerai-credential.bin`, зашифрованном DPAPI текущего пользователя. Этот файл
не переносим между пользователями/ПК как обычный пароль. На других ОС открытого
резервного способа записи ключа нет. Снятие «Запомнить…» и сохранение удаляет
прежний защищённый файл. Ключ не включён в кампании, Хроники и обычные настройки.

При следующем запуске предпочтение включения восстанавливается. С ключом и
согласием выполняется только проверка метаданных; без них облако не включается
и рассказ автоматически не запрашивается. Реальные ответы DeepSeek, стоимость
и нативная работа DPAPI на Windows не проверены в Linux-среде разработки.

## Обновление локальной папки Windows

Закройте окно игры. Следующий блок копирует всю папку данных и локальный промпт,
получает изменения в `D:\Projects\DND-NCFU`, проверяет проект и запускает окно.
При конфликте Git остановится; локальные изменения автоматически не удаляются.
Новые библиотеки устанавливать не требуется.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location 'D:\Projects\DND-NCFU'
    $gameData = if ($env:RPG_VKR_DATA_DIR) { $env:RPG_VKR_DATA_DIR } else { 'D:\Projects\DND-NCFU-data' }
    $backup = Join-Path 'D:\Projects\DND-NCFU-backups' (Get-Date -Format 'yyyyMMdd-HHmmss-fff')
    New-Item -ItemType Directory -Path $backup | Out-Null
    if (Test-Path -LiteralPath $gameData) {
        Copy-Item -LiteralPath $gameData -Destination (Join-Path $backup 'game-data') -Recurse
    }
    if (Test-Path -LiteralPath 'prompts\master_system_prompt.local.txt') {
        Copy-Item -LiteralPath 'prompts\master_system_prompt.local.txt' -Destination $backup
    }
    git switch setup/development-environment
    if ($LASTEXITCODE -ne 0) { throw 'Git не переключил ветку. Сохраните вывод.' }
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Git не обновил файлы. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\repair_fixture_checkout.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка тестового файла не прошла. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\check.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка не прошла. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\run_game.py
}
```

После обновления проверьте меню, продолжение старого мира, Хроники, карточку
известного NPC, неизвестные свойства, поиск/фильтры и сохранение с перезапуском.
Для ручной Windows-приёмки DPAPI: сохраните ключ через UI, закройте игру, откройте
заново и убедитесь, что подключение проверяется; затем снимите запоминание и
сохраните. Не присылайте ключ или защищённый файл в чат.
