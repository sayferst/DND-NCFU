Порядок продолжения: закончить проверку/приёмку27, затем механики конструктора и
магии/ремесла по согласованным правилам; отдельно проектировать перенос копии и
расширение мира. Материалы архива использовать как кандидатов/сценарии проверки,
а не автоматически исполняемый баланс. Отбор техник для RAG остаётся отдельным
путём разработки без изменения числовой истории кампаний.
