Статус экспорта на обучение: BLOCKED_PROVIDER_TRAINING / BLOCKED_DATA_REVIEW.
Обычный inference не изменяет веса. В этом этапе нет сравнительной человеческой
оценки прозы и нет доказанного прироста качества модели. Состояние API-ключей,
конфигурация хоста, лимиты и DPAPI-хранилища не менялись.

Дополнение CODEX READY: ключ для санкционированного probe был только во временном
файле вне Git, затем удалён. `scripts/learning/live_probe.py` по умолчанию dry-run,
при --execute проверяет каталог/месячный остаток, резервирует стоимость перед
POST и ограничивает выход1024токенами. Проверка inference не читает «все веса»:
через этот API они недоступны. Сохранённые пользовательские подключения
автоматически на новую модель не переключались.
