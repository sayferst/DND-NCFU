# Проба Qwen2.5 7B на Windows — 19 октября 2026

Пользователь разрешил попробовать qwen2.5:7b после повторных несвязных ответов
Qwen3 1.7B. Подготовлена работа через существующую Ollama. Это новая проба качества,
не утверждение, что модель уже установлена или проверена на Windows агентом.
Прямого удалённого доступа к ПК пользователя в этой среде нет.

Модель бесплатная, API/подписка/карта не нужны. Ориентир загрузки — 4,7 ГБ;
фактический размер/digest проверяются локально. Для сохранения на D: запускаем
сам сервер Ollama с OLLAMA_MODELS=D:\AI\Models. Одной переменной у команды pull
недостаточно: уже работающий сервер мог быть запущен с другой папкой.
Текущую 1.7B и игровые сохранения не удаляем. Ожидание ответа 7B будет больше;
первая загрузка особенно медленная. В игре остаются CPU/четыре потока/ограниченный
контекст. Минимум8ГиБ свободного D: в блоке — запас, не точный размер модели.
Прочие конфигурационные файлы Ollama/Windows могут оставаться на C: как раньше.

## 1. Обновить проект

Закройте игру с сохранением. В PowerShell:

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location 'D:\Projects\DND-NCFU'
    $saveDir = 'D:\Projects\DND-NCFU-data\saves'
    if (Test-Path $saveDir) {
        Copy-Item -LiteralPath $saveDir -Destination ($saveDir + '-backup-' + (Get-Date -Format 'yyyyMMdd-HHmmss')) -Recurse
    }
    git switch setup/development-environment
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось переключить ветку.' }
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Обновление не получено.' }
    .\.venv\Scripts\python.exe scripts\check.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверки проекта не прошли.' }
}
```

Зависимости прежние, переустановка Python/pip/библиотек не требуется.

## 2. Запустить Ollama с хранилищем на D:

Полностью выйдите из Ollama через значок в трее → «Выйти». Блок ниже не убивает
чужие процессы; если порт ещё занят, попросит закрыть работающую Ollama.

В этом окне PowerShell запустите и **оставьте его открытым**:

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $ollamaExe = 'D:\AI\Ollama\ollama.exe'
    if (!(Test-Path $ollamaExe)) { throw 'Ollama не найдена в D:\AI\Ollama.' }
    if ((Get-PSDrive D).Free -lt 8GB) { throw 'На D: нужно не менее 8 ГиБ свободного места.' }
    if (Get-NetTCPConnection -LocalPort 11434 -State Listen -ErrorAction SilentlyContinue) {
        throw 'Порт 11434 занят. Полностью выйдите из прежней Ollama и повторите блок.'
    }
    New-Item -ItemType Directory -Force -Path 'D:\AI\Models' | Out-Null
    [Environment]::SetEnvironmentVariable('OLLAMA_MODELS', 'D:\AI\Models', 'User')
    [Environment]::SetEnvironmentVariable('OLLAMA_NO_CLOUD', '1', 'User')
    $env:OLLAMA_MODELS = 'D:\AI\Models'
    $env:OLLAMA_NO_CLOUD = '1'
    $env:OLLAMA_HOST = '127.0.0.1:11434'
    & $ollamaExe serve
}
```

Появятся журнальные строки сервера; ожидается прослушивание127.0.0.1:11434.
Пока сервер работает, строка приглашения PowerShell в этом окне не возвращается —
это ожидаемо. При ошибке запуска не продолжайте загрузку в следующем окне.
Позже Ctrl+C в этом окне завершит именно запущенный здесь сервер.

## 3. В новом окне PowerShell скачать модель и проверить лицензию

```powershell
& {
    $ErrorActionPreference = 'Stop'
    $ollamaExe = 'D:\AI\Ollama\ollama.exe'
    $env:OLLAMA_HOST = '127.0.0.1:11434'
    Invoke-RestMethod -Uri 'http://127.0.0.1:11434/api/version' -TimeoutSec 10
    & $ollamaExe pull qwen2.5:7b
    if ($LASTEXITCODE -ne 0) { throw 'Модель не загрузилась. Сохраните текст ошибки.' }
    $info = Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:11434/api/show' -ContentType 'application/json' -Body '{"model":"qwen2.5:7b"}' -TimeoutSec 20
    if ($info.license -notmatch 'Apache' -or $info.license -notmatch '2\.0') {
        throw 'Лицензия конкретного тега не подтверждена. Пока не запускайте модель.'
    }
    New-Item -ItemType Directory -Force -Path 'D:\AI\Checks' | Out-Null
    $recordName = 'D:\AI\Checks\qwen25-7b-' + (Get-Date -Format 'yyyyMMdd-HHmmss') + '-' + ([guid]::NewGuid().ToString('N')) + '.json'
    $info | ConvertTo-Json -Depth 30 | Set-Content -Encoding UTF8 $recordName
    & $ollamaExe list
    Write-Host "Сведения о модели и лицензия: $recordName"
}
```

Дождитесь success. Лицензия/параметры конкретного тега сохраняются вне Git.
Проверка текста Apache2.0 не заменяет чтение лицензии при дальнейшем распространении.
Через облачную среду карточка этого тега/размер/квантование не получены:
Ollama Library/Hugging Face/реестр блокировались прокси. Не выдаём ориентир4,7ГБ
за живое измерение. Веса не включаются в репозиторий.

Если загрузка оборвалась, повторить pull того же тега; TLS/проверку SHA не отключать,
старые веса/частично загруженные файлы не удалять автоматически.

## 4. Сравнить ответы и выбрать модель в игре

```powershell
Set-Location 'D:\Projects\DND-NCFU'
.\.venv\Scripts\python.exe scripts\check_narrator.py --model qwen2.5:7b --compare-with qwen3:1.7b --timeout 240
.\.venv\Scripts\python.exe scripts\run_game.py
```

Тест не скачивает моделей и не открывает пользовательских ячеек. Обе модели
получают копии одного начального мира и пять одинаковых сообщений. Их реальные
профили/запросы записываются: для1.7B применяется короткий режим, для7B обычный.
Это сравнение пользовательских конфигураций, **не эксперимент, изолирующий влияние
одних весов**. Модели выгружаются после каждой серии, чтобы не держать обе в RAM.
При транспортном отказе серия прекращается. Отклонённые попытки тоже сохраняются.

JSON и читаемый TXT с ответами, причинами отказа, временем, model digest и версиями
кода/промпта — в D:\Projects\DND-NCFU-data\diagnostics, новое имя на каждый запуск.
Код возврата отражает ограниченные проверки основной qwen2.5:7b. Отказ старой
1.7B сам по себе не означает отказ основной. Программа **не оценивает грамматику**:
в отчёте literary_review=pending. Оцените язык, причинность, полноту ответа и
отсутствие придуманных реплик игрока. При отказе выгрузки сравнение остановится;
основной результат и ошибка останутся в отчёте.

В игре открыть «Раздел → Рассказчик», нажать «Найти установленные модели», выбрать
**qwen2.5:7b** и включить мастера/свободный ввод. Проверить имя в диагностике:
`модель: qwen2.5:7b`. Само скачивание не переключает существующее окно с1.7B.
Можно загрузить прежнюю ячейку; старый текст останется в журнале, плохие сцены
версий1–3 не используются как реплики NPC в новом промпте. Новые игровые кнопки,
ручной GPT и случайный мир этим пакетом не возвращаются.

## Что изменено в приложении

- Промпт — короткие русские сведения о сцене и явный говорящий вместо большого
  JSON с английскими названиями служебных полей. Внутренний контекст валидатора
  остаётся отдельным и не читается из ответа модели.
- Одна реакция на один ход. Для известной проблемной qwen3:1.7b —1–3 предложения,
  токены320/450; обычный профиль2–5 предложений,450/650. Краткость — инструкция,
  не автоматическая оценка литературного мастерства. API обычной Qwen2.5 не получает
  параметр think или /no_think. Qwen3 по-прежнему явно отключает thinking.
- repeat_penalty1.0: не усиливаем наказание за нужные повторения названий/имён.
  Это устранение возможной помехи, не измеренный результат A/B или причина всех ошибок.
- Новые проверки замечают неатрибутированное «я…»/подпись игрока и повторный подход.
  Нелепую грамматику/всю семантику они не доказывают и не исправляют.
- WriterJSON15/reader1–15, SceneRecord4/reader1–4, Narration10/reader1–10,
  SQLite snapshot12–15. Настоящая fixture14 создана до правок кодом36ce2f8.
  История, типизированные факты/имена, числовое состояние и RNG сохраняются.

Нового обучения весов и книжного датасета нет. Качество7B остаётся проверяемой
гипотезой до реального запуска на Windows; автоматические тесты HTTP — заготовки.

Если после запуска сервера сD: старая1.7B не видна в ollama list, probe проверит
основную7B и явно отметит пропуск сравнения. Он не скачивает1.7B заново и не
переносит/удаляет прежние веса сC:. Отсутствие основной7B завершает проверку с ошибкой.
