# Подключения и данные

Для нового облачного мира настройте мастера до создания кампании. Обычная сборка
использует введённый пользователем ключ провайдера. Поддержаны контракты RouterAI,
OpenAI и OpenRouter; наличие адаптера не гарантирует доступность любой модели.
Выбирайте модель из доступного каталога и проверяйте её поддерживаемые параметры.
ChatGPT-подписка не является API-балансом.

Художник настраивается отдельно и может использовать другой ключ RouterAI.
Перед генерацией показываются цена и согласие; неизвестные цены/возможности
блокируют отправку. Локальный бюджет не заменяет лимит аккаунта провайдера.
Тарифы могут измениться; сохранённые тестовые цены не являются текущим прайсом.

На Windows секреты сохраняются через DPAPI для текущего пользователя.
Если защищённое хранение недоступно, используйте ключ только в текущем сеансе.
Не публикуйте настройки, `.bin`, базы данных или содержимое каталога пользовательских
данных. Не включайте секреты в скриншоты и сообщения об ошибках.

Локальный Ollama — дополнительная возможность; устанавливается отдельно.
Модельный ответ проходит валидацию и может быть отклонён. Не обещается равное
качество локальных и облачных моделей, как и полностью автономная генерация нового мира.

## Общий тестовый клиент

`setup_api.exe` содержит публичный адрес discovery и открытый Ed25519-ключ,
предоставленные владельцем. Это не API-ключ. Фактический адрес шлюза проверяется
по подписи, сроку действия и последовательности обновлений. Встроенного допуска нет.
Код вводится отдельно, привязывается сервером к установке и может быть отозван.
Клиент не может самостоятельно увеличить серверный бюджет или продлить допуск.

Владелец выдаёт допуски существующими инструментами рабочей ветки. Чтобы извлечь
уже выданный код на своём Windows-ПК, в публикационной ветке выполните:

```powershell
.\.venv\Scripts\python.exe scripts\export_tester_code.py tester1
```

Файл `dist\tester1-access.txt` передайте только назначенному тестировщику лично.
Не загружайте его в GitHub Release. Команда не создаёт допуск, не меняет бюджет
и не проверяет его срок: окончательное решение принимает сервер при активации.
Полная инфраструктура хоста остаётся в ветке `setup/development-environment`.
