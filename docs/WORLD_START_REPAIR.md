# Мир не создан и возвращение к деревне — исправление 21.10.2026

## Новый экран создания мира

1. В главном меню выберите «Новая легенда», заполните анкету и пожелания к миру.
2. Нажмите «Создать героя». Анкета сохранится, откроется отдельный фэнтезийный экран.
3. Нажмите центральную **«Создать новый мир»**. Начнётся запрос к вашему мастеру.
4. Фоны и фразы сменяются во время ожидания, полоса движется снизу. Можно отменить
   запрос кнопкой «Отменить создание»; анкета сохранится для повтора.
5. При успехе появится **«Мир создан»**, затем автоматически откроется вступление
   в журнале. При отказе причина и повтор останутся на этом же экране.

Экран заменяет кнопку под журналом. «Продолжить приключение» для подготовленного
героя без мира возвращает к центральной кнопке. Три фона уже находятся в пакете;
переключение картинок не создаёт запросов к Художнику. Фразы — оформление ожидания,
а 100% появляется по реальному результату. Изменять настройки Windows не нужно.

**Дополнение: «ответ обрезан / достигнут лимит генерации».** Для создания мира
предел увеличен с4500 до **65 536 токенов**, ожидание — до15минут, буфер ответа —
до2МиБ. RouterAI получает явный лимит и при запуске без каталога. Дождаться ответа
можно в открытом окне; ожидание отменяется обычной кнопкой в панели Мастера.
Оплачиваются фактически использованные токены по тарифу выбранной модели.
После пересборки нажмите кнопку создания мира с сохранённым героем.

Если у героя ещё нет сохранённого мира, старый интерфейс позволял отправить
«начать» облачному мастеру. Его контекст содержал учебную деревню, а Художник
отказывался рисовать сцену, поскольку готового мира действительно не было.
Подключение ИИ и создание мира — два отдельных результата. Само заполнение
анкеты ещё не означает, что ответ генератора принят и сохранён.

Теперь чат и действия ждут готовый мир. Ошибка и кнопка повтора находятся
на экране создания мира. Пожелания к миру и описание героя сохраняются; присланный текст
в2685символов помещается в поле3000 и передаётся целиком. Литературное качество
живой модели этими техническими проверками не оценивалось.

## Обновление EXE

Закройте игру. Сначала выполните блок резервного копирования из
[инструкции сборки](WINDOWS_APP.md#обновить-существующий-проект-и-собрать-на-вашем-windows).
Для уже сохранённых данных и повторной сборки:

```powershell
Set-Location D:\Projects\DND-NCFU
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Обновление остановлено. Сохраните вывод.' }
.\scripts\build_windows.cmd
if ($LASTEXITCODE -ne 0) { throw 'Сборка остановлена. Сохраните вывод.' }
Start-Process '.\dist\DND-NCFU\DND-NCFU.exe'
```

Если вы прежде запускали EXE с `--data-dir "D:\Projects\DND-NCFU-data"`,
повторно используйте тот же аргумент, чтобы открыть прежнюю папку данных:

```powershell
Start-Process '.\dist\DND-NCFU\DND-NCFU.exe' -ArgumentList '--data-dir "D:\Projects\DND-NCFU-data"'
```

Обычный EXE использует `%LOCALAPPDATA%\DND-NCFU`; исходники по умолчанию —
`D:\Projects\DND-NCFU-data`. Не копируйте и не удаляйте папки наугад.
Обновление исходников не изменяет уже собранный или запущенный EXE.

## Продолжить после ошибки

1. Откройте прежнюю ячейку или рабочую кампанию в разделе «Сохранения».
2. Для героя без действий откройте «Продолжить приключение», затем **«Создать новый мир»**.
3. Если уже появились старые действия, та же кнопка предложит новый мир с исходной анкетой.
   Программа предложит сохранить рабочую копию старой истории и создать отдельную
   кампанию с исходной анкетой. Ячейки не перезаписываются; отмена сохраняет всё как есть.
4. Дождитесь вступления и названия нового места. После этого отправляйте сообщения
   и используйте «Изобразить сцену». При отказе причина останется на экране создания.

Новая легенда всегда запускает создание своего мира. При сетевой ошибке старый
эпизод не подставляется. Повтор вручную использует ваш обычный облачный тариф;
технические проверки сборщика обращаются только к локальному тестовому серверу.

Проверено в Linux из исходников и упакованного приложения; нативный Windows EXE
после исправления нужно пересобрать и проверить на вашем ПК.
[Сырые результаты](validation/world-start-2026-10-21/README.md).
