# 1T — подключение мастера и последний сохранённый ключ

С версии 1U панель «Рассказчик» переименована в «Мастер». Отдельное подключение
изображений находится в «Художнике»: [инструкция](MASTER_AND_ARTIST.md).


Панель «Рассказчик» разделена на сервис/ключ, модель и подключение.
Загрузка каталога, проверка ключа и платная генерация — разные операции.
Поле последней ошибки находится рядом с соответствующим действием.

## Как подключиться на Windows

1. Выберите RouterAI. Вставьте обычный API-ключ без слова Bearer и кавычек.
   Каталог публичный: для его загрузки ключ не нужен.
2. При желании нажмите **«Сохранить последний API-ключ»** рядом с полем.
   На Windows он шифруется DPAPI для текущего пользователя. Новое сохранение
   заменяет прежний ключ; при следующем запуске он подставится замаскированным.
   Опция «Запоминать последний ключ на этом ПК» также сохраняет его после
   успешного подключения. На Linux кнопка недоступна, открытого fallback нет.
3. Нажмите **«Обновить каталог моделей RouterAI»**. Найдите deepseek/flash
   через поиск и выберите `deepseek/deepseek-v4-flash-latest`.
   Можно оставить этот ID вручную, если каталог временно недоступен.
4. Разрешите отправку сцены и нажмите **«Проверить ключ и подключить мастера»**.
   Для RouterAI выполняется GET `/api/v1/key`, проверяющий ключ и доступный
   месячный лимит. У ключа нужен положительный месячный лимит до 2000 ₽,
   установленный вами в кабинете; новый безлимитный ключ эту проверку не пройдёт.
5. Вверху появится модель, подтверждение ключа и остаток лимита. Если ID введён
   вручную и отсутствует в загруженном каталоге, это явно отмечается: авторизация
   ключа не доказывает, что сервер сейчас обслуживает конкретную модель.
6. Вернитесь к игре. Только игровая реплика начинает платный запрос рассказа.
   Сохранение ключа, подключение и каталог не генерируют текст или изображение.

В разделе «Настройки» остался явный shortcut DeepSeek Flash и ссылка на эту же
форму. Открытие формы не меняет провайдера и не стирает введённый ключ.
Выключение мастера не удаляет сохранённые кампании или ключ из поля. Смена
провайдера очищает поле и согласие, чтобы не отправить чужой ключ на другой адрес.
Для OpenAI/OpenRouter профиль применяется отдельно; бесплатная проверка ключа
RouterAI не выдаётся за проверку этих провайдеров.

## Как сохраняется последний ключ

`<папка данных>/routerai-credential.bin` — зашифрованная запись DPAPI.
Она читается только тем же пользователем Windows. Ключ не записывается в кампанию,
репозиторий, настройки JSON, EXE или диагностические отчёты. Сохранение не проверяет
его у провайдера: опечатка останется опечаткой до нажатия «Подключить мастера».
Некорректное поле или сбой шифрования не заменяют прежнюю запись пустыми данными.

Чтобы перестать хранить ключ на диске, снимите отметку запоминания и нажмите
«Хранение ключа и сохранение настроек → Сохранить настройки…». Удаляется локальная
зашифрованная запись; ключ в кабинете не отзывается, поле текущего сеанса остаётся.
Для переноса на другой ПК введите ключ заново: копирование DPAPI-файла не переносит
права другого пользователя. Резервная копия всей папки данных сохраняет запись
в зашифрованном виде.

## Что исправлено

- Старый предел каталога 4 МБ отклонял большой корректный JSON. Теперь предел
  16 МБ; превышение и неверный JSON имеют отдельное сообщение.
- Модели без распознанной цены больше не исчезают из пользовательского каталога:
  цена отмечается как неподтверждённая. Цена за запрос/картинку не выдаётся за
  рубли на миллион токенов. Изображения по-прежнему требуют известной полной цены.
- GET каталога и GET ключа используют отдельные клиенты. Загрузка каталога не
  подменяет проверку ключа и не отменяет её незаметно. Отмена не включает мастер
  после позднего ответа; ответ сравнивается с провайдером, моделью, ключом и согласием.
- Применение выбранной модели и восстановление после перезапуска не заменяют её
  на Flash. Flash выбирается только явным shortcut.
- В облачном интерфейсе скрыт пустой селектор локальной модели; основные поля
  подписаны, диагностика сворачивается, у каталога есть поиск и отдельный статус.
- HTTP 401/402/403/429, сеть/TLS, формат, лимит и ошибка защищённого сохранения
  объясняются явно. Ответы сервера с возможным эхом ключа в интерфейс не копируются.
- Ключ проверяется на допустимый формат до HTTP. Переменная ключа другого
  провайдера не используется для RouterAI. Редиректы с ключом запрещены.

Проблемы подтверждены отдельными регрессионными тестами; это не диагноз точного
сетевого сбоя на вашем ПК. Если каталог снова не загрузится, теперь сообщение
появится непосредственно под ним. Оно поможет отличить сайт/сеть от настроек ключа.

## Проверки и оставшаяся приёмка

[Сырые результаты, до/после и снимки](validation/connection-2026-10-20/README.md).
Тесты используют реальный Qt и loopback HTTP, синтетические ключи и ответы.
DPAPI-обвязка проверяется с тестовым шифрованием; настоящий Windows DPAPI требует
ручной проверки на Windows. Нет платных запросов и оценки качества DeepSeek.
Контракт Images API из предыдущего пакета по-прежнему требует документации;
исправление текстового подключения не означает сверку этого внешнего API.

## Обновить файлы на D:

Закройте игру. Блок делает backup всей папки данных, обновляет существующую ветку,
проверяет проект и запускает игру. Зависимости для этого исправления не менялись.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location 'D:\Projects\DND-NCFU'
    $gameData = if ($env:RPG_VKR_DATA_DIR) { $env:RPG_VKR_DATA_DIR } else { 'D:\Projects\DND-NCFU-data' }
    $backup = Join-Path 'D:\Projects\DND-NCFU-backups' (Get-Date -Format 'yyyyMMdd-HHmmss-fff')
    New-Item -ItemType Directory -Path $backup | Out-Null
    if (Test-Path -LiteralPath $gameData) {
        Copy-Item -LiteralPath $gameData -Destination (Join-Path $backup 'game-data') -Recurse
    }
    if (Test-Path 'prompts\master_system_prompt.local.txt') {
        Copy-Item 'prompts\master_system_prompt.local.txt' -Destination $backup
    }
    git switch setup/development-environment
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось выбрать ветку.' }
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Файлы не обновлены. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\repair_fixture_checkout.py
    if ($LASTEXITCODE -ne 0) { throw 'Ошибка тестового файла.' }
    .\.venv\Scripts\python.exe scripts\check.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка не прошла. Сохраните вывод.' }
    $env:RPG_VKR_DATA_DIR = $gameData
    .\.venv\Scripts\python.exe scripts\run_game.py
}
```
