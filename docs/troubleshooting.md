# Решение проблем

| Симптом | Действие |
| --- | --- |
| Нет связи с мастером | Проверьте интернет; попросите владельца подтвердить готовность хоста |
| Не подходит профиль | Проверьте раскладку и выданные данные; владелец проверяет допуск |
| Исчерпан бюджет/срок | Обратитесь к владельцу; переустановка лимит не сбрасывает |
| Кампания долго загружается | Дождитесь фонового восстановления; не удаляйте сохранение |
| Setup прерван проверками | Передайте владельцу конец лога и первую ошибку; не обходите тесты |
| ngrok не скачивается | Владельцу: локальная установка проверенного ZIP по инструкции ниже |

Для владельца: после остановки хоста `scripts/tester_host.py update-ngrok --archive "ПУТЬ-К-ZIP"`
проверяет подпись официального EXE и версию перед заменой. Путь восстановления:
[ngrok recovery](validation/ngrok-recovery-2026-10-28/README.md).
Срок действия временного артефакта смотрите на GitHub; просроченная ссылка не релиз.

[Сообщить об ошибке](https://github.com/sayferst/DND-NCFU/issues/new/choose).
Укажите версию, Windows, шаги и текст ошибки. Удалите из вложений токены, пароли,
персональные данные и чужие игровые записи. Полное сохранение публично не прикладывайте.
