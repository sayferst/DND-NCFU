# Предложения проектных Skills

Skill — короткая повторяемая инструкция агенту для определённого вида задачи.
Ниже только предложения: Skills и сторонние плагины не установлены.

1. **small-verified-step** — прочитать текущий статус, выбрать один небольшой
   результат, выполнить подходящие проверки, обновить журналы и дать команды
   PowerShell. Поможет сохранять понятный темп и не терять контекст между сессиями.
2. **srd-rule-review** — сверить правило с официальным SRD 5.2.1, записать раздел,
   лицензию и адаптации, различить SRD/homebrew/research, проверить крайние случаи.
   Поможет избегать смешения редакций и закрытого контента.
3. **reproducible-conflict-study** — проверить научный первоисточник, зафиксировать
   гипотезу и протокол A/B, сохранить входы/seed/версии/сырые результаты,
   отделить наблюдения от интерпретации. Поможет готовить проверяемые материалы ВКР.

При принятии предложения оформить локальный SKILL.md с узкой областью применения.
Эти инструкции не требуют платных сервисов, моделей или внешних плагинов.
