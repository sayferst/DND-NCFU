# Исправление Windows-путей ресурсов

Основание — новый консольный вывод владельца: сборщик `.cmd` запущен на Windows,
Python3.12.10; **1214 passed, 1 failed / 275.80с**. PyInstaller ещё не запускался.
Единственный отказ: существующий тест `/absolute` ожидал ValueError.

`owner-windows.txt` сохранён побайтно из file_00000000137881f4ba228bf838788427:
19349 байт, SHA-256
`874d05c1da45037df2421c4b0bfa57c3e5a2dbf3a10e70cf55f741619d4d6cb9`.
Это результат запуска владельца, не запуск Windows в облачной среде.

Причина: Windows допускает путь с корнем без диска; у `/absolute`
`PureWindowsPath.is_absolute()` возвращает False, а `anchor` равен `\`.
Раньше проверялся только is_absolute. Теперь правила Windows применяются на
каждом хосте, проверяются корень/диск и `..`, затем сегменты переводятся в Path
хоста. Разрешены оба вида слешей. Данные пользователя обрабатываются по прежним
правилам; семь ресурсов не изменены.

  Сам `/absolute` уже отклонялся Linux; это различие не выдаётся за Windows-запуск.
