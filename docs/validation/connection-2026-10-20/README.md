## Ограничения

Нативный Windows DPAPI не выполняется на Linux. Проверена обвязка с тестовым
шифрованием и существующий контракт DPAPI; это не доказательство работы crypt32
на конкретном ПК. Живой RouterAI-ключ владельца не использовался, авторизация
сервиса на его ПК не подтверждена. Четыре воспроизведённых дефекта не доказывают,
какой именно сработал на его сети. Новая панель показывает конкретный этап и причину.

Публичный каталог — не проверка ключа. Успешный GET key — не выполнение платной
генерации и не доказательство обслуживания вручную заданного ID. При недоступном
каталоге это явно отмечается. Финансовая политика ключа и Images не ослаблена;
предыдущий несверенный контракт Images API остаётся отдельной задачей.
