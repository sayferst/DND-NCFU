# Аудит перед обновлением интерфейса, 21.10.2026

База: 1b4e19e, setup/development-environment; рабочее дерево было чистым.
Исходное поручение сохранено побайтно в OWNER_REQUEST.txt.

- MainWindow/EpisodePanels: один QTabWidget, скрытая строка вкладок и видимый
  QComboBox. WorldCreationScreen отдельный QStackedWidget, сохраняем его переходы.
- Master/Artist: существующие контроллеры, DPAPI владельца, выбранная модель и
  месячный бюджет не должны меняться при переносе UI. Flash и Artist добавляют
  технические shortcuts в обычные настройки — их тоже нужно перенести.
- ChroniclesPanel/knowledge: единственная публичная проекция; категории, поиск,
  фильтры уже есть. Новая сетка должна читать эту проекцию, не raw WorldSeed.
- VisualRegistry: SQLite aliases/requests/assets, неизменяемые PNG/версии/refs.
  Фотоальбом читает тот же реестр по campaign, без копирования и генерации.
- ImagesTransport: один POST, bounded JSON/PNG, без redirect/retry. Бюджеты на
  клиенте защищают владельца, но для распространения нужен отдельный сервер.
- Сборка: существующие spec, PowerShell/CMD, ручной workflow, Inno Setup.
  Сохранения вне установки, uninstall их не удаляет. Среда Linux, Windows здесь нет.
- Шлюза сейчас нет. Требуется отдельный stdlib HTTPS-компонент, токены с отзывом,
  атомарные серверные резервы, allowlist моделей/параметров, ограниченные тела,
  запрет произвольных upstream URL и повторной отправки request id.

Платные API/хостинг не запускаются. Системы механики, схемы сохранений, fixtures,
исследовательские результаты, стандартный промпт и исходные фоны сохраняются.
Этапы фиксируются отдельными коммитами; старые результаты не перезаписываются.
