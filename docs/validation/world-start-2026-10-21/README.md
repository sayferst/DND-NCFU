# Мир, чат и самостоятельная сборка — 21.10.2026

Владелец сообщил о запущенном Windows EXE: после создания героя появлялись
«Мир ещё не создан» и запись «Учебная кампания», но чат принимал «начать» и
получал старую сцену с деревней/стражником/яблоками. Художник требовал готовый мир.
Снимки и текст получены в чате. Точная исходная ошибка живого генератора по этим
данным не установлена; доступ к настоящему ключу и платные пробы не требовались.

Подтверждено в исходниках: проверка cloud_ready не проверяла WorldSeed. После
отказа генерации современный UI допускал чат/локальные действия на старом контексте.
Тайтл/журнал считали черновик завершённым после первого хода, база называла его
учебным. Ошибка нового мира была далеко от основного чата; исключение чтения
инструкции могло оставить генерацию в ожидании. Проверка пакета прежде начиналась
с уже готового seed, не проходила реальный диалог создания героя.

Изменения:

- Готовность мира проверяется до действий и чата; текст/состояние/RNG не меняются
  при отказе, повторная отправка не отменяет создание. Старый эпизод не подставляется.
- Ошибка и повтор видны под журналом. Некорректный формат повторяется максимум
  один раз; ошибки доступа/сети/отмена не повторяются автоматически.
- Анкета сохраняется; для сессии со старыми ходами новый мир создаётся с исходной
  анкетой в отдельной кампании после подтверждения. Рабочая история сохраняется
  до перехода, ячейки остаются побайтно прежними; отказ базы прекращает переход.
- Название незавершённой кампании обновляется без изменения revision/digest/payload.
- В smoke-test добавлены настоящий диалог→HTTPгенерация→чат→сцена→JSON/SQLite.
  Личный промпт в этой пробе исключён, остаётся неизменным; используется bundled default.
