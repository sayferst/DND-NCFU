маркеры копирования убираются; внутренние символы не соединяются и не удаляются.
Upstream также отклоняет старые ключи с управляющими/не-ASCII символами до HTTP.
Такие ключи могли быть сохранены прежним менее строгим первым вводом; это найденный
недостаток, а не доказанная причина живого400 пользователя.
