Изменения:

- При start явно сообщается об использовании сохранённого ключа и команде замены.
- Команда key проверяет формат и заменяет только API-credential. Ключ подписи,
  клиентские допуски и квоты остаются прежними. key/diagnose не открывают Store.
- Команда diagnose делает только GET метаданных ключа, без генерации, туннеля и Git.

  только фиксированные категории; исходный текст и персональные поля не выводятся,
  не сохраняются в исключении и не пересылаются клиентам.
- Отчёт содержит HTTP-статус, JSON/text/HTML и категорию. Распознавание помечено
  `reason_is_inferred`; неизвестный ответ остаётся неизвестным. Произвольные
  значения атрибутов исключения также отфильтрованы перед отчётом.
- Неудача чтения пояснения не затирает уже известный HTTP400. Платные endpoints,
  проверки allowance, бюджет и число попыток не менялись.
