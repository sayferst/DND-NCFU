## Исполнение

203 точные последовательности мультиатак, 36 с разными ударами.
Для критического попадания кости удваиваются без повторения постоянной прибавки.

вызывают один переход HP/счётчиков смерти. Проверены остановка серии при
падении цели, силовой урон, недопустимые индексы и полный replay.

Подключены 560 авторских магических шаблонов и 720 авторских рецептов.
Проверяются MP/уровень/владение/цель/одноразовость носителя; для ремесла —
реальные запасы, рабочее место, инструменты, время и бюджет ценности.
Проверено сохранение остатка частично израсходованной партии и отсутствие
самовосстановления материала после загрузки.
Новые свойства legacy-материала находятся у нового экземпляра; прежнее
определение не переписывается. Новые версии не включаются в старые миры.
