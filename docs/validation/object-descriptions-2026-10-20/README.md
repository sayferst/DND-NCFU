## Ручная проверка владельца

1. После backup/pull/repair/check/run открыть Хроники → Бинт: видны тип,
   видимая форма, назначение; скрытые эффекты не раскрыты.
2. Для старого сгенерированного предмета нажать «Уточнить описание», проверить
   вопрос, отправить его мастеру. Сохранить сессию и перезапустить: признаки те же.
3. Явно заказать новое изображение/перегенерацию, проверить модель/цену.
   У предмета должен быть сам объект, без владельца. Оценить настоящий результат
   вручную; старый кэш не перерисовывается при открытии.
4. Портрет и сцена сохраняют свои композиции и прежние референсы.
5. Сверить расходы вкабинете. Платные пробы вэтой сессии не проводились.
