# Изоляция теста обновления при сборке с работающим хостом

Владелец прислал реальный Windows-лог:12027passed/1failed/1skipped, полный
прогон остановлен на11пакете. test_fetches_and_fast_forwards_only_current_release_branch
видел настоящий tester_host.py start через Get-CimInstance и ошибочно ожидал
разрешённый fast-forward. Это ошибка изоляции теста; защита сборщика корректна.

Дочерний PowerShell теста теперь подменяет только Get-CimInstance в своём
сеансе. Сценарии отсутствующего/работающего хоста задаются явно. Дополнительная
проверка подтверждает: при работающем хосте fetch разрешён, merge заблокирован,
HEAD не изменён. Процессы пользователя не останавливаются, рабочий checkout
не используется. Производственный сборщик, хост, ключи и сохранения не менялись.
Нативный результат нового прогона следует проверять в Native updater isolation.
