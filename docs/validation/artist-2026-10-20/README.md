## Что проверено

- Имена/наличие двух разделов и алиас старой навигации; видимое поле ключа.
- Полные имена/ID Recraft и FLUX, поиск, неподтверждённый/полученный/неполный каталог.
- Общий и отдельный ключ, отсутствие скрытого fallback для пустого отдельного поля,
  отсутствие передачи ключа другого провайдера, независимость ключа Мастера.
- Настоящие loopback GET key/models, каталог без ключа, HTTP401/403/429/503,
  понятная причина нулевого/неограниченного месячного лимита.
- Ввод ключа не мешает публичному каталогу; отменённый/устаревший ответ не применяется;
  второй worker не запускается до завершения старого.
- Зашифрованное сохранение/замена/перезапуск/маска, ошибка сохранения без стирания
  прежней записи, удаление только ключа Художника.
- Перенесённые бюджеты и прежние пороги, выбор строки без генерации/изменения мира.
- Отдельный ключ доходит именно до FakeTransport.metadata/generate;
  один тестовый рендер не меняет Session/RNG, не кладёт ключ в реестр.
  Изображение — однопиксельная тестовая PNG, не результат нейросети.

## Визуальная проверка

Семь реальных Qt-снимков: Мастер, Художник, popup с двумя моделями, сведения FLUX,
компактный640×620 в двух положениях и бюджет в светлой теме. Снимки этапа просмотрены;
[исходник](capture-source.txt), [лог](screenshots.txt),
[манифест/SHA-256](screenshots-manifest.json).

Данные каталога/лимита и ключ синтетические, источник — loopback HTTP. Поэтому
показанные0.75/0.97₽ и1900₽ не являются подтверждением тарифа/баланса провайдера.
DPAPI-кнопки на Linux отключены; тестируется обвязка с подменой шифрования,
не нативный crypt32. Снимки сделаны до финального уточнения одной строки
информации о бюджете; структура и элементы подключения соответствуют реализации.

## Непроверенное

Живой RouterAI Images, правильность его текущей схемы, доступность моделей,
реальные счета/скорость/сходство/пиксель-арт и нативный Windows GUI/DPAPI не
проверены. Предыдущая внешняя сверка Images API всё ещё необходима.
Наличие ID в публичном каталоге не равно успешной генерации/персональному доступу.
Полный неизвестный тариф не обходится, платные повторы/автогенерация не добавлены.
