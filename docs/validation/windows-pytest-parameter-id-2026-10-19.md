# Windows: слишком длинное имя параметризованного теста

Источник — файл владельца ошибка.txt, загруженный 2026-10-19. SHA-256 исходника:
7363fa5ec8abab0a46470215b8686c482b6868963618db80637c38a0721eb8dd.
Исходник содержит представление окружения с личными путями; здесь сохранены только
необходимые выдержки. Это транскрипция/выборка, не побайтовая копия отчёта.

Python3.12.10, Windows, pytest8.4.2. Собрано777тестов. Результат:
`776 passed, 2 errors in 48.24s`.

Обе ошибки относятся к setup/teardown одного параметра теста
test_invalid_instruction_is_rejected_instead_of_silently_using_another.
Pytest записывает его nodeid в PYTEST_CURRENT_TEST. Сообщение:
`ValueError: the environment variable is longer than 32767 characters`.

Параметр b"x"*65537 автоматически вошёл вID; при проверке коллекции исходного
теста получены длины108,112,114,65645. Тело теста не успело выполнить проверку
файла инструкции. Linux-прохождение не выявляло ограничениеWindows.

Исправление: явные короткиеID empty/invalid-utf8/control-character/oversized,
с прежними исходными байтами и assert. Новый процесс pytest --collect-only
проверяет наличие всех четырёх случаев и длинуID ниже лимитаWindows. Это
воспроизводимый тест коллекции, не запуск настоящейWindows в облачной среде.
