# 1V — исправление Images API и автоматического выбора моделей

Исходная версия:5908560. Исправление кода:e172602. Текущий запрос владельца:
устранить «Каталог не подтверждает параметр size» и проверить автовыбор моделей.
Потом получены руководство и отдельные модельные примеры RouterAI; доступны
как источники вdocs/research. Реальных платных запросов было0.

## Причины

1. Адаптер ошибочно требовал supported_parameters.size и вымышленные обязательные
   supported_resolutions/max_input_references, хотя API допускает resolution
   и минимальные запросы без размера.
2. input_references передавался строками вместо документированных image_url объектов.
3. usage.cost без currency терялся как неподтверждённая валюта, хотя Images guide
   прямо определяет рубли.
4. common одновременно означал обычность предмета и общий файл типа. Отключение
   общего файла ошибочно выбирало FLUX для обычной вещи без референсов.

## Решение и файлы

- visuals/policy.py: альтернативы размера/полная цена, документированные профили,
  корректные references, автоматический класс модели и объяснение.
- visuals/context.py: economy_eligible отдельно от common(type/instance).
- visuals/client.py: RUB usage.cost, явная чужая валюта остаётся чужой.
- ui/visuals_panel.py: реальное распределение, причина доPOST/при отказе/после успеха.
- ui/artist_panel.py: честное обозначение размера по умолчанию модели.
- tests/test_images_contract_revision.py:41новый случай; прежние тесты уточнены
  под документированные objects/явный0лимит, защита расходов не отключена.

Фиксированная полная цена без параметра размера позволяет минимальный запрос
при обычной1Kнастройке, без обещания точных1024пикселей. Recraft принимаетaspect_ratio1:1.
Выбор особого размера или тарифа по неизвестному варианту остаётся заблокирован.
FLUX references подтверждены конкретным модельным примером, не обязательной
полнотой supported_parameters. Неизвестный верхний лимит →1приоритетныйобраз.
Явный0/невалидныйлимит не игнорируется. Recraft не принимаетреференсы.

Общий образ влияет только на хранение. Любое прежнее изображение при перегенерации
→FLUX. Никаких изменений сохранений/канона/RNG/бюджетов/ключей/модели DeepSeek.

Все HTTP-запросы в тестах направлены на loopback. FakeTransport возвращает
тестовую PNG, не настоящий Recraft/FLUX. Пять исходных случаев — измерение
ошибок приложения, не статистика качества настоящих моделей/научныйэксперимент.

предоставленных владельцем источниках. Нужна Windows/живаягенерацияприёмка.

## Ручная проверка Windows

ОбновитьпапкуD: и запустить проверку блоком изMASTER_AND_ARTIST.md, затем:

1. Художник → загрузить модели/проверить ключ; прежний бюджет не сбрасывается.
2. Выбрать обычный предмет вХрониках → создатьобраз. Вподтверждении Recraft,
   причина/полнаяцена, размер либо явное«поумолчанию». Отключениеобщегообраза
   само по себе не переключает обычную вещь вFLUX.
3. NPC/существо/место/сцена →FLUX. При неизвестнойцене или превышениилимита
   не будетPOST; причина и выбраннаямодель видны.
4. После отдельного согласия вUI создать изображение, перезапустить: просмотр
   изкэша безоплаты. Перегенерация используетFLUX и прежнийобраз-референс.
5. Передсценой с известным портретом проверить количество/цену вдиалоге.
   При неопределённом рефлимите будет1образ, при объявленном — доэтоголимита.
6. Сверитьusage/кабинет/изображениевручную. Отмена послеPOST не обещает возврата.

Без бюджета/разрешения отправки тестировать только бесплатные GET. Codexне
запускал платныепроверки. Внешнийсервис, качество, сходство, текущаяцена искорость
не подтверждаются этими автоматическими тестами.
