# Экран рождения мира — 21.10.2026

Прямой запрос владельца: после анкеты и «Создать героя» отдельная центральная
«Создать новый мир», затем фэнтезийная загрузка со сменой фонов, фразами и нижней
полосой, подтверждение успеха и начало истории в журнале. Кнопка под журналом
заменена этим экраном. Увеличение65536токенов/15минут из c9504af сохранено.

## Реализация

WorldCreationScreen — отдельная страница QStackedWidget, вне списка игровых
разделов. Анкета только готовит героя; платный POST начинается центральной кнопкой.
Во время API используется неопределённая полоса range(0,0), таймер33мс рисует фон,
меняет фразы раз в4.2с и панорамы раз в9с с плавным переходом. Он не меняет сессию
и игровой RNG. Фразы декоративные. Принятый WorldSeed даёт реальный100%, надпись
«Мир создан» и переход700мс к журналу. Callback привязан к той же сессии.
Ошибка/отмена оставляют анкету и повтор; сеть/бюджеты/проверки мира прежние.
Архивная история доступна, черновик в меню не называется воротами деревни.

## Изображение

`art-provenance.json` содержит источник/описание запроса/SHA-256 и размер нового
PNG. Он создан инструментом OpenAI image generation по этому поручению, исходник
оставлен в workspace/generated_images, в assets побайтная копия.1254×1254,
3341575байт, три горизонтальные панорамы: горное королевство, лесной город,
подземные чертоги. Qt выбирает sourceRect во время рисования, файл не редактируется.
Это локальное оформление; ожидание не вызывает Художника и не добавляет данные
в канон кампании. Исходный kingdom.png и стандартный промпт неизменны.
