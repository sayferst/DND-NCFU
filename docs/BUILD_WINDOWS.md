# Опциональная бесплатная сборка Windows EXE

Сборку Windows выполняйте на Windows x64 с Python3.12. LinuxPyInstaller не
создаёт WindowsEXE. Здесь проверены сборка Linuxonedir и --self-check ресурсов;
готовый нативный WindowsEXE в облачной среде не создан и не проверен.

```powershell
Set-Location 'D:\Projects\DND-NCFU'
.\.venv\Scripts\python.exe -m pip install --no-cache-dir --require-hashes -r requirements-build.lock
powershell -NoProfile -File scripts\build_windows.ps1
```

requirements-build.lock — отдельный lock бесплатных инструментов упаковки,
включающий прежниеruntime/devпины и PyInstaller6.16.0. Обычная игра не требует
его установки. Не редактируйте исходный requirements-dev.lock ради сборки.
Скрипт сначала запускает все проверки, затем создаёт dist\DND-NCFU.
Переносить нужно **всю папку**, включая _internal, не одинexe.

Сборка включает ресурсыUI, общиеdata, стандартный системныйпромпт и лицензии.
Ключи, .env, пользовательскийlocalпромпт, кампании,визуальнаяSQLite и картинки
изпапкиданных не включаются. Игровой код не содержит настоящегоAPI-ключа.
Рецепт DND-NCFU.spec использует белыйсписок ресурсов, не рекурсивное включение
всей папкипользователя.

Чтобы использовать прежние данные на D:, перед запуском:

```powershell
$env:RPG_VKR_DATA_DIR = 'D:\Projects\DND-NCFU-data'
& '.\dist\DND-NCFU\DND-NCFU.exe'
```

Без переменной EXE использует `%LOCALAPPDATA%\DND-NCFU`. Обновление папки
программы не удаляет эту папку. В EXE личныйпромпт находится в
`<папка данных>\prompts\master_system_prompt.local.txt`; при необходимости
скопируйте туда свою версию, не упаковывайте её вприложение. Резервнаякопия —
весь каталогданных, с SQLite/картинками и настройками; ключDPAPI привязан к
томуже Windowsпользователю, на другом ПК его нужно указатьзаново.

Проверка собранного приложения без обращений к моделям:

```powershell
$p = Start-Process '.\dist\DND-NCFU\DND-NCFU.exe' -ArgumentList '--self-check' -Wait -PassThru
$p.ExitCode
```

Ожидается0. Это проверка упаковки ресурсов, не проверка облачных API или всейGUI.
Далее вручную откройте старый мир, Хроники/кэш, закройте и перезапустите EXE;
проверьте внешнююпапкуизображений. Платнуюгенерацию не запускайте ради сборки.
Каталог licenses с доступными уведомлениями включён в bundle, вместе с
LICENSES_AND_ATTRIBUTIONS.md. Установленные здесь wheels PySide6/shiboken
не содержат отдельных файлов лицензий; это не полный комплект уведомлений Qt
для распространения. Перед распространением сборки нужно приложить официальные
тексты/уведомления для конкретных Qt-библиотек и проверить условия LGPL/GPL.
Личная техническая проверка упаковки не подтверждает юридическую готовность
дистрибутива. Ссылки и сведения: LICENSES_AND_ATTRIBUTIONS.md.
