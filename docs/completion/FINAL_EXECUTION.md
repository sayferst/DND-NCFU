# Завершение: текущая разработка

Пользователь просит закончить проект до обновления своей локальной установки.
Работа выполняется в существующей feature/unified-rpg-automatic-gm. Команды для
диска D: сейчас не требуются; локальная установка владельца не затрагивается.

Опубликованные каталоги1/2 и их replay заморожены. Разрабатывается внутренняя
ревизия3, автоматически выбираемая для новых героев без выбора версии игроком.
До окончательных проверок это непубличный рабочий вариант, не готовый релиз.

Уже изменён код: классовые способности/ресурсы, прочность/ремонт, физические
свойства после покупки (включая боеприпасы), регистрация сцен после появления
физического инвентаря, запись реально нанесённого урона, отступление/первая помощь,
поселения с конечными запасами и профессиями, перевозки по дорогам, питание,
растения/хищники/индивидуальные иждивенцы, NPC-объединения и проверяемые поручения.
Поручения резервируют настоящую награду, требуют реальной добычи после принятия,
переносят сданный материал в запасы и не выдаются повторно; есть отмена/истечение.
Добавлены реальные кнопки этих действий, параметры поступают в тот же Session.

Все текущие результаты в docs/validation/final-campaign-2026-10-28 относятся к
разработке. Не выдавать попытки с ограничением числа противников или ошибки
контроллера за успешную полную кампанию. Ранние тесты:147passed, затем19passed,
поручения/Qt22passed.3360контрактов: первый запуск2960passed/400failed, затем
события388passed/12failed; исправлены предусловия/проверка instanceID, все400
