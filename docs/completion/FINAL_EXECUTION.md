## Реальные изменения

Единый четырёхшаговый конструктор сохраняет имя, класс, набор, характеристики,
талант и свободную историю. Выбора версии приключения, импорта ZIP и покупки
отдельных навыков в обычном интерфейсе нет. Шесть классов используют настоящие
способности, требования, HP/ST/MP и развитие до20.

Каталог3 связан с Session, Qt, физической экипировкой, многосторонним боем,
магией, ремеслом и торговлей. Атаки учитывают классовую характеристику,
боеприпасы, прочность и фактически нанесённый урон; промах не накладывает
вторичный эффект. Лечение и первая помощь меняют реальные HP. Отступление
требует ST и доступного соседнего пути, сохраняет оставшихся противников.
Ремесло списывает материалы конкретного результата, использует инструменты
и время. Покупка сохраняет физические свойства того же предмета.

Поручения резервируют настоящую награду в кошельке NPC, проверяют добычу после
принятия и фактическую сдачу. Повторная выплата запрещена, отмена/истечение
возвращают резерв. Вступление и взносы фракциям перечисляют настоящие деньги.

Мир использует конечные запасы воды, почвы, растений, добычи и пищи. Работа,
переработка и перевозки имеют материальные входы и причинный журнал. Закрытая
дорога задерживает груз; миграция использует известные NPC пути. Семьи,
индивидуальные иждивенцы, старение и голод имеют проверяемые последствия.

Последнее исправление `world_policy4` подключает существующий физический
инструмент NPC к производству: тот же ID, прочность, качество, владелец и
местоположение, без второго комплекта. Удалённый инструмент недоступен.
Назначенная профессия не разрешает ребёнку взрослую работу. Генератор мира
получает контракт реально поддерживаемых профессий и инструментов.

Список сохранений читает ограниченный заголовок без многократного replay.
Настоящая загрузка полностью проверяет историю в QThread с индикатором:
окно продолжает обрабатывать события. Формат сохранения не ослаблен.

Мастер автоматически ищет по19000подготовленным справочным карточкам;
ещё200старых ID — алиасы. SQLite/FTS поставляется с программой. В запрос
попадает ограниченная релевантная справка, а не весь архив одновременно.
Справка не становится фактом кампании и не заменяет программную механику.

Изменены `unified_session.py`, `domain/catalog_engine.py`,
`catalog_revision3.py`, `catalog_identity.py`, `npc_inventory.py`,
`society.py`, `contracts.py`, `field_actions.py`, обработчики каталога,
`narrative/master.py`, `gameplay_prompt.py`, `payment_guard.py`, `ollama.py`,
интерфейс героя/мира, `ui/save_loading.py`, `ui/adventure_panel.py`, `storage/slots.py`,
`storage/update_probe.py`, бюджетный guard, training capture, сценарии
репетиций и Windows workflow. Все действия проходят игровой валидатор.

## Открытые ограничения

Для настоящих обученных весов нужны оборудование, базовая модель, допуск
данных и фактическое обучение. Слепая оценка, литературное ревью каталога
и ручная Windows-приёмка требуют участников. Конечная homebrew-модель мира
не объявляется полной симуляцией произвольных профессий/экосистем.
Независимый баланс всех вариантов контента не подтверждён.

Обычный git push потерял авторизацию. После явного разрешения владельца
четыре согласованных файла и исправление опубликованы через GitHub API
обычным fast-forward, без force. Коммитe3c536f содержит тот же runtime, что
проверенный локальный8cf1228; отличаются только пять дополнительных сырых
логов, оставленных локально после отказа автоматической проверки публикации.
Исходный8cf1228 сохранён в локальной recovery-ветке, данные не потеряны.
