## Что доступно сейчас

В «Раздел» появились **Память мира** и **Рассказчик**. Остальные разделы и три
ячейки остались. Бой/развитие/цены не изменены, новых зависимостей нет.

«Память мира» показывает известные игроку последствия: перемещение, поручение,
расход/получение вещей, лечение, отношение персонажей, развитие и ранения.
Обычный осмотр не создаёт выдуманных изменений. Отображаются последние 100 событий
с видимыми изменениями; в ячейке сохранены все новые действия, включая без изменений.
Это пока **не частные знания/убеждения каждого NPC** и не ConflictSolver.

Рассказчик получает состояние текущей сцены, свои ресурсы героя, видимых участников,
подтверждённый исход и до шести кратких записей памяти. Ему не передаются внутренний
кошелёк торговца, сырые поля мира, точные HP врага, генератор/seed игры и история
чужих недоступных мест. Предыдущее сочинение модели не становится источником фактов.
Ассортимент может упоминаться в подтверждённой реплике после подхода к торговцу.

Локальный ИИ **дополняет** исход художественным текстом. Его ответ имеет схему
`{"narration": "..."}`; числа и команды изменения мира не принимаются. Текст
модели может ошибаться по смыслу: автоматическая проверка истинности каждой фразы
ещё не реализована. Источник игровых последствий — подтверждённый исход движка.
ИИ не создаёт мобов/предметы/квесты и не распознаёт произвольное действие вместо
существующего парсера. План этих систем — CONTENT_GENERATION_PLAN.md.

## Как пользоваться без Ollama

По умолчанию режим выключен, при каждом запуске выбран автономный рассказчик.
Модель не запускается при старте/загрузке игры, просмотре памяти или сохранении.
Все прежние команды работают. Можно проверить новый журнал и контекст сцены.

Кнопка «Найти установленные модели» делает только запрос к локальной Ollama.
Если программы нет, появится понятный отказ; игра не блокируется. Эта кнопка
не скачивает программу/модели, не открывает регистрацию и не вызывает платный API.
Пока Ollama не установлена, оставьте автономный режим.

## Подключение уже установленной модели

Эти шаги предназначены только для случая, когда пользователь отдельно установил
Ollama и заранее скачал подходящую модель после согласования объёма/лицензии.
Команды установки и скачивания этим этапом не выполнялись.

1. Запустить Ollama на Windows. Стандартный локальный адрес — 127.0.0.1:11434.
2. В игре открыть «Рассказчик», нажать «Найти установленные модели».
3. Включить локальный режим и выбрать модель. Облачные ссылки, нулевые/отсутствующие
   локальные файлы и объявленные удалённые модели в список не включаются.
4. Нажать «Рассказать текущую сцену». Ожидание можно отменить; окно продолжает
   принимать действия. Новое действие/новая сессия/загрузка отменяют устаревший запрос.
5. При желании оставить «Дополнять новые игровые действия автоматически».
   Запрос происходит только при включённом локальном режиме и выбранной модели;
   простой учебный бросок и неизвестная команда не запускают модель.
6. Успешное дополнение появляется с подписью «ИИ-рассказчик · модель».
   Для одной текущей сцены хранится одно дополнение. Сохранить игровую ячейку.
7. Перезапустить и загрузить: прежний текст восстановится без нового запроса.
   Для новых запросов локальный режим нужно снова включить.

## Ограничения подключения

- QtNetwork уже входит в установленный PySide6 Essentials. HTTP-клиент асинхронный,
  обращается только к фиксированному loopback-адресу, без системного HTTP-прокси.
  Переадресации не выполняются. В интерфейсе нельзя указать внешний endpoint.
- Только `/api/tags` и `/api/chat`, без `/api/pull`, установки/удаления или shell.
- Поиск установленных моделей: до 2 секунд; генерация текста: до 90 секунд.
  Размер ответа до 64 КиБ, текст до 1500 символов.
  JSON со сторонними полями отклоняется. Никакие полученные команды не исполняются.
- Запрос: контекст 4096, до 400 выходных токенов, thinking выключен,
  CPU (`num_gpu=0`), четыре потока, `keep_alive=0` для освобождения модели после ответа.
  Это начальные ограничения, **не измеренная гарантия скорости/RAM** на i5.
- Ошибка/тайм-аут/отмена оставляют обычный рассказ и результаты в журнале;
  никакого перехода на облачный или платный сервис. Обычного автосохранения нет.
- Качество русской прозы, соблюдение смысловых инструкций, подходящая лицензия
  конкретной модели, скорость/RAM и полноценный офлайн-запуск реальной LLM пока
  не проверены. Для этого следующий отдельный этап на целевом ноутбуке.

## Сохранения и источник истины

Writer JSON **v7**, reader **v1–v7**. Добавлены `memory` и `narrations`.
В памяти — исходный снимок и цепочка разностей с номерами действий/бросков и SHA-256
состояний. При чтении сверяются поля/типы, последовательность, старые значения,
отпечатки и конечное состояние. Формулы и RNG по-прежнему проверяются прежними
боевыми/числовыми записями. Память не применяется второй раз при загрузке.

Для v1–v6 исходная точка — фактически сохранённое состояние; подробная память
начинается со следующего действия. Старые команды не выполняются задним числом,
байты файла не меняются при загрузке. Новая версия записывается при сохранении.

Разности подтверждают последовательность снимков, но не доказывают допустимость
всех исторических действий при согласованной ручной подделке файла. Полный
world replay, частные знания NPC и защита от всех изменений файла не заявляются.
Прямое изменение `session.world` после начала сессии обходит протокол и теперь
отклоняется при следующем действии. Тестовые начальные состояния задаются конструктором.

Тексты ИИ сохраняются отдельно от Turn/событий: номер действия, имя модели,
версия промпта, отпечаток контекста и текст. Они не добавляют RNG, опыт или события.
Для текущей сцены отпечаток также сверяется при чтении; для прошлых дополнений
проверяются структура/порядок, без реконструкции всех старых промптов.
Это **не готовый научный протокол**: для A/B ещё нужны точный digest весов модели,
параметры/входы, отдельные run_id и сырые измерения. Одна метка модели их не заменяет.
При изменении формата контекста нужна совместимость старых сохранённых дополнений.

Лимиты 3 ячейки / 4 МиБ / 2000 действий прежние. Новые записи занимают место.
Перед пересохранением важной старой сессии сделайте копию папки saves. Старое
приложение не откроет v7 — для отката нужна старая копия.

## Проверка Windows без нейросети

1. Закрыть игру с сохранением, скопировать `D:\Projects\DND-NCFU-data\saves`.
   Обновить проект, выполнить scripts/check.py и запустить по README.
2. Новая сессия: взять поручение → идти на рынок → доставить корзину → подойти
   к торговцу → купить бинт. В «Память мира» видны причины изменений, без кошелька NPC.
3. Поссориться с торговцем в отдельной пробной сессии: в памяти отношение меняется,
   торговля закрыта; старые последствия сохраняются после загрузки.
4. В «Рассказчик» видно текущее место, свои ресурсы и доступные факты.
   При отсутствии Ollama кнопка поиска выдаёт отказ, после него можно продолжать игру.
5. Загрузить копию старой ячейки: старые числа прежние, новые события начинают
   память с момента обновления. Перезапустить, проверить новый формат на пробной ячейке.
6. Проверить обе темы, большой шрифт и свой масштаб Windows.

Сетевые автотесты обращаются к собственному временному HTTP-серверу на 127.0.0.1:
это проверка подключения/отказов, а не проверка настоящей модели. Процессный тест
сохраняет синтетическое дополнение и проверяет восстановление в другом процессе.
