# Внедрение материалов v3 от 25.10.2026

Исходный документ владельца: [source.docx](source.docx). Внутри находятся
технические предложения и три исторических несовместимых приложения, а не
единственный готовый набор правил. Приоритет для дальнейшей реализации —
совместимый вариант части II: текущие атрибуты 8–16 при создании, бюджет 24,
модификатор `(score−10)//2`. Значения 60 и шкала 3–10 не импортируются в героя.
Идентификатор нового ruleset пока не присваивается старым сохранениям:
это ошибочно означало бы, что новые правила уже исполняются.

Дополнение владельца: [пошаговый план](step-plan.docx), SHA256
`ac7d3d58cca2a827b3ac69513525d5bc282bfa85fea3e2b1def5bd199f766978`.

## Что действительно работает в этом обновлении

- Присланный master_system_prompt_v3 заменяет стандартную инструкцию целиком.
  Файл проверен существующим загрузчиком (UTF-8, размер, управляющие символы).
  Личный .local.txt по-прежнему имеет приоритет; не перезаписывается автоматически.
- Три отдельные темы журнала: тёмное фэнтези, древний пергамент, магический обсидиан.
  Стандарт — тёмное фэнтези с фоном #171A21 и повествованием #E8DFC9.
- Все девять цветов меняются в настройках и сохраняются в reading.json отдельно
  от кампании. Старый reading.json поддерживается. Есть предпросмотр и сброс.
  Размер шрифта и жирность продолжают действовать. Пользователь может выбрать
  собственный низкоконтрастный цвет; восстановить читаемость можно сбросом.
- Речь NPC сохраняет свой цвет, враждебность — цвет опасности; заголовки мест
  и блоков отделяются акцентом. Подпись игрока не может подделать роль NPC.
  HTML не исполняется, журнал остаётся QPlainTextEdit.
- Общий API DiceRoller.roll: d4/d6/d8/d10/d12/d20/d100, до 100 кубиков,
  модификатор, отдельные результаты, сумма, причина и счётчик RNG.
  Ошибочное выражение не расходует случайные числа. eval не используется.
- В боковой панели доступны пробные броски NdM±K. Они намеренно изолированы
  от кампании, не назначают попаданий/добычи, не сохраняются как игровой исход.
  Прежний D20 остаётся воспроизводимым; новый API совместим с checkpoint/restore.

Настройки цветов «успех», «важное», «подписи» доступны в предпросмотре и API
ролей. Не каждое старое сообщение имеет такую семантическую метку: модельный
текст не превращается в подтверждённый успех только из-за слова «успех».

## Подключённый игровой прототип (следующее обновление)

В схеме24 для новых кампаний доступно «Приключение v3»: экземпляры экипировки,
дуэльный бой через общий resolver, шесть заклинаний I–II/MP/таланты, два рецепта,
ремонт, медный рынок, часы и малые расписания NPC. Команды доступны в Qt/Session,
записываются в Turn и воспроизводятся при загрузке JSON/SQLite.
Подробные правила, ручная проверка и ограничения:
[GAMEPLAY_V3_PLAYABLE.md](../../GAMEPLAY_V3_PLAYABLE.md).
Это не завершение всех этапов DOCX. Старые кампании остаются на прежних правилах.

## Схема25: следующий физический срез

Новые opt-in кампании используют25: реальные физические товары/медные, поддержанные

Текущая инструкция и остаток: [GAMEPLAY_V3_PHYSICAL.md](../../GAMEPLAY_V3_PHYSICAL.md).

| Подсистема | Что ещё необходимо |
| --- | --- |
| Версия правил / миграции | Схема24/версии введены; мигрированная копия, backup и rollback ещё открыты |
| Конструктор героя | Пять описательных видов, шесть специализаций, исходные пресеты; полные расовые/классовые механики ещё нужны |
| Развитие 1–20 | Применение наград есть; HP/ST и шесть талантов подключены в25; баланс поздней игры ещё нужен |
| Навыки | Реальные проверки, начальный черновик и сохранения23/24; миграции старых кампаний нет |
| Бой | Дуэль и смена экипировки работают; много участников, состояния, боеприпасы и лут ещё нужны |
| Магия | Малый набор I–II подключён; другие школы/круги/эффекты ещё нужны |
| Ремесло / ремонт | Два рецепта и полевой ремонт работают; расширение станций/качества ещё нужно |
| Экономика | В25 физические товары также считаются в меди; региональная экономика ещё открыта |
| Мир / NPC | Часы/расписания/передача слуха и прототип общины; полные знания/фракции ещё нужны |
| Длинная кампания | Лимиты 2000 ходов/32 МиБ сохранены до отдельной проверки размера и загрузки |
| Исследование | Сравнительный эксперимент не выполнен; интеграционные тесты его не заменяют |

Указанные возможности нельзя получить только изменением системного промпта.
Согласованные числа и точная граница готовности навыков: [D20_SKILLS.md](../../D20_SKILLS.md).
Движок пока отклоняет неподдержанные эффекты. Данные истории «Аэльтары» не
включаются автоматически в каждую кампанию. Старые предметы, XP, HP и расходы
хоста не пересчитываются этим обновлением.

## Сборка на Windows

В `D:\Projects\DND-NCFU` выполните `git pull --ff-only`, затем
`Команды\BUILD_EXE.bat` для личного EXE или `Команды\BUILD_SETUP.bat`
для общего Setup при работающем хосте. Оба пути включают новые исходники
и стандартный промпт через существующий сборщик. Ключи/пароли не добавлялись.
Пробные кубики и цвета не требуют новой активации или сброса бюджета.
Готовый Windows Setup в Linux-среде этой задачи не собирался.
