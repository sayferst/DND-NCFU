# Чат с локальным ИИ — этап 1J

Пользователь хочет обычную речь и художественные ответы вместо технических
«Мир: Корзина доставлена» / «Мир: Вы пришли». Теперь в явно включённом режиме
ИИ интерпретирует ввод, движок проверяет действие, ИИ формулирует фактический исход.
Никаких новых моделей, зависимостей и облачных сервисов не требуется.

## Как включить

1. Закрыть игру, обновить локальные файлы, выполнить scripts/check.py.
2. Оставить Ollama запущенной. В игре открыть «Рассказчик», найти модели,
   выбрать qwen3:1.7b, включить локальный режим и флажок
   «Понимать свободный текст через ИИ и отвечать в чате» (сам флажок по умолчанию включён).
3. Писать в основной чат обычным языком. Например:
   - «Спрашиваю жительницу, нужна ли ей помощь»;
   - «Я согласен доставить вашу корзину»;
   - «Выхожу из деревни на дорогу»;
   - «Передаю корзину получателю» — когда герой действительно на рынке с поручением.
4. Для неоднозначных/неподдерживаемых намерений ожидается уточнение. Проверить
   «Привет» у ворот без адресата и действие, которого ещё нет в движке.
5. Ответ NPC имеет подпись «Жительница · ИИ», повествование — «ИИ-рассказчик · модель».
   Успешный художественный ответ заменяет строку движка; числовой исход/разбор
   видны справа, исходный результат остаётся в истории. Повторного ответа «Мир» нет.
6. Сохранить в свободную ячейку, перезапустить, загрузить: исходные слова, намерение,
   результат и проза сохраняются; загрузка не запрашивает ИИ.

Чат отвечает даже при выключенном флажке повествования после быстрых кнопок.
Кнопки выполняют известное действие напрямую; этот второй флажок управляет
последующим рассказом для них. Без локального режима работают прежние команды.

## Что происходит внутри

Первый запрос возвращает только JSON с одним полем command: действие из перечисленных механик,
беседу с одним из трёх NPC или уточнение. Неподдерживаемая команда/лишние поля/
смешанный результат отклоняются до исполнения. Предложение модели проверяет движок:
место, ресурсы, бой, отношение, поручение и другие прежние ограничения.
Нейтральная атака/провокация дополнительно подтверждается в игре.

При беседе в основу ответа передаются текущая реплика, доступные сведения о NPC,
состояние поручения и подтверждённый результат. Модель не получает чужой кошелёк,
точные HP, seed или доступ к файлам. Текст игрока — данные, а не код для исполнения.
Цели/личные убеждения NPC, свободное создание мира, новые предметы/мобы/боссы ещё
не реализованы. ИИ может обсуждать окружение, но не вводит новую механику словами.

После действия второй запрос пишет выразительную прозу по уже вычисленному исходу.
Это может быть медленнее прежнего одного запроса: каждый ограничен 90 секундами;
на целевом ноутбуке нужно измерить общее ожидание. Уточнение в новом однопольном контракте тоже использует второй запрос для вопроса.
Внутренние команды нужны движку, игроку не требуется воспроизводить их дословно.
Точность понимания каждого русского предложения не гарантируется малой моделью.

## Отказ и отмена

Пока ИИ разбирает сообщение, мир не меняется. При ошибке/отмене текст возвращается
в поле, его можно уточнить. При смене сцены/сессии поздний ответ не применяется.
После исполнения ход не откатывается и не повторяется из-за ошибки художественного
текста: показывается обычный исход. Отмена второй стадии возвращает этот исход
в чат; действие остаётся в истории. В отсутствие модели доступен автономный резерв.

Промпт narrator-prose-3 требует русский язык, образность и запрет решать за игрока.
Фильтр отклоняет чужие буквы и некоторые сочетания вроде «путник подходит»,
«вы решаете», «герой атакует». Это частичная эвристика: возможны ложные отказы
(включая латинские имена) и пропуск перефразированной выдумки. Семантическая
истинность каждого предложения автоматически не доказана. Нет скрытых повторов.
Старые сохранённые тексты narrator-prose-1/2 не исправляются и читаются как прежде.

## Сохранения и проверка

JSON writer v8, reader v1–v8. Turn.action хранит исходные слова, Turn.intent —
распознанное проверенное действие, расчёты/рост/чтение боя учитывают intent.
Старые ходы получают intent=None, не переигрываются. Загрузка не переписывает файл.
Перед сохранением важных ячеек новой версией скопировать папку saves для отката.
Старое приложение v7 не читает новые ячейки v8.
Fixture save-v7.json создан архивированным кодом 2f2f0cb, а не вручную новой схемой.

Автотесты используют временный loopback HTTP-сервер/Qt offscreen. Они проверяют
протокол, обычный ввод, отсутствие дублирования, сохранения, отмену, поздний ответ,
отказы, подтверждение провокации и однократную награду при сбое второй стадии.
Новый промпт на настоящей Qwen3 и ручной Windows-сценарий ещё не проверены.
Пришлите диалог и примерное время ответа; это поможет оценить следующий шаг.

При общем отказе проверки используйте флажок «Показать последний технический
ответ ИИ» в «Рассказчик»: видно, не прошёл ли разбор намерения, формат прозы или
ответ оборвался по лимиту. Подробности не сохраняются в файлы. Инструкции/контекст
и дообучение — разные вещи: см. LOCAL_AI_IMPROVEMENT_PLAN.md.
