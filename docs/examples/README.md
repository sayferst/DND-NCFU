# Готовые описания для тестовой игры

Если не хочется писать биографию и пожелания к миру, возьмите одну из шести пар.
Это собственные вымышленные примеры: в них нет данных реальных игроков.
Каждый TXT содержит только текст нужного поля, без заголовков для удаления.

## Как использовать

1. В конструкторе задайте имя и выберите класс из таблицы.
2. Примените рекомендованные характеристики и выберите начальный талант.
3. На шаге **«История и мир»** скопируйте весь текст файла **«Герой»**
   в поле **«Описание персонажа»**.
4. Текст парного файла **«Мир»** вставьте в поле **«Пожелания к миру»**.
5. Проверьте итог, создайте героя и дождитесь начала кампании.

На GitHub откройте TXT и используйте кнопку **Raw**, чтобы скопировать чистый
текст, либо скачайте файл. Импортировать ZIP или TXT в игру не требуется.
Имя и класс из таблицы выбираются отдельно: биография не меняет выбор конструктора.
Любой пример можно сократить, изменить или сочетать с другим пожеланием к миру.

## Первые сообщения мастеру

После создания мира можно отправить по одному:

> Осматриваюсь. Какие люди, места и доступные пути я вижу рядом?

> Хочу поговорить с ближайшим доступным жителем. Что я могу о нём узнать?

> Какие небольшие поручения здесь доступны и у кого можно уточнить условия?

Для магии откройте героя и проверьте известные заклинания; для ремесла — рецепты,
материалы и требования к рабочему месту. Подробности: [гайд игрока](../player-guide.md).

## Что ожидать от примера

Это стартовые пожелания для рассказчика, а не готовые сохранения или гарантированная
сцена. Генерация может создать другой район, имена и зацепки. Указание кузницы,
наставника или обсерватории не гарантирует их появления в конкретной стартовой сцене.
Описание не выдаёт предметы, деньги, рецепты, заклинания или преимущества.
Получение мира использует обычный игровой запрос к мастеру и расходует допуск
по правилам вашего профиля. Открытие этих TXT на GitHub ничего не генерирует.
