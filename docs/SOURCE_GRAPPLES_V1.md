# Захват при попадании

База хранит source_grapple_v1: индекс атаки, DC освобождения, число удерживаемых
целей, предельный размер, досягаемость, опутывание, преимущество по удерживаемой
цели и блокировку атак против других целей. Отдельный Python-обработчик исполняет
эти условия после фактического попадания, даже если сопротивление обнулило урон.
Иммунитет к захвату проверяется до применения. Неизвестные дополнительные
предложения не отбрасываются: такие атаки остаются неподдержанными.

Состояние содержит устойчивые связи source/target/attack_index. Они сохраняются
в Session и SQLite, не зависят от таймера произвольного состояния. Захват
прекращается при недееспособности захватчика, смерти, исчезновении источника
или выходе за досягаемость. Взятие нескольких целей ограничено числом конечностей.
NPC может освободить занятые конечности перед новой атакой; NPC, который не
достаёт противника из-за захвата, пытается освободиться проверкой характеристики.
Для исходных NPC используются явно извлечённые бонусы Атлетики/Акробатики.

Мастер получает source_grapples и может предложить source_escape:
`{source:ID, ability:strength|dexterity, attack_index:число}`. Необязательная
`position:[x,y,z]` задаёт движение после успешного освобождения в тот же ход.
Бросок и результат вычисляет движок. Если остаётся другой захват, движение
блокируется. Перетаскивание перемещает удерживаемую цель вместе с захватчиком
и уменьшает скорость по правилу размеров. Обычные переходы захваченного NPC
блокируются; внутреннее принудительное перемещение разрешается отдельно.

Для новых программ мастер видит геометрию участников боя без невидимых целей;
контекст читается без изменения мира. Начальные координаты старых сцен явно
отмечены homebrew. Если исходник не указал предельный размер, используется
отдельно отмеченная адаптация NCFU: не более одной категории крупнее источника.
Старые Definition и миры без новых связей не получают захват задним числом.

Миграция009 добавляет ревизии схем и реестр обработчика; SQL001–008 не меняются.
`enrich_source_grapples.py` сверяет закреплённые источники, извлекает программу,
пересобирает связанные боевые программы и проверяет все ссылки до замены файла.
Исходная проза не распространяется. Сейчас полностью разобраны12атак; периодический
урон, проглатывание и другие неразобранные условия остаются отдельной работой.
