# Общий Setup с двумя учётными записями

Выбран один установщик для всех: `dist\Release\setup.exe`.
При запуске EXE открывается вход admin/tester. Кнопка главного меню
«Проверить сопряжение» проверяет /health без генерации.

Первичная настройка на ПК владельца при остановленном хосте:

1. `Команды\CHANGE_ADMIN_API.bat`: ввести ключ admin.
2. `Команды\CHANGE_TESTER_API.bat`: ввести отдельный ключ tester.
3. `Команды\SETUP_ACCOUNTS.bat`: задать выбранные пароли admin и tester,
   каждый дважды. Ключи повторно вводить не нужно.
4. `Команды\START_HOST.bat`: дождаться готовности.
5. `Команды\BUILD_SETUP.bat`: собрать общий Setup.

Бюджеты: admin 500 ₽, tester 100 ₽, общие для текста и изображений каждой
учётной записи. Это денежные бюджеты, а не фиксированное число токенов.
Вместе с историей старых допусков действует общий предел 600 ₽ на хосте.
Срок каждой учётной записи 30 дней от первой настройки. Смена ключа/пароля,
вход или пересборка не сбрасывают расходы и не продлевают срок.
Продление: `scripts\tester_host.cmd extend account_tester --days 30`;
отзыв: `scripts\tester_host.cmd revoke account_tester`. Для admin имя account_admin.

Пароль хэшируется на сервере PBKDF2 с отдельной солью, ключи защищаются DPAPI.
Пароли/API-ключи не включаются в EXE, Setup или исходники. Пароль передаётся
только проверенному HTTPS-хосту. После пяти неправильных попыток вход блокируется
на минуту. Пароли нельзя восстановить из клиента, но короткие пароли допускают
подбор; это не гарантия абсолютной защиты. Пароль нужно передать игроку лично.

Без запущенного хоста вход и облачная генерация не работают. Игроку не нужны
Python/ngrok. Консоль разработчика в этой сборке доступна только роли admin;
само изменение клиентских файлов не меняет серверные права или бюджеты.
Сессия действует максимум сутки; при новом запуске пользователь входит заново.
Игровые сохранения остаются локальными и общими на одном ПК, не отдельными
профилями кампаний для каждой учётной записи.

`BUILD_EXE.bat` собирает ту же версию с входом без Inno Setup; каталог результата
`dist\Accounts-НОМЕР\DND-NCFU.exe`. Нужна вся папка Accounts, не один EXE.
После успешной сборки промежуточная папка dist\DND-NCFU перемещается в Accounts.
Старые Personal/Tester сборки не удаляются и не превращаются в новый выпуск.
`UPDATE_AND_BUILD_SETUP.bat` и `BUILD_TESTER_SETUP.bat` теперь также собирают
единый Setup, дополнительных вариантов с вшитыми ключами не создают.
