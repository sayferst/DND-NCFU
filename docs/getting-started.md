# Установка и первый запуск

Скачайте setup.exe и setup.exe.sha256 из опубликованного GitHub Release.
Сверьте хэш: `Get-FileHash .\setup.exe -Algorithm SHA256`.
Установите игру и запустите её. Python, Git и ngrok игроку устанавливать не нужно.

В окне входа укажите admin или tester и пароль, лично полученный у владельца.
Установщик один для обеих ролей. Ключи и бюджеты выбирает сервер;
кнопка активации теста не нужна. На главном экране «Проверить сопряжение»
проверяет доступность хоста без генерации и списаний.

Владелец должен оставить ПК и START_HOST.bat работающими.
Пароли и API-ключи не вшиты в EXE. Если вход не проходит, проверьте
логин/пароль и попросите владельца проверить хост.

Сохранения локальны. Переключение учётной записи на одном ПК не изолирует
кампании. Перед обновлением сохраняйте резервную копию данных.

Из исходников доступны привычные инструкции Python 3.12 в README.
Не путайте запуск исходников с публичным установщиком: его профиль и вход
включаются параметрами сборщика.
