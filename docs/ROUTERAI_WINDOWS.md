# RouterAI в игре на Windows

Дата: 19 октября 2026. Это дополнительный облачный режим: сервер RouterAI
генерирует текст, а ваш ПК хранит мир/память/сохранения и рассчитывает действия.
Ollama для него не требуется. Игра по-прежнему запускается и работает офлайн.

Адреса и формат взяты из присланной пользователем документации:
[справочник RouterAI](https://routerai.ru/docs/reference#tag/api-keys/POST/v1/keys).
Прямой доступ из среды агента возвращал CONNECT403. Реальная генерация,
текущие тарифы, биллинг/комиссии и доступ аккаунта ещё не проверены агентом.
Веса, библиотеки, плагины и обучающие корпуса не скачивались.

## 1. Ключ и месячный бюджет

В кабинете RouterAI создайте отдельный обычный API-ключ для игры. В его настройках
проверьте, что лимит указан именно **в рублях**, и задайте **положительный месячный
лимит не выше 2000 ₽**. Если кабинет показывает другую валюту или не указывает
единицу, сначала уточните её у сервиса: число2000 в другой валюте не равно2000₽.
Для первой проверки можно
выбрать меньший лимит, например100₽. Уточните в кабинете, как сервис останавливает
расход на границе лимита и учитывает комиссии; отключите автопополнение, если оно
есть. Приложение само не создаёт ключи и не пополняет баланс.

Ссылка пользователя ведёт к административному API создания ключей. Мастер-ключ
из этого раздела нужен для управления другими ключами через API; для игры нужен
**обычный ограниченный ключ**. Не публикуйте его в Git или чате.

Перед каждой генерацией, включая единственный повтор плохого ответа, игра делает
чтение `GET https://routerai.ru/api/v1/key`. Она требует:

- boolean `disabled=false`;
- положительный `limit` не выше2000;
- корректные `usage_monthly` и положительный остаток; если есть
  `limit_remaining`, берётся меньший из него и `limit - usage_monthly`;
- дневной/недельный лимит не принимается за месячный.

Если API не даёт этих данных, ключ без лимита или остаток исчерпан, запрос модели
не отправляется. Приложение проверяет заявленные сервисом данные, но не заменяет
его биллинг и не гарантирует размер последнего пограничного списания/комиссий.
Самостоятельных операций POST/PATCH/DELETE с ключами в коде нет.

Полный отдельный ответ GET /v1/key не был показан в присланной документации,
а в описании поля disabled есть неоднозначность. Неизвестная схема/статус
останавливает генерацию. Если такая ошибка возникнет на настоящем аккаунте,
нужно сверить сообщение с документацией; ключ и полный ответ аккаунта в чат
отправлять не нужно.

## 2. Обновление файлов на диске D:

Сохраните свою сессию в ячейку и закройте игру. Выполните в PowerShell:

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location D:\Projects\DND-NCFU

    $saveDir = 'D:\Projects\DND-NCFU-data\saves'
    if (Test-Path $saveDir) {
        $backupRoot = 'D:\Projects\DND-NCFU-data\backups'
        New-Item -ItemType Directory -Path $backupRoot -Force | Out-Null
        $backupDir = Join-Path $backupRoot ('before-routerai-' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff'))
        Copy-Item -LiteralPath $saveDir -Destination $backupDir -Recurse
    }

    git switch setup/development-environment
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось переключить ветку.' }
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Обновление не получено. Сохраните текст ошибки.' }
    git restore --source=HEAD --worktree -- tests/fixtures
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось обновить эталоны тестов.' }

    .\.venv\Scripts\python.exe scripts\check.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка не прошла. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\run_game.py
}
```

Новых зависимостей нет. Restore обновляет только эталоны тестов после исправления
Windows LF/CRLF; пользовательские ячейки лежат отдельно в DND-NCFU-data/saves.
Не используйте reset --hard при конфликте с вашими изменениями.

## 3. Подключение через окно игры

1. Откройте раздел **Рассказчик**, включите ИИ-мастера и свободный текст.
2. Выберите **Облако: RouterAI · тарифы в рублях**.
3. Нажмите **Загрузить модели и цены RouterAI**. Это публичный GET без ключа
   и без генерации. Выберите модель из списка.
4. Идентификатор `deepseek/deepseek-chat-v3.1` заранее взят из примера документации.
   Он не считается гарантированно доступным или лучшим по качеству. Если его нет
   в каталоге, выберите другой подходящий ID из полученного списка.
5. Вставьте свой обычный ограниченный ключ в скрытое поле. Разрешите отправку
   сцены в API и нажмите **Применить настройки облачного API**.
6. Вернитесь к игре и отправьте сообщение. Сначала проверяется лимит ключа,
   затем мастер получает уже доступный игре контекст и пишет ответ.

После смены провайдера старый ключ и согласие очищаются. OpenRouter и RouterAI
имеют отдельные ключи. Для RouterAI доступна необязательная переменная
`RPG_VKR_ROUTERAI_API_KEY`; общий `RPG_VKR_LLM_API_KEY` для него не используется.
Ключи не записываются в сохранения, SQLite, конфигурацию чтения или диагностику.
При перезапуске окна ключ нужно ввести снова, если переменная не задана.

В облако уходят сообщение/анкета героя и отобранные сведения текущей сцены,
а не сырая база целиком. Условия обработки и хранения запросов нужно сверить
у RouterAI и выбранного им провайдера. Подписка ChatGPT Plus с этим API не связана.

## Цены и время ответа

Каталог сообщает `pricing` в рублях и `pricing_units` отдельно. Игра показывает
входную/выходную цену **за миллион токенов**, только если единица обоих полей —
`token`. Цена за запрос/изображение/секунду не пересчитывается как токен.
Нетекстовые модели с явно указанным другим выходным форматом скрыты из списка.

Числа306,32₽/млн входа и1531,59₽/млн выхода из присланного JSON — только пример
документации, не проверенный текущий тариф. Ориентируйтесь на свой загруженный
каталог и условия кабинета. Входные токены включают передаваемую историю/контекст;
повтор ответа тоже может оплачиваться. Возможные прочие комиссии здесь не оценены.

Стоимость текста = входные токены × цена входа за токен + выходные токены ×
цена выхода за токен. Счётчики input/output появляются в техническом ответе,
если API их вернул. Приложение не объявляет эту оценку точной суммой списания.
Фактический ID ответившей модели сохраняется как источник новой прозы.

Поля max_tokens/max_completion_tokens передаются только при их наличии в
supported_parameters полученного каталога. Без такого объявления отправляется
минимальный документированный чат-запрос с просьбой короткого ответа. Общий
месячный лимит проверяется в обоих случаях. RouterAI-specific @-маршрутизация,
веб-поиск/инструменты и дополнительные провайдеры автоматически не включаются.

Cloud уменьшает вычисления на вашем ноутбуке, но не гарантирует быстрый или
качественный ответ: сеть, очередь и модель остаются факторами. Проверять надо
на настоящем диалоге. Контракт мастера и проверяемые правила те же, что локально;
дообучение весов этим подключением не выполняется.

## Ошибки и сохранность хода

- 401 — ключ не принят; проверьте, что это именно обычный ключ RouterAI.
- 402 — недостаточно баланса; автоматического пополнения нет.
- 403 — доступ отклонён; проверить доступ аккаунта/сервиса.
- 429 — частые запросы/квота; подождать или выбрать локальный режим.
- Неподтверждённый лимит — привести ключ в соответствие месячному бюджету
  или сверить схему ответа; модель до этого не вызывается.

После ошибки повторные платные запросы по сети не запускаются автоматически.
Одна попытка исправить плохой текст допускается после успешного HTTP-ответа
и заново проверяет остаток. Отмена/смена ключа/провайдера прекращает ожидание.
Перенаправления с ключом не выполняются. Исход боя уже записан движком и
сохраняется независимо от ошибок облака; невыполненная реплика возвращается в ввод.

На машине агента проверен синтетический HTTP и общий pytest, а не настоящий
RouterAI: ключей нет, сайт недоступен из среды. Скорость/русская проза/стоимость
реального запроса и ручная Windows-проверка ожидаются.
