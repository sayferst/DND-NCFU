## Воспроизведение

Из корня с активной Python3.12 `.venv`:

```powershell
.\.venv\Scripts\python.exe scripts\evaluate_response_contract.py --output docs\evals\my-new-run.json
.\.venv\Scripts\python.exe scripts\check.py
```

Для повторения исходных Qt/HTTP probes скопировать `audit.py.source.txt`,
`transport.py.source.txt`, `ui_probe.py.source.txt` в НОВУЮ временную папку
под именами audit.py/transport.py/ui_probe.py; выставить PYTHONPATH на src проекта.
Запуск transport.py и ui_probe.py пишет результаты только рядом с копиями.
Для проверки нового протокола аналогично использовать ui_inline.py.source.txt.
Не запускать их внутри папки исходного эксперимента: сырые файлы неизменяемы.
