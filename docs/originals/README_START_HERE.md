# С чего начать (Windows, без опыта программирования)

1. Создай папку `C:\Projects\RPG_VKR` (путь без пробелов и кириллицы удобен, но не обязателен).
2. Распакуй **всё содержимое этого архива прямо туда**. `MASTER_CODEX_RPG_VKR_ZERO_COST.md` и `AGENTS.md` должны находиться в корне папки.
3. Открой приложение Codex (официальная страница: https://openai.com/codex/) и выбери папку `C:\Projects\RPG_VKR` как проект.
4. Открой `CODEX_FIRST_PROMPT.md` и отправь его текст Codex. Никакие платные модели/ключи/платёжные карты для этапа 0 не нужны.
5. Дальше действуй по командам Codex **маленькими шагами**. Если команда непонятна — спроси «объясни, где нажать и что появится». При ошибке копируй её текст и отправляй Codex.
6. В конце этапа 0 убедись, что хотя бы одно окно запускается и без интернета выдаёт текстовый ответ на действие. Отдельно проверь тесты.

## Что внутри
- `MASTER_CODEX_RPG_VKR_ZERO_COST.md` — **главный документ**, полный план и вопросы для уточнений, обязательный нулевой бюджет.
- `AGENTS.md` — короткие постоянные инструкции для Codex.
- `CODEX_FIRST_PROMPT.md` — первый запрос.
- `TECHNICAL_SPEC_OLDER.md` и `PROJECT_CONTEXT_OLDER.md` — подробные **архивные** документы из прошлой переписки. Они могут содержать прежние идеи, которые теперь ограничены бюджетом 0 ₽; главному документу не противоречить.

## Важно
Пока не скачивай локальную языковую модель. Первое окно, правила и научные вычисления должны работать без неё. Позже отдельным экспериментом проверим маленькую модель на твоём ноутбуке.
