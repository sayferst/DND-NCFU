# Два подключения: Мастер и Художник

С версии 1U раздел «Рассказчик» называется **«Мастер»**.
Для изображений создан отдельный раздел **«Художник»**.
В общих «Настройках» находятся ссылки на эти панели; параметры не смешиваются
с настройками чтения. Старые внутренние вызовы раздела работают через алиас.

## Мастер — текст и приключение

Здесь выбирают сервис и текстовую модель, вводят/сохраняют ключ, разрешают отправку
сцены и подключают мастера. DeepSeek Flash остаётся прежней текстовой моделью;
настройки Художника её не заменяют. Подробности предыдущего исправления:
[CONNECTION_REPAIR.md](CONNECTION_REPAIR.md).

## Художник — изображения

1. Откройте **Раздел → Художник**.
2. Выберите источник ключа:
   - **«Использовать ключ Мастера»** — общий RouterAI-ключ из его поля,
     переменной `RPG_VKR_ROUTERAI_API_KEY` или защищённой записи. Поле Художника
     показывает его с маской и недоступно для редактирования. Ключ OpenAI/OpenRouter
     из другого поля/общей переменной сюда не отправляется.
   - Снимите отметку, чтобы **ввести отдельный ключ Художника**. Этот режим
     не подставляет общий ключ, если отдельное поле пустое.
3. Для отдельного ключа есть **«Сохранить ключ Художника»** и опция запоминания
   при успешной проверке. На Windows применяется DPAPI текущего пользователя;
   ключ не хранится открытым текстом. Ошибка шифрования не заменяет старый файл.
   Отдельный ключ не перезаписывает ключ Мастера. Удаление сохранённого ключа
   Художника удаляет только его локальную запись, не отзывает ключ в кабинете.
4. **«Загрузить модели»** запрашивает публичный каталог без ключа.
   **«Проверить ключ и модели»** проверяет ключ/месячный лимит и каталог.
   Обе кнопки выполняют только GET, не создают текст/картинки и не резервируют деньги.
5. В списке закреплены полные названия двух утверждённых моделей. Их можно найти
   по названию или ID через поиск. До запроса указано «не проверена», затем
   «есть в каталоге» либо «не найдена». Справочные названия не считаются
   доказательством доступности сервиса.

| Название | ID | Назначение |
|---|---|---|
| Recraft V4.1 Flash | recraft/recraft-v4.1-flash | Обычные предметы и материалы, без референсов |
| FLUX 3 Image Klein | black-forest-labs/flux-3-image-klein | NPC, существа, уникальные вещи и сцены; референсы при поддержке API |

Выбор строки в списке показывает её ID, назначение, актуальный распознанный тариф
и возможности. **Распределение генераций между моделями остаётся автоматическим**
по типу объекта и референсам, как в исходном ТЗ. Просмотр строки не заменяет
текстовую модель и не начинает платную генерацию.

Цена не выдумывается при отсутствии подходящих данных. Если API не подтверждает
полный тариф или нужный параметр, причина видна в карточке модели, платного POST
не будет. Каталог публичный: наличие ID не доказывает обслуживание конкретного
запроса провайдером или персональные разрешения ключа.

## Бюджет и качество находятся у Художника

Разверните **«Бюджет, разрешения и качество»**. Здесь разрешение передачи публичных
описаний/референсов, месячный бюджет изображений, пороги Recraft/FLUX, разрешение
портретов/сцен, подтверждение запроса, учтённые расходы, очередь и история.
Сохраните выбранные параметры. Начальное значение бюджета новой установки 0 ₽
не означает бесплатный проект: это отсутствие заранее выданного разрешения расхода.
Прежние сохранённые настройки бюджета читаются без сброса.

Предел Recraft — до 0,85 ₽, FLUX — до 5 ₽, одна картинка на запрос,
автогенерация и автоматический повтор платного запроса отсутствуют. Прежние
референсы, кэш, версии и привязки ID сохраняются. Изменение ключа отменяет очередь
и неотправленную генерацию; уже принятый сервером POST может быть оплачен,
его результат сохраняется без повтора. Отмена бесплатной проверки только
игнорирует её поздний ответ, не отменяет платные операции.

Изображение создаётся прежними кнопками «Изобразить сцену»/«Создать изображение»
в приключении и Хрониках либо явной текстовой просьбой. Открытие Художника,
изменение ключа, загрузка каталога и просмотр строки модели его не создают.

## Файлы и совместимость

В папке данных:

- `routerai-credential.bin` — общий/Мастер, прежний файл;
- `artist-credential.bin` — отдельный Художник, Windows DPAPI;
- `visuals/connection.json` — только источник ключа, запоминание и выбранная
  строка модели; ключа в JSON нет;
- `visuals/settings.json`, `visuals/visuals.sqlite3`, `visuals/assets` — прежние
  бюджеты, расходы, версии и файлы образов.

На Linux нет открытого fallback хранения ключей. Подписанные имена моделей
видны без подключения, но тарифы и наличие до запроса не считаются проверенными.
Для переноса всех кампаний/образов копируйте всю папку данных. DPAPI привязан
к пользователю Windows; на другом компьютере ключ нужно указать заново.
Схема сохранений/правила/RNG и стандартный промпт этим пакетом не изменяются.

## Обновление папки на D:

Закройте игру. Нужны прежние зависимости, новых библиотек нет.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location 'D:\Projects\DND-NCFU'
    $gameData = if ($env:RPG_VKR_DATA_DIR) { $env:RPG_VKR_DATA_DIR } else { 'D:\Projects\DND-NCFU-data' }
    $backup = Join-Path 'D:\Projects\DND-NCFU-backups' (Get-Date -Format 'yyyyMMdd-HHmmss-fff')
    New-Item -ItemType Directory -Path $backup | Out-Null
    if (Test-Path -LiteralPath $gameData) {
        Copy-Item -LiteralPath $gameData -Destination (Join-Path $backup 'game-data') -Recurse
    }
    if (Test-Path 'prompts\master_system_prompt.local.txt') {
        Copy-Item 'prompts\master_system_prompt.local.txt' -Destination $backup
    }
    git switch setup/development-environment
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось выбрать ветку.' }
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Файлы не обновлены. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\repair_fixture_checkout.py
    if ($LASTEXITCODE -ne 0) { throw 'Ошибка тестового файла.' }
    .\.venv\Scripts\python.exe scripts\check.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка не прошла. Сохраните вывод.' }
    $env:RPG_VKR_DATA_DIR = $gameData
    .\.venv\Scripts\python.exe scripts\run_game.py
}
```

После обновления проверьте два пункта в списке разделов, сохранение ключа,
обе строки моделей, поиск и отдельные бюджеты. Подключение на вашем ПК,
настоящие картинки/списания и нативный Windows DPAPI здесь не проверялись.
Платные запросы Codex не выполнял. Живой контракт Images API требует сверки,
описанной в [IMAGES_API_CONTRACT.md](IMAGES_API_CONTRACT.md).
