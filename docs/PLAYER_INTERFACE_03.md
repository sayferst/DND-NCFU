# Интерфейс закрытого тестирования 0.3.0

Обычный режим открывается при запуске. Видимые вкладки: Приключение, Герой,
Инвентарь, Дневник, Карта, Энциклопедия, Фотоальбом, Сохранения, Настройки, Меню.
В небольшом окне строка прокручивается стрелками Qt, доступна с клавиатуры.
Старые имена «Хроники мира»/«Каталог мира» остаются внутренними совместимыми
переходами к энциклопедии. Экраны не пересоздаются при переключении: черновик,
прокрутка, выбор объекта и запросы сохраняются. Навигация не обращается к моделям.

Создание легенды: анкета → «Создать героя» → центральная «Создать новый мир» →
фэнтезийная загрузка → проверка/сохранение мира → «Мир создан» → история в журнале.
Лимит мира остаётся 65536 токенов/15 минут/2 МиБ. Ошибка/отмена сохраняет анкету;
учебная деревня автоматически не подставляется. Картинка доступна для готового мира.

Кнопка «⚙ Разработчик» — внизу главного меню. Начальный локальный пароль 995539.
После пяти ошибок действует задержка 30 секунд, даже если закрыть и открыть диалог.
Доступ сохраняется только до выхода/перезапуска. Есть смена пароля (8–128 символов).
В файле вне установки только соль и PBKDF2-HMAC-SHA256; открытый пароль не хранится.
Повреждённый файл проверки не возвращает заводской пароль автоматически.
Локальный доступ легко обойти при анализе программы; это защита интерфейса от
случайного доступа, а не защита общего RouterAI-аккаунта.

Консоль объединяет прежние формы ИИ-мастера/ИИ-художника, подключения, бюджет,
диагностику и инструкции по управлению тестированием. Они перенесены, не созданы
заново: у владельца остаются выбранная модель, DPAPI, цены 5/10 ₽, бюджет и кэш.
Закрытые страницы проверяют доступ в обработчике перехода. Прямой выбор страницы
консоли без входа возвращает игровой экран. Обычные настройки содержат чтение,
тему, F11 и эффекты; API-ключей/моделей там нет. У Tester Build прямые формы
провайдеров отключены даже после локального входа.

Энциклопедия мира использует единственную прежнюю knowledge_entries-проекцию.
Горизонтальные категории появляются только при наличии знаний; есть поиск,
фильтры слухов/близости/частичной информации, сортировка. Сетка показывает кэш
или собственные тематические заглушки. Клик/Enter открывает подробности в том же
экране, «Вернуться» возвращает к выбору. Описания/полезные сведения/наблюдения
остаются публичными. Связь с картой и действия создания/просмотра/перегенерации
сохранены. Чужие мотивы, private_plot и неизвестные характеристики не добавляются.
Миниатюры обновляются после сохранения изображения; повторные статусы не читают
все PNG заново. Локальный кэш миниатюр ограничен 512 изображениями.

Фотоальбом — самостоятельная сетка над VisualRegistry, без копий файлов и второй
БД знаний. Только текущая campaign identity. Категории, даты, названия, описания,
увеличенный просмотр, предыдущая/следующая, переход к известной записи или журналу.
По умолчанию последняя сохранённая версия; «Показать прошлые версии» раскрывает
предыдущие. Ничего не удаляется, ссылки сюжетных сцен остаются действительными.
Публичные подписи новых работ сохраняются отдельной добавочной таблицей captions
того же реестра. Для старых работ без подписи используются известная запись/дата
и нейтральное название. Модели и технические промпты в альбоме не показываются.
Пустой альбом не запускает генерацию. Изображения создаются только явной командой.

Анимации: общий переход 180 мс (100 мс в уменьшенном режиме), снимок предыдущего
экрана вместо постоянной обработки тяжёлой страницы, короткое золотистое наведение
кнопок и подсветка карточек, появления уведомлений. Клик доступен во время эффекта.
Предыдущая анимация прекращается при новом переключении, обработчики снимаются
при закрытии. Важные ошибки не исчезают по таймеру: пользователь закрывает их сам.
Настройки: Плавные / Уменьшенные / Выключены. Учитывается Windows
SPI_GETCLIENTAREAANIMATION. У невидимого экрана мира таймер остановлен; при
отключённых эффектах фон статичен. Видеофонов и фоновых запросов к художнику нет.

## Обновление на компьютере владельца

Закройте старую игру. При необходимости сделайте копию внешней папки сохранений:
для EXE это обычно `%LOCALAPPDATA%\DND-NCFU`, для Python —
`D:\Projects\DND-NCFU-data`. Не копируйте эти данные в дистрибутив тестировщика.

```powershell
Set-Location D:\Projects\DND-NCFU
$backup = Join-Path $env:USERPROFILE ('DND-backup-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
New-Item -ItemType Directory -Path $backup | Out-Null
foreach ($source in @('D:\Projects\DND-NCFU-data', (Join-Path $env:LOCALAPPDATA 'DND-NCFU'))) {
    if (Test-Path $source) { Copy-Item -LiteralPath $source -Destination $backup -Recurse }
}
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Обновление остановлено.' }
.\scripts\build_windows.cmd
if ($LASTEXITCODE -ne 0) { throw 'Проверьте сообщение сборщика.' }
Start-Process '.\dist\DND-NCFU\DND-NCFU.exe'
```

Это Developer Build владельца с новым игровым интерфейсом. Сборщик сам выполняет
repair_fixture_checkout, scripts/check.py, реальную упаковку, self-check/smoke-test,
создаёт EXE-папку и ZIP/SHA256. Открывается прежнее фэнтезийное меню с небольшой
кнопкой разработчика; в игре вместо «Раздел» видна строка вкладок.

Для Setup установите Inno Setup 6 и используйте существующую команду:

```powershell
.\scripts\build_windows.cmd -Installer
```

Результат на Windows: `dist\DND-NCFU-Setup.exe` и portable ZIP. Переносите всю папку
EXE либо используйте Setup. Профиль Tester, развёртывание, выдача/отзыв кодов и
порядок передачи первому игроку — [TESTER_GATEWAY.md](TESTER_GATEWAY.md).
Зависимостей Python у конечного пользователя нет; у сборщика они устанавливаются
из прежнего requirements-build.lock с хешами. Общие настройки безопасности Windows
менять не требуется. Обновление EXE не происходит само от одного git pull.

## Ручная приёмка на Windows

Проверить 1366×768, 1920×1080 и маленькое окно: меню/пароль/выход/повторный вход,
все вкладки клавиатурой и мышью, черновик/скролл при переключении, новый мир,
карточку с длинными текстами/без картинки, альбом/версии/смену кампании, F11,
отключение эффектов, отсутствие сети, установку/обновление/удаление с сохранением
данных. Перезапуск должен закрывать доступ разработчика. Полный прогон и Qt
снимки Linux не заменяют эти нативные проверки.
