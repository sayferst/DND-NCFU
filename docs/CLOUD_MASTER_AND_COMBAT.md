# Облачный мастер и проверяемые действия — 19 октября 2026

Генерацию можно выполнять на серверах API: ваш ПК хранит игру, SQLite, сохранения,
инвентарь и бросает кубики; облако пишет рассказ. Перенос весов Ollama и аренда
собственного сервера для этого не нужны. Нагрузка генерации уходит с ноутбука,
но скорость зависит от сети, очереди и модели. Мгновенный ответ не гарантирован.
ChatGPT Plus не включает отдельный API и не подключается как ключ игры.

Пользователь разрешил рассматривать необязательное облако до **2000 ₽/месяц**.
Обязательная эксплуатация игры остаётся бесплатной. Регистраций, платежей,
платных запросов, новых весов, обучающих корпусов и плагинов агент не выполнял.

## С чего начать бесплатно

Встроен ограниченный профиль **OpenRouter → openrouter/free**.
По официальной документации, проверенной через Git-зеркало 19 октября:

- до 20 бесплатных запросов в минуту;
- без покупки кредитов от $10 — до 50 запросов в сутки;
- повтор генерации после отказа проверки — ещё один запрос;
- openrouter/free выбирает доступную бесплатную модель. Качество, очередь,
  длина контекста и состав моделей могут меняться;
- для длительной партии лучше выбрать существующую модель `автор/модель:free`
  из [каталога](https://openrouter.ai/models). Приписывание `:free` произвольному
  платному ID бесплатную версию не создаёт.

Приложение в этом режиме принимает только `openrouter/free` или ID с `:free` и
отправляет `provider.max_price` с нулевыми prompt/completion/request,
`allow_fallbacks=false`. Если такой маршрут недоступен, запрос завершается ошибкой.
Платный маршрут автоматически не выбирается. Это ограничение API-запроса, а не
управление биллингом аккаунта. Не пополняйте баланс ради первой проверки.

Актуальные условия региона, создание аккаунта без карты и доступность конкретной
модели нужно проверить на стороне сервиса. Из облачной среды агента сайты тарифов
возвращали CONNECT 403; официальная документация прочитана в GitHub-зеркале.
Не утверждаем, что вход или оплата российской картой доступны пользователю.
Используйте сервис только там, где он предоставляется по его условиям.

## Подключение в окне игры

1. Закройте старое окно и обновите файлы командами ниже.
2. Если OpenRouter доступен вам, создайте свой API-ключ на
   [странице ключей](https://openrouter.ai/settings/keys). Не используйте пароль
   ChatGPT и не присылайте ключ в чат, консольный отчёт или Git.
3. Откройте раздел **Рассказчик**. Включите **ИИ-мастера** и свободный текст.
4. Выберите **Облако: OpenRouter API**. В поле модели появится `openrouter/free`.
   Оставьте **«только бесплатные модели, без платной замены»** включённым.
5. Вставьте ключ в скрытое поле и разрешите отправку сцены в API. В облако уйдут
   игровой контекст, анкета героя и сообщения, нужные для ответа.
   Затем нажмите **Применить настройки облачного API**.
6. Вернитесь к игре и отправьте сообщение. Идентификатор фактически ответившей
   модели появляется в техническом ответе и сохраняется как источник новой сцены.
   Ключ живёт только в памяти окна либо берётся из `RPG_VKR_LLM_API_KEY`.
   Он не записывается в JSON/SQLite или настройки чтения.

При HTTP 429 квота исчерпана. Подождите или выберите локальную Ollama. Ошибка
ключа, сети или региона также не вызывает перехода на платную модель.
Свободный текст без модели не становится универсальным: офлайн выполняется
ограниченный набор распознаваемых действий и доступен резервный рассказ.

Если сам сайт показывает «Проверка не завершена. Пожалуйста, попробуйте снова»,
сначала нажмите «Попробовать снова». При повторении откройте сайт в обычном
Edge/Chrome с разрешёнными JavaScript и cookies, временно отключите блокировщик
рекламы для этого сайта. До успешного входа создание ключа не подтверждено.
Причина браузерного отказа из одного скриншота неизвестна; это не результат
проверки API из игры. Если страница остаётся недоступной, потребуется помощь
поддержки сайта; локальный режим игры по-прежнему доступен.

## Если понадобится платный API

Подписка на GPU-сервер не нужна: API обычно оплачивает объём входного и выходного
текста. 2000 ₽ — допустимый бюджет, а не уже выбранный или подтверждённый тариф.
Точную цену и способ оплаты нужно сверить для региона, модели и объёма игры.
Не обещаем, что любая модель при любом количестве ходов уложится в эту сумму.

Оценка: стоимость месяца = входные токены × ставка входа + выходные токены ×
ставка выхода; учитывать историю, повторные попытки, валюту и возможные комиссии.
Приложение не устанавливает жёсткий рублёвый лимит платного аккаунта.
Для платного доступа задайте у провайдера отдельный лимит ключа/расхода,
отключите автопополнение и проверьте, является ли ограничение жёстким.
Снятие галочки бесплатного режима разрешает тариф выбранной модели.

## Почему смены модели было недостаточно

Раньше точная команда «атаковать стражника» попадала в движок, а свободное
«ударить его ножом» — к писателю. Он придумывал ранения, смерть и кошельки,
не меняя проверяемое состояние мира. Это ошибка маршрутизации приложения.
Большая облачная модель могла бы написать более грамотный, но столь же неверный
исход, если оставить этот путь.

Теперь явные распознаваемые попытки нападения сначала получают локальный план.
Цель определяется из названного NPC/сохранённого имени, местоимения и текущего
собеседника. Проверяются место и имеющееся оружие. Анкета или фраза «у меня нож»
не добавляет нож в инвентарь. У разведчика есть дорожный нож, у бойца учебный меч,
у учёного посох. Неоднозначная цель уточняется до запроса модели.

- «Ударить стражника ножом» — одна попытка атаки. Введённое «убить» не гарантирует
  попадания или победы. Движок считает броски, урон и ответ противника.
- «Незаметно вонзить нож стражнику» — проверка скрытного подхода, затем одна
  атака, если герой ещё способен действовать. Ловкость отвечает за подход,
  Сила — за попадание в существующем авторском бою; кубик усиления отдельный.
  Это прежние homebrew-формулы, не полная реализация боевых правил SRD.
- «Подойду к воротам и осмотрюсь» — переход к месту, затем осмотр, если место
  достигнуто. Вопрос «к какому NPC?» здесь не возникает.
- Вопросы, отрицания, цитаты и распознаваемые угрозы не являются нападением.
  Подтверждение GUI для нападения на нейтрального NPC сохранено.
- «Ударить и обыскать» выполняет одну атаку, а отдельная заметка сообщает,
  что обыск/добыча ещё не реализованы. Яблоки и чужой кошелёк не появляются.
  Победа пока означает **повержен**, а не подтверждённую смерть с отдельным трупом.

Исход виден сразу, даже пока ИИ думает или отвечает ошибкой. Расчёты по-прежнему
справа. Последующее описание не бросает кубики заново. Два шага применяются
атомарно: ошибка второго откатывает состояние, историю, память и RNG.
Если герой выбыл или переход заблокирован, недоступный следующий шаг не даётся.

Распознавание ограничено и не гарантирует понимания любого русского предложения.
Обыск, кража, произвольное оружие, полноценные тактические комбинации и новый
генерируемый мир этим пакетом не реализованы.

## Голоса, память и совместимость

Новые ответы показываются одним блоком **Мастер**, цитаты выбранного NPC имеют
свой цвет; враждебные — красный. Подпись больше не вставляется между цитатой
и словами «спрашивает он». Добавлены ограниченные проверки выдуманной речи
героя, чужого говорящего, второго стражника, неподтверждённого убийства/добычи
и противоречия промаху. Это эвристики, а не доказательство литературного качества.

Writer JSON16, reader1–16, Scene5 (reader1–5), Narration11 (reader1–11), SQLite12–16.
Fixture15 создана исходным кодом75280df до правок, со своим SHA-256/источником.
Старые ячейки, имена, события, проза и RNG не переписываются при чтении.
Реплики Scene4 также исключены из активной истории модели: в них оказались
выдуманные слова героя. Архив и установленные типизированные факты сохраняются.
Полные промпты и ответы провайдера не являются автоматически научным A/B-опытом.

## Обновление папки на диске D:

Закройте игру, затем выполните в PowerShell. Блок делает отдельную копию старых
ячеек, не удаляя и не перезаписывая их:

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location D:\Projects\DND-NCFU
    $saveDir = 'D:\Projects\DND-NCFU-data\saves'
    if (Test-Path $saveDir) {
        New-Item -ItemType Directory -Path 'D:\Projects\DND-NCFU-data\backups' -Force | Out-Null
        $backupDir = 'D:\Projects\DND-NCFU-data\backups\before-cloud-' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff')
        Copy-Item -LiteralPath $saveDir -Destination $backupDir -Recurse
    }
    git switch setup/development-environment
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось переключить ветку.' }
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Обновление не получено. Сохраните текст ошибки.' }
    git restore --source=HEAD --worktree -- tests/fixtures
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось обновить эталонные файлы тестов.' }
    .\.venv\Scripts\python.exe scripts\check.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка не прошла. Сохраните текст ошибки.' }
    .\.venv\Scripts\python.exe scripts\run_game.py
}
```

Новых Python-зависимостей нет. Если Git сообщает о ваших локальных изменениях,
не используйте `reset --hard`: сохраните сообщение для разбора.

Команда `git restore ... tests/fixtures` однократно обновляет эталонные файлы
автоматических тестов после исправления Windows-переводов строк. Git больше
не преобразует их байты при скачивании. Игровые ячейки находятся отдельно,
в `D:\Projects\DND-NCFU-data\saves`.

Для проверки создайте отдельного разведчика и попробуйте подход/осмотр ворот,
разговор с женщиной, затем отдельную попытку нападения на стражника. Ожидаются
броски и действительная враждебность, а не требование морального оправдания.
У созданного героя должен быть именно нож в инвентаре. Не проверяйте боевой
сценарий на единственной ценной ячейке без копии.

Источники и непроверенные условия: [манифест](research/CLOUD_API_SOURCES_2026_10_19.json).
Реальные время/качество облака, доступ аккаунта и ручная Windows-проверка ожидаются.
