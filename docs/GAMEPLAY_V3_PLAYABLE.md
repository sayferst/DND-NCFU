# Игровой набор v3: подключённый прототип

Начато 25.10.2026, проверено 26.10.2026 (Москва). Базовый коммит до изменений: `6e238d9`.
Руководство: `design/gameplay-v3/source.docx` и `step-plan.docx`; вновь
приложенные владельцем файлы совпали с ними по SHA-256. Никакие команды из
исторических приложений не исполнялись как самостоятельные поручения.

Это ограниченный **играбельный набор**, а не завершение всей спецификации DOCX.
Его команды вызываются из Session и Qt, меняют реальное состояние, попадают
в журнал и воспроизводятся при загрузке. Расчётный `d20_combat` теперь вызывается
этим путём и для героя, и для NPC. Старый бой сохранён для прежних кампаний.

## Как включить и проверить на Windows

Обновление локального checkout после публикации изменений:

```powershell
Set-Location D:\Projects\DND-NCFU
git pull --ff-only
if ($LASTEXITCODE -ne 0) { throw 'Обновление не выполнено' }
.\.venv\Scripts\python.exe scripts\check.py
if ($LASTEXITCODE -ne 0) { throw 'Проверки не прошли' }
.\.venv\Scripts\python.exe scripts\run_game.py
```

Новых зависимостей нет. Перед приёмкой сохраните копию пользовательской папки
данных. Создайте **нового** героя и включите «Приключение v3». Пять разделов
конструктора: личность, навыки/талант, история/мир, характеристики, подтверждение.
База атрибутов 8, максимум 16, бюджет 24; навыки 13 очков, начальный ранг до 2.
Превышение бюджета запрещено до создания. До подтверждения меняется только форма.

Для магии выберите специализацию «Маг» и хотя бы ранг 1 «Теории магии».
После создания мира откройте «Герой» и прокрутите к «Правила приключения · v3».
Внутри доступны экипировка, бой, магия/развитие, мастерская/рынок, время/отношения.
Можно также написать «выучить свет», «применить свет», «подождать 60 минут»,
«отдохнуть», «изготовить кинжал». Отрицания и условия этот локальный адаптер
не исполняет. Для боевых заклинаний выберите конкретную цель в форме.

Проверка: надеть/снять щит → AC меняется; выучить/применить свет → MP уменьшаются;
подождать 60 минут → эффект исчезает; сохранить/закрыть/загрузить → MP, вещи,
время и журнал совпадают. Атака нейтральной цели из новых кнопок требует
подтверждения. Отказ валидатора не расходует ресурсы и RNG.

### Числа прототипа

MP для магического профиля: `max(4, 12 + 4×INT_mod)` при создании. После обучения
и отдыха: `max(4, 12 + 4×INT_mod + 4×(уровень−1))`; немагический профиль до
обучения имеет 0. Обучение не пополняет MP. Отдых 8 часов восстанавливает HP/MP.
I круг требует Теорию магии 1, II — ранг 2 и уровень 5.

| Заклинание | MP | Действие |
| --- | --- | --- |
| Искра | 3 | 1d6, дальность 12 м, спасбросок DEX |
| Исцеление | 4 | 1d6 + INT_mod, себя, 1 трава |
| Защита | 3 | Помеха атакующему, концентрация, 10 минут |
| Свет | 1 | Сохраняемый источник света, 60 минут |
| Пламя | 7 | 2d6, дальность 18 м, 1 трава, спасбросок DEX |
| Восстановление | 7 | 2d6 + INT_mod, себя, 2 травы |

Сложность магии `8 + INT_mod + 2×Теория магии`; успешный спасбросок полностью
отменяет урон этих двух заклинаний. Концентрация при получении урона:
`D20 + CON_mod >= max(10, damage//2)`. Защита снимается при потере концентрации,
завершении боя и истечении времени. Свет не выдаёт произвольных бонусов к проверкам.
Таланты: +1 к Силе, +1 к Интеллекту (каждый до 20), +2 к магическому лечению.

Начальный каталог вещей — авторский набор снабжения; у торговца первый контакт
создаёт по одному экземпляру объявленного малого ассортимента. Покупка его
расходует, продажа возвращает конкретный экземпляр; автоматического бесконечного
пополнения нет. Суточный коэффициент покупки 100/110/120%, продажа 50% базы
с поправкой на состояние; обратная сделка не приносит прибыль.

Материалы для подготовки: `mat_iron`, ткани `mat_linen/mat_wool/mat_silk`,
`type_healing_herb`. Чужое, закрытое или отсутствующее не конвертируется.
Неподдержанный материал не переименовывается в нужный по догадке.

## Совместимость и транзакции

Старые схемы 1–23 читаются прежними путями. При их сохранении новый блок не
добавляется; старые формулы и исторические сообщения не меняются. Автоматической
миграции в v3 нет. Прежние исходные fixtures и DOCX не переписываются.

Каждое новое явное действие имеет `request_id`. Повтор с теми же аргументами
возвращает первоначальный результат без повторного расхода; другой payload
с тем же ID отклоняется. Кандидат вычисляется до commit; при ошибке восстанавливается
RNG. Ошибка пассивного тика также откатывает основное действие целиком.

Входные контексты и результаты записаны в Turn. Загрузка сначала повторяет
расчёт, затем связывает его с историческим миром/каталогом/героем/навыками.
Нельзя вставить будущий XP, подменить MP, чужой кошелёк или урон. Автоматический
тик времени связан с длительностью основного действия, не является доступной
игроку командой обхода боя. UI и повествование используют исход движка.

## Что ещё не завершено

- Это дуэли, не общая очередь многих участников. Дистанция скалярная, NPC не
  преследует героя. Нет полного каталога состояний/сопротивлений, боеприпасов и лута.
- Все произвольные сгенерированные предметы ещё не могут стать экипировкой v3.
  Сейчас экипируются экземпляры малого каталога; материалы мира имеют явный мост.
- Виды описательные. Шесть специализаций не равны шести полным классам SRD;
  прежние три пресета задают бюджет характеристик. HP и прежняя практика сохранены,
  новые формулы HP/ST на 1–20 не внедрены. Полного баланса 1/5/10/15/20 нет.
- Права на пять талантов в поздней игре могут превышать текущие три разных таланта.
  Круги III–V, другие школы, ритуалы и произвольные эффекты не поддерживаются.
- Полевой верстак — единственная мастерская. Качество пока 1; нет кузницы,
  заточки, разборки всего каталога и многоступенчатого производства.
- Точный медный расчёт относится к новому рынку. Старые сделки с произвольными
  предметами мира остаются целозолотыми и не мигрированы в новую денежную модель.
- Расписания детерминированы. Слух не превращается в подтверждённое наблюдение;
  полного графа знаний, распространения через цепочки NPC и фракционной политики нет.
- Миграция копии с отчётом/откатом и автоматические backup ещё открыты.
  Лимит 2000 ходов/32 МиБ не снят; полные контексты новых записей увеличивают saves.
- Свободный текст поддерживает малый локальный адаптер и прежний планировщик;
  произвольная длинная условная цепочка не объявляется понятой.
- Linux offscreen-тесты не доказывают нативную Windows-приёмку, качество живого
  рассказчика или готовность нового Setup. Windows-сборка требует отдельного прогона.

Числа и ограничения выше — версия авторского прототипа, не доказанный баланс,
не полная SRD и не научный сравнительный эксперимент.
