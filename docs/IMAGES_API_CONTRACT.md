# RouterAI Images: документированный адаптер

Обновлено 20.10.2026 после присланного владельцем руководства
[«Генерация изображений»](research/USER_ROUTERAI_IMAGES_GUIDE_2026-10-20.md).
Исходный текст сохранён без изменения байтов; происхождение/SHA — в соседнем
`.source.json`. Дополнительно получены [примеры обеих моделей](research/USER_ROUTERAI_IMAGE_MODEL_EXAMPLES_2026-10-20.json):
Recraft с aspect_ratio1:1 безsize; FLUX с объектамиinput_references.
Это предоставленная документация, а не успешная живая проба:
GET из среды разработки по-прежнему получает tunnel403. Платных запросов нет.

## Запрос и референсы

`POST https://routerai.ru/api/v1/images`, Bearer-ключ Художника.
Один запрос, без автоматического повтора:

```json
{
  "model": "black-forest-labs/flux-3-image-klein",
  "prompt": "...public pixel-art brief...",
  "n": 1,
  "resolution": "1K",
  "input_references": [
    {"type": "image_url", "image_url": {"url": "data:image/png;base64,..."}}
  ]
}
```

Руководство подтверждает `resolution` (тир) и `size` (точные пиксели) как
альтернативные параметры. Набор зависит от модели; неподдерживаемые значения
могут игнорироваться. Поэтому адаптер выбирает объявленный моделью `resolution`,
иначе `size`. Точный ценовой вариант `image_pricing.variant` с тиром/пикселями
тоже служит источником доступного размера и полного тарифа. Оба параметра
одновременно не передаются. Для размера с неизвестной ценой запрос не отправляется.

Если модель не объявляет ни параметр, ни варианты разрешения, для обычной
настройки 1K допускается документированный минимальный запрос model/prompt/n
**только при фиксированной полной цене за изображение**. ДляRecraft добавляется
документированный aspect_ratio1:1. Размер не задаётся:
подтверждение и карточка прямо пишут «по умолчанию модели», не обещают 1K.
Пользовательские 768/1.5K/2K/4K без подтверждения размера не заменяются незаметно.

`per_request_limits.supported_resolutions` и `max_input_references` были ошибочно
обязательными в первой реализации: в руководстве такой обязательной схемы нет.
Теперь отсутствие этих полей само по себе не блокирует генерацию. Если поля
есть, их ограничения соблюдаются. Поддержка FLUX input_references подтверждена
присланным примером страницы именно этой модели; отсутствие параметра в
неполном supported_parameters больше не отменяет этот документированный контракт.
При неизвестном верхнем лимите приложение передаёт только один наиболее
приоритетный образ. Это консервативная политика приложения,
не заявление о максимуме провайдера. При известном лимите передаётся до него.
Наличие референсов всегда выбирает FLUX. Recraft остаётся text-to-image.
Недоступные референсы не отбрасываются молча ради обхода проверки.

## Цена и ответ

Каталог принимает data[], [] или [{data:[]}]. Цена: `pricing_units.image_output=image`
и `pricing.image_output`, либо `image_pricing` с `unit=image` и точным вариантом
или общей ценой `variant=null`. Распознаётся известный request-сбор. Неизвестные
MP/token/дополнительные сборы по-прежнему блокируют POST. При наличии таблицы
вариантов нельзя брать цену другого разрешения или обходить неоднозначность
общим числом из pricing. Справочные цены из задания не заменяют актуальный каталог.

Руководство подтверждает `data:[{b64_json:...}]` и **`usage.cost` в рублях**.
Адаптер учитывает эту сумму даже без поля currency. Явная другая валюта не
переименовывается в рубли. Прежние cost_rub/usage.cost_rub сохраняют совместимость;
неизвестный факт расхода удерживает резерв. Разрешён ровно один результат.

Поддержка URL-ответа сохранена как совместимость: только HTTPS, без ключа и
редиректов, запрет частных адресов. Размер до20МБ/4096², Qt нормализует PNG.
Если загрузка не удалась после получения стоимости, известный расход сохраняется.
Квитанция содержит ограниченные id/billing без ключа/непроверенных ошибок сервера.

## Автоматическое распределение

- Обычный предмет/материал без референсов → Recraft.
- NPC/существо/локация/событие/уникальная вещь → FLUX.
- Любой объект с прежним изображением-референсом, включая перегенерацию → FLUX.

«Общий образ типа» выбирает хранение type/instance, а не дорогую/дешёвую модель.
Строка в списке Художника — просмотр тарифа, не ручная подмена распределения.
Выбранная модель и причина показаны до отправки и при отказе проверки цены.

## Что проверено

Новые тесты воспроизводят пять дефектов предыдущего адаптера и проверяют
исправления на локальном HTTP/Qt/FakeTransport. Локальный сервер проверяет
точный JSON, число запросов и рублёвый usage. Это не настоящий RouterAI.
Нет подтверждения художественного качества, скорости, текущих тарифов,
реальных лимитов моделей или визуального сходства. Нужна ручная проверка
на Windows с отдельно выбранным бюджетом; Codex платные запросы не выполнял.
