# Контрактный адаптер Images API: что подтверждено и что требует документации

Источник IDs, endpoint, input_references и пределов — прямой запрос владельца
20.10.2026. Реальные GET каталога/документации из среды получили tunnel403.
Следующие структуры являются **реализованным контрактом и синтетическими
fixtures**, а не заявлением, что RouterAI в точности возвращает их сейчас.

Транспорт: POST https://routerai.ru/api/v1/images, Bearerсуществующего ключа,
JSON model/prompt/n1/size, опционально input_references как массивdataURL PNG.
Recraft безреференсов, FLUX только при подтверждённой поддержке. Размеры:
768x768,1024x1024,1536x1536,2048x2048,4096x4096. Реальный параметр размера и
форма input_references должны быть сверены с примером RouterAI до живой пробы.

Каталог принимает data[],[] или[{data:[]}]. Нужны:

- точный id модели;
- pricing/pricing_units.image_output=image либо image_pricing[{unit:image,
  variant:<768/1K/1.5K/2K/4K илиWxH/null>,price:<рубли>}];
- если есть request-сбор — pricing.request и pricing_units.request=request;
- supported_parameters с size и при референсахinput_references;
- per_request_limits.supported_resolutions и max_input_references.

Это консервативная нормализованная форма: если реальная документация использует
другие имена/единицы, адаптер остановится, а не отправит платный запрос наугад.
Нужен исходный ответ безключа, чтобы добавить именно документированное отображение.
Список параметров не считается доказательством полной цены неизвестного MP/token
тарифа. Параметры маршрутизации/идемпотентности, не подтверждённые Images API,
клиент не изобретает и вPOST не добавляет.

Поддержанный ответ: dataсровноодним объектом b64_json илиurl. URL только HTTPS,
безавторизации и редиректов, адреса частныхсетей запрещены. Размер≤20МБ,
размерность≤4096²; Qt декодирует и сохраняет PNG. Поля cost_rub/usage.cost_rub
или cost с currency=RUB становятся проверенной валютной суммой. Неизвестная
валюта не превращается врубли, сумма не выдумывается. Сохраняется ограниченная
квитанция id/billing; непроверенные сообщения сервера/ключи не копируются.

Тесты tests/test_images_client.py выполняют настоящиеHTTP GET/POST на127.0.0.1,
не наRouterAI. Другие интеграции используют FakeTransport. Они подтверждают
поведение приложения, не качествомоделей/ихцен/доступность/схемуживогоAPI.

Для завершения внешней приёмки нужны примерPOST/ответа, строки каталога этихдвух
моделей и ограничения референсов. Никакого ключа в чат. Платная проба — только
после отдельного разрешения владельца, с указанной суммой и количеством1.
