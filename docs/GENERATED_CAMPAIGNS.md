# 1P — новые кампании, постоянная память и дневник

## Как начать

1. Обновите папку проекта командами ниже. Старые ячейки останутся на месте.
2. В разделе «Рассказчик» включите уже настроенный RouterAI, выберите свою
   DeepSeek Flash, проверьте модель, цену и лимит ключа. Новый ключ вводите только
   в приложении, никогда в чат, Git или системный TXT. Настройка API:
   [ROUTERAI_WINDOWS.md](ROUTERAI_WINDOWS.md). Подписка ChatGPT Plus не оплачивает API.
3. Откройте «Главное меню» → «Новый герой». Заполните биографию и поле
   «Мир, жанры и настроение»: жанры, масштаб магии, темы и ограничения.
   Оставьте флажок «Создать новый мир и сюжет мастером».
4. Подождите завершения создания. Мастер получает эти два поля, класс и отдельный
   идентификатор варианта. Он создаёт стартовый район, свои имена и жителей,
   предметы, зацепки и скрытый сюжетный замысел. Деревня с яблоками не обязательна.
   Замысел связан с прошлым героя, но не определяет его будущие решения.
5. Действуйте текстом. Новые детали проходят регистрацию, физические действия —
   проверку движком. Мастер не спрашивает разрешения придумать обычную деталь.
   Подтверждения рискованного броска, непонятого намерения, оплаты и удаления
   остаются: они защищают от неверно распознанного действия.

Если ИИ выключен, недоступен или дважды возвращает неподходящие данные,
приложение явно сообщает об автономном старте. Это выбор из шести авторских
мест, не полноценная генерация языковой моделью и не гарантия выполнения всех
жанровых пожеланий. Описание героя сохраняется. Чтобы попробовать ИИ-генерацию,
сначала настройте подключение, затем создайте следующего героя. Состоявшуюся
кампанию нельзя незаметно заменить другим миром. Старые сохранения продолжают
прежний эпизод; они не получают случайный старт задним числом.

## Что хранится

По умолчанию данные находятся вне Git:

- `D:\Projects\DND-NCFU-data\campaigns.sqlite3` — рабочие кампании, полный снимок,
  цепочка событий, состояния сущностей, важные воспоминания, записи дневника и
  тексты рассказчика. У каждой кампании свой ID, данные разных героев разделены.
- `D:\Projects\DND-NCFU-data\saves\slot-1.json` … `slot-3.json` — три явные
  контрольные точки. Они обновляются кнопкой сохранения, не каждым ходом.
- `world-catalog.sqlite3` — прежний индекс каталога, а не замена архива кампаний.

Путь может отличаться при настройке `RPG_VKR_DATA_DIR`. Игра пишет рабочую базу
после принятых изменений, записей и рассказа. При ошибке записи показывает её;
нельзя считать неуспешную запись сохранением. Закрытие не обновляет JSON-ячейку.
В разделе «Дневник» выберите кампанию и нажмите «Открыть рабочую кампанию из базы»,
чтобы продолжить без JSON-ячейки, в том числе после перезапуска программы.

Загрузка старой ячейки возвращает её состояние: будущие события не выдаются
мастеру как настоящее. Архив событий остаётся в SQLite, активная ветка меняется.
Это не интерфейс просмотра всех альтернативных ветвей. Удаление JSON-ячейки
не удаляет рабочую кампанию из базы. Перед обновлением копируйте **всю папку
DND-NCFU-data**, а не только saves: это включает SQLite, настройки и личный TXT.
Резервная копия может содержать API-ключ из ваших настроек; храните её лично.

## Как мастер вспоминает

Движок передаёт актуальные предметы, местоположения, здоровье и отношения.
Мастер предлагает краткие важные записи: обещание, имя, улику, слух, интерес,
связь с сюжетом. Их схема проверяется до принятия. Проза не меняет числа.

SQLite подбирает до 12 важных/подходящих фактов, пяти закреплённых или подходящих
заметок, восьми карточек, трёх недавних действий и трёх найденных фрагментов
старых разговоров. Русский поиск использует заранее нормализованный текст;
запросы SQL параметризованы. Контекст ограничен размером, целая база в промпт
не уходит. Скрытый замысел получает планировщик, а не журнал игрока.
Невидимые существа не появляются в публичном поиске по имени.

Это детерминированный поиск и отбор, без embeddings, серверной БД или обучения
весов. Память не гарантирует, что модель отметит каждый важный факт или найдёт
перефразированную мысль без общих слов. Полный архив сохранён, но не всегда
извлекается в контекст. Художественный рассказ — записанное повествование,
не дополнительный источник числовой истины. Слухи, предположения героя,
секреты и подтверждённые состояния различаются.

## Дневник

Откройте «Дневник», нажмите «Новая заметка», заполните заголовок, источник/место
и текст. Можно записывать места трав, цены, имена, наблюдения за существами или
сведения информатора. «Сохранить заметку» записывает её в рабочую кампанию.
Флажок «Важное» повышает доступность записи мастеру. Список фильтруется поиском;
выбор записи позволяет редактировать и повторно сохранить. «Удалить заметку»
требует подтверждения; прежние редакции остаются внутри снимка.

Личная заметка не создаёт траву, деньги или предмет, не доказывает слух и не
сообщает его всем NPC. Несохранённый текст редактора — черновик; переход к другой
записи/новой заметке и закрытие предупреждают о его потере. Нижняя часть страницы
доступна прокруткой. «Вспомнить» показывает публичную выборку памяти для проверки.

## Торговля и схватки

Постоянных разделов «Жители», «Лавка», «Схватка», «Кубики», «Команды» и «Задание»
в обычном интерфейсе нет. Старый интерфейс остаётся только для регрессионных
проверок. Основной ввод — чат. Например, попросите доступного торговца показать
товары. Откроется окно реальных экземпляров: покупка/продажа, количество,
итоговая цена и кнопка сделки. Кошелёк NPC не показывается. При переходе или
смене героя окно теряет доступ к прежнему взаимодействию.

Торговля нового мира проверяет наличие товара, денег, владельца, доступность
и вместимость. Покупка округляется вверх до золотой, продажа — вниз от половины
базовой цены. Для дешёвых вещей можно выбрать партию. Заполненный контейнер пока
нужно опустошить перед продажей. Используются золото героя, личный кошелёк NPC
и доступные физические монеты при NPC. Магазин старого эпизода сохраняет старые
правила, это ещё не единая экономика всех прежних подсистем.

Атака нового существа открывает окно выбранной цели со свободным вводом.
Движок считает попытку; живой оставшийся противник получает ответный бросок.
Смерть/поражение и здоровье сохраняются, поверженный не атакует в ответ.
Расчёты остаются справа от рассказа. Нейтральность не запрещает нападение;
заявленное убийство не гарантирует успеха.

Для новых миров неудачная попытка завладеть чужим предметом сохраняет уже
выполненные шаги до неё и останавливает дальнейшую цепочку. Обычный перенос
контейнера сохраняет его содержимое. Присутствующие бодрствующие свидетели
получают собственную запись наблюдения и изменение отношения: храбрый защитник
может стать враждебным, пострадавший может лишь обидеться. Все жители автоматически
врагами не становятся. Это небольшая авторская политика, не полная психология.

## Инструкция мастера и источники

Шаблон: `prompts/master_system_prompt.txt`. Личная копия выбирается/редактируется
через раздел «Рассказчик» и перечитывается перед запросом. В нём объясняются роль,
русский стиль, свобода выбора героя, новый мир, память, слухи, цели NPC и границы
прозы/движка. Биография и пожелания к миру хранятся отдельно, в самой кампании.
Никаких весов этим TXT мы не дообучаем. Контракт движка остаётся кодом приложения.

[Жанровый справочник](NARRATIVE_SOURCES.md) содержит ссылки-кандидаты и описание
семи небольших собственных карточек. При генерации выбираются не более двух.
Сайты из облачной среды оказались недоступны; их страницы не копировались.
У мастера нет встроенного браузера. Чужие книги и обучающие корпуса не добавлены.

## Проверка и границы

Автоматические проверки используют временные базы и местный тестовый HTTP,
не расходуют баланс RouterAI. Результат Linux не заменяет проверку настоящего
DeepSeek и Windows. Проверьте новый мир, запись/правку/удаление заметки,
закрытие/восстановление без ячейки, торговлю, атаку и сохранение/загрузку.

Пределы текущего прототипа: 40 мест, 2000 ходов, 2000 редакций дневника,
4000 кратких воспоминаний, снимок до 32 МБ. Запись пока пересобирает часть индексов;
не заявляется измеренная производительность неограниченной кампании. Полная
инициатива, магия, ремесло, все свойства растений/монстров, время/дистанция,
самостоятельное преследование NPC, все старые предметы и ConflictSolver ещё
не объединены. Новые правила торговли/ответа/реакций — homebrew, не полная SRD.
Число механик не является результатом исследования ВКР: для него нужен отдельный
сравнительный эксперимент с контролируемыми входами и реальными моделями.

## Обновление папки на D:

Закройте игру. Команды не удаляют ваши файлы и останавливаются при ошибке Git.
Если есть несохранённые локальные правки исходников, Git попросит разобраться
с ними; не используйте reset --hard. Python-зависимости не изменились.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location 'D:\Projects\DND-NCFU' -ErrorAction Stop
    $dataDir = 'D:\Projects\DND-NCFU-data'
    if (Test-Path $dataDir) {
        $backupDir = 'D:\Projects\DND-NCFU-backup-' + (Get-Date -Format 'yyyyMMdd-HHmmss')
        Copy-Item -LiteralPath $dataDir -Destination $backupDir -Recurse -ErrorAction Stop
        Write-Host "Резервная копия: $backupDir"
    }
    git switch setup/development-environment
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось переключить ветку.' }
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Обновление не получено. Сохраните вывод.' }
    & '.\.venv\Scripts\python.exe' scripts\repair_fixture_checkout.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка эталонных файлов не прошла.' }
    & '.\.venv\Scripts\python.exe' scripts\check.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка не прошла. Сохраните вывод.' }
    & '.\.venv\Scripts\python.exe' scripts\run_game.py
}
```
