# Канонический набор новых кампаний

ID: `dnd-ncfu-unified-d20-v1`, writer30, UnifiedSession. Старые22–29 и ранние
форматы читаются своими проверенными обработчиками. Это авторские правила,
не заявление о полном воспроизведении SRD или всего литературного архива.

Шесть классов: Воин, Лучник, Плут, Маг, Жрец, Ремесленник. Один стандартный
комплект на класс, физические единицы с устойчивыми ID,200медных. Никакого
виртуального второго комплекта/второго кошелька. Бонусов из свободной биографии нет.
Шесть характеристик8–16, база8,ровно24повышения. Модификатор floor((score-10)/2).
Профильная подготовка +2/+3/+4/+5/+6 по ступеням1–4/5–8/9–12/13–16/17–20.
Список применимых задач — CLASSES; непрофильная задача не запрещена классом.
Талант один на создании. Доступны общие и классовые таланты с расчётными эффектами.
Покупаемых рангов/очков навыков в новых героях нет, d20_progress=None.

Общий XP порога L:50*(L-1)*L,до20.50XP за впервые подтверждённое выбытие
конкретного противника,10за первое изготовление по конкретному рецепту.
Повтор ID запроса/того же достижения не выдаёт опыт снова. Повышения
характеристик:2на4/8/12/16/20,талант на1/5/10/15/20. Показаны в «Развитии героя»
только при наличии выбора; классовая подготовка повышается автоматически.
Экономика/темп не прошли длительного балансировочного playtest.

Ресурсы централизованы в domain/unified.caps, основаны на проверенных формулах
hero_resources без изменения старого обработчика. C/S/I — модификаторы
Телосложения/Силы/Интеллекта, l — уровень:

- HP=16+2C+max(1,6+C)*(l-1)+2при«Крепком».
- ST=max(10,20+2*(S+C))+3*(l-1)+4при«Неутомимом».
- MP=max(4,12+4I+4*(l-1))+4при«Сосредоточенном» для мага/жреца; иначе0.

Проверки: d20+характеристика+подготовка применимого класса+талант.
DC5/10/15/20/25/30. Обычный разговор/осмотр не требуют броска.
Свободные AI-предложения и кнопка подтверждения используют этот же канонический
валидатор задач/сложностей. В контекст планировщика передаются class_tasks,
а не ranks. Чистая проверка характеристики без профильной задачи не получает
подготовку класса; например,не всякая проверка Интеллекта является магией.
Атаки: натуральная1 — промах,20 — попадание и удвоенные кубики урона;
обычные проверки не получают автоматический исход от1/20.
Броня по фиксированному каталогу, щит+2AC. Оружие использует d4/d6/d8/d10/d12
и2d6. d100 применяется при поиске сырья; универсальный DiceRoller поддерживает
всеD4/D6/D8/D10/D12/D20/D100,NdM±K,границы и seed/checkpoint.
Результаты не берутся из текста модели.

Очередь до8участников: герой, согласившиеся союзники, противники; реальные
атаки NPC после действия героя, включая магию/расходник. HP изменяется
в зарегистрированных экземплярах. Квитанция содержит фактические броски,
ресурсные изменения и результаты; текстовая перегенерация не исполняет ход.

Минимальный новый каталог: свет, магический разряд, исцеление;4рецепта
(слиток,меч,мана,бинт), ремонт и конечные узлы добычи. Он не выдаётся за26старых
заклинаний или5000готовых эффектов. Старый каталог действует только в старых
кампаниях. Свитки одноразовые,малое зелье маны восстанавливает до6MP,
лекарства лечат по кубикам. Отказ/нехватка ресурсов сохраняет RNG и всё состояние.
Торговля реальными экземплярами по1единице, умеет отделять единицу из стопки.
Цена берётся из зарегистрированной Definition, кошелёк NPC конечен.

Календарь/потребности/производство/локальные сообщения используют существующую
конечную симуляцию. Никаких дополнительных LLM-запросов на каждого жителя.
Это ограниченная исполняемая RPG, не бесконечная экономическая симуляция.
