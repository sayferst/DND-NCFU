# Один пользовательский маршрут

Создать героя -> Герой -> Характеристики и талант -> История и мир ->
Подтверждение -> автоматическая генерация мира -> обычная игра.

Имя; один из6классов; автоматически предлагаемый комплект с количеством вещей;
6характеристик/24очка/модификаторы; один талант;2свободных текстовых поля.
Четыре страницы,Назад/Далее,Создать только на последней,Отмена на любом шаге.
Ошибки показаны рядом,введённая биография не переписывается.
Высота зависит от шага,горизонтальной прокрутки нет,вертикальная по необходимости.
При смене класса пользовательские характеристики сохраняются до явного
«Рекомендованные характеристики». Талант обновляет ресурсы предпросмотра.

Нет галочек версий,D20-навыков,профиля поверх класса,возраста/расы отдельными
обязательными полями,библиотеки/импорта/теневого режима. Удалён и старый
переключатель RAG из панели приключения, и кнопка перевода в старый набор29.
CLI совместимости сохранена. Консоль владельца сохраняет RouterAI/допуски,
но не требует настройки моделей обычным игроком.

Сбой генерации показывает ошибку/повтор,не запускает учебный эпизод.
Сессия хранит исходную анкету; повтор не удаляет ячейки. Старый учебный UI
доступен лишь внутренним тестам/историческим сохранениям,не новому конструктору.

Изображения screenshots/*.png — снимки реальных Qt-виджетов offscreen Linux,
не макеты и не доказательство нативного Windows/DPI. Последний шаг подтверждает
уже рассчитанный движком комплект/ресурсы. Экран героя вызывает Session,
а не применяет числовые результаты самостоятельно.
