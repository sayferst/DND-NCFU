# Автономные проверки

Для этапа 1E после установки зависимостей:

1. Отключить интернет на ноутбуке.
2. В PowerShell из `D:\Projects\DND-NCFU` выполнить
   `.\.venv\Scripts\python.exe scripts\check.py` (ожидается 290 passed).
3. Запустить `.\.venv\Scripts\python.exe scripts\run_game.py`.
4. Ввести «осмотреться», «поговорить», «помочь», «бросить d20», «проверить силу» и неизвестное «улететь».
5. Сохранить тестовую сессию в ячейке 1, закрыть и открыть окно, загрузить ячейку.
   Журнал должен восстановиться. Протестировать ячейки 2–3, перезапись и удаление
   на пробных сессиях по docs/SAVE_SLOTS.md.

Код прототипа не содержит сетевых запросов и не использует API-ключи.
Пользователь подтвердил первое окно на Windows. Пользователь также подтвердил d20 и сохранения. Профиль 1B принят. Эпизод 1C принят пользователем. Новый интерфейс 1D и ручное отключение сети пока не подтверждены.
Облачные Qt-тесты используют offscreen и не заменяют эту проверку.

Полный протокол для будущей игры (сейчас не выполнено):

1. Подготовить копию тестового сохранения и записать версии кода/правил.
2. Отключить Wi-Fi/сетевой доступ; временно отключить доступ приложения к ключам,
   сохранив их безопасно, не удаляя пользовательские секреты.
3. Не запускать Ollama. Выбрать offline_rules; загрузить тестовую кампанию.
4. Пройти 30 ходов, бой, лут, торговлю и конфликт; сохранить и перезапустить.
5. Сверить состояние и журнал, отсутствие запросов к сети и ошибок.
6. Отдельно испытать local_llm, если её установка была согласована.
7. Повторить с portable-релизом на Windows без Codex/Python/API-ключей.

Записывать фактические результаты, длительность, ошибки и ограничения.

Дополнительно без сети пройти docs/EPISODE.md, сохранить мир в середине поручения,
перезапустить приложение и закончить доставку после загрузки.

Также проверить поиск, справочник, тему/шрифт, экспорт и Ctrl+S по docs/INTERFACE.md.

После обновления 1F также выполнить цикл docs/CHARACTER_AND_PROGRESS.md без сети.

Для 1G без сети также выполнить docs/COMBAT_AND_HOSTILITY.md: бой, отношения, повторная загрузка.

### Дополнительно 1H

Без сети проверить «бросить кубик», вопросы «что я вижу?»/«где я нахожусь?»,
разбор подхода/атаки справа и краткий исход слева. Выбор прошлого броска не меняет
мир, ресурс или следующий результат. Экспорт всех расчётов работает локально.
Ни одна из новых функций не отправляет запрос модели или сайту StoryForge.

### Дополнительно 1I

Без Ollama и интернета пройти эпизод, проверить «Память мира» и сохранение/загрузку
v7. В «Рассказчик» поиск без локального сервера даёт понятный отказ; после него игра
принимает команды. На Windows пользователь пока не установил Ollama/модели.
Будущая проверка настоящего локального режима: заранее установить согласованную
модель, отключить интернет, проверить создание/отмену прозы и её восстановление из
ячейки без обращения к модели. Пока этот пункт не выполнен, не считать его принятым.
