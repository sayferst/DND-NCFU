# Автономные проверки

Для прототипа 0B после установки зависимостей:

1. Отключить интернет на ноутбуке.
2. В PowerShell из `D:\Projects\DND-NCFU` выполнить
   `.\.venv\Scripts\python.exe scripts\check.py` (ожидается 19 passed).
3. Запустить `.\.venv\Scripts\python.exe scripts\run_game.py`.
4. Ввести «осмотреться», «поговорить», «помочь» и неизвестное «улететь».
5. Проверить ответы, закрыть окно и снова открыть. Появится начальная сцена;
   сохранения на этом этапе не предусмотрены.

Код прототипа не содержит сетевых запросов и не использует API-ключи.
Ручное отключение сети и запуск окна на Windows пока не подтверждены пользователем.
Облачные Qt-тесты используют offscreen и не заменяют эту проверку.

Полный протокол для будущей игры (сейчас не выполнено):

1. Подготовить копию тестового сохранения и записать версии кода/правил.
2. Отключить Wi-Fi/сетевой доступ; временно отключить доступ приложения к ключам,
   сохранив их безопасно, не удаляя пользовательские секреты.
3. Не запускать Ollama. Выбрать offline_rules; загрузить тестовую кампанию.
4. Пройти 30 ходов, бой, лут, торговлю и конфликт; сохранить и перезапустить.
5. Сверить состояние и журнал, отсутствие запросов к сети и ошибок.
6. Отдельно испытать local_llm, если её установка была согласована.
7. Повторить с portable-релизом на Windows без Codex/Python/API-ключей.

Записывать фактические результаты, длительность, ошибки и ограничения.
