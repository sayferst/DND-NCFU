# Архитектура текущей игры

PySide6 показывает состояние Session и отправляет проверяемые команды. Слой
приложения связывает правила, контракты действий, квитанции и сохранения.
Модули domain/unified и связанные каталоги определяют числовые исходы; модель
не является расчётным ядром. RNG и история событий сохраняются для продолжения.

RouterAI/DeepSeek предлагает действие в разрешённой структуре. Валидатор отклоняет
неподдержанный эффект или недостаточные ресурсы. После применения команды мастер
получает подтверждённые факты и описывает исход. RAG добавляет короткие релевантные
справки; SQLite хранит мир и память кампании, JSON — переносимые ячейки.

Новые герои используют единый поток. Старые форматы читаются с прежними правилами;
миграция создаёт копию, не переписывает исходник. Контур training отделён от клиента,
не содержит обученного адаптера. Данные и права: [ML](ml/data_rights.md).

Для проверки исходного состояния до объединения сохранён
[исторический аудит](unified/architecture_before.md). Это не актуальная карта всех классов.
