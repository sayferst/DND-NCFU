# Установка и первый запуск

После установки откройте [пошаговый гайд игрока](player-guide.md).

Текущая 0.4.0 проходит предварительное тестирование; Setup выдаёт владелец.
Публичные [Releases](https://github.com/sayferst/DND-NCFU/releases) пока содержат
историческую 0.3.1 Preview2. Не подменяйте её инструкциями для 0.4.0.

Нужны Windows x64, интернет и выданный профиль. Облачная игра требует работающего
хоста владельца. Python, модели и библиотеки машинного обучения не нужны.

1. Получите Setup у владельца и сравните SHA256 с переданной им контрольной суммой.
2. Установите приложение для текущего пользователя. Ярлык рабочего стола необязателен.
3. Запустите DND-NCFU и войдите в выданный профиль. Не публикуйте пароль в Issues.
4. Создайте героя: класс → характеристики/талант → история и пожелания → подтверждение.
5. Дождитесь создания мира. Используйте поле действий и доступные игровые кнопки.
6. Сохраняйте кампанию через интерфейс и продолжайте её из сохранений.

При обновлении закройте игру и запустите новый Setup. Установщик не должен удалять
данные пользователя. Перед обновлением сохраните отдельную резервную копию каталога
данных, показанного приложением/владельцем. Не переносите чужой файл ключей.
Долгая загрузка большой кампании возможна; дождитесь окончания фонового задания.

Приложение/Setup не подписаны коммерческим сертификатом издателя. Не отключайте
защиту Windows: при предупреждении проверьте источник/хэш и обратитесь к владельцу.
Смена адреса хоста обычно не требует переустановки: клиент получает подписанный адрес.
