# Внутренний рассказчик

RouterAI сохраняет понимание/планирование/создание мира и обычный рассказчик.
После receipt _start_story может выбрать проверенный локальный backend.
Trained manifest:approved_for_runtime,неухудшение критических ошибок,
минимум1holdout-кампания,model,localhost endpoint,путь иSHA настоящего адаптера.
Manifest владельческий,не распространяется игрокам вместе с весами.

Выбран protocol /api/chat совместимый с OllamaClient. training.serve загружает
base+PEFT через Transformers,bind только127.0.0.1,одна генерация одновременно,
лимиты контекста/выхода,без логирования промптов. При отсутствии модели,
ошибке/невалидной прозе обычный RouterAI остаётся fallback в прежнем лимите
запросов/квоты. Перегенерируется только текст,не операция Session.

Автовыбор проверен синтетическим loopback-транспортом,реального адаптера нет.
Это owner-local контур; развёртывание обученного рассказчика на отдельном
сервере для всех тестировщиков этим прогоном не подтверждено. Облачные ключи,
допуски и биллинг не меняются. В Windows-клиент не включены training stack/веса.
