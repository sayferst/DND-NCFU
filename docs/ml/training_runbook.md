# Запуск владельцем, отдельно от игры

Текущий основной блокер:нет допущенных SFT-пар. Сначала export реального
публичного контекста/receipt/прозы,проверка прав и выборочное человеческое ревью,
потом prepare_dataset.19000структурных карточек не обходят этот шаг.

Техническая среда этого задания:Linux,3CPU,около9.7GiB RAM,нетNVIDIA/CUDA
или PyTorch в game venv. Не использовались облачные GPU/Colab и скачивание весов.
Для заданного NF4/BF16 требуется отдельный совместимый NVIDIA-контур;
объём VRAM на конкретном датасете не измерен и не гарантируется.

В отдельном окружении установить requirements-train.txt,проверить совместимость,
локально предоставить модель из проверенной revision/лицензии. Заполнить
dataset_sha256 только после review. train_lora --dry-run проверяет prerequisites;
--smoke-test обучает2шага,затем отдельный обычный run. Фиксировать GPU/VRAM,
версии библиотек,seed,параметры,loss,ошибки и SHA полученного адаптера.
Нельзя делать runtime-approval на основании одного smoke/loss.

До включения сравнить неизменные holdout-кампании для base/trained/hybrid,
оценить критические противоречия receipt/агентность/приватность/длину/повторы/
latency/fallback/VRAM. Рост критических ошибок блокирует активацию.
RouterAI baseline — только отдельно разрешённые запросы с бюджетом,
не автоматический этап pytest/train. В текущем задании платных генераций0.
