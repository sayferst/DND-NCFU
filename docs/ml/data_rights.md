# Права и происхождение

Raw CODEX_READY остаётся вне Git/установщика/API. Предоставление архива для
анализа не равно разрешению опубликовать чужие/частные тексты или признать
машинное QC человеческим ревью. Для SFT нужны реальные помеченные пары,
permitted+approved и подтверждённое происхождение engine_receipt. Сейчас их0.
Синтетические примеры формата не являются обучающим набором.

Встроены24оригинальных метода проекта. Их права project_owned; нет сведений
чужих кампаний,GM-секретов,паролей или API-ключей. Другие выдержки требуют
отдельного явного допуска к публичной базе,а не только допуска к локальному SFT.
Типы campaign_private/secret_gm не входят в глобальную базу.
Qwen3-4B: Apache-2.0 по публичным метаданным на дату проверки;revision в config
и validation/base-model-metadata-01.json. Веса не получались/не распространялись.
