Оставшиеся экспериментальные границы: конечный словарь физических эффектов,
неполный NLP, отсутствие полной семантической проверки художественных деталей,
непроверенный на GPU обучающий стек, отсутствие человеческих меток/литературного
holdout/измерений реальной Faun. Их нельзя объявлять готовыми из-за наличия кода.
