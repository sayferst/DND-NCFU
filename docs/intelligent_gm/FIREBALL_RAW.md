Внутри gzip/tar находятся отдельные `anonymized/data/*.jsonl.gz` и

## Что выполняет программа

`training.fireball_raw` читает архив целиком, без извлечения путей из tar:
проверяет внешний и внутренние gzip CRC, считает SHA256 всех байтов архива и
каждого member, обрабатывает каждую строку. Учитывает типы событий, признаки
авторства и все встреченные верхние поля. Ошибки JSON считаются отдельно;
при canonical-режиме исходная ошибочная строка сохраняется в base64.
Неизвестные заклинания, поля и значения не исключаются по поддержке DND-NCFU.

Есть два разных результата:

- **Проверка и индекс**: полная статистика, manifest в `members.sqlite`, цепочки
  SHA строк, компактные индексы событий и ссылки filtered. Это **не полное B-хранилище**:
  исходные тексты raw не сохраняются этим режимом. Оригинальный архив остаётся
  у владельца и на сервере авторов; его SHA позволяет проверить идентичность.
- **Canonical**: каждая строка сохранена отдельной JSON-обёрткой в gzip с исходными
  значениями, расположением, SHA, ролью/основанием и явным отсутствием approval.
  Исходный `.tar.gz` не изменяется. Это хранение данных, не обучение или SFT admission.

Облачный workspace перед этим этапом имел менее1ГБ свободного места: полный
архив7,7ГБ и полное каноническое хранилище туда не помещаются. Поэтому здесь
используется индекс с лимитом240МБ и резервом192МБ свободного места. Автоматическая
проверка отклонила вариант без ограничения дополнительного вывода; он заменён
ограниченным режимом без сохранения дополнительных filtered-файлов.
Нельзя объявлять такой аудит полным локальным хранением всех raw-полей.

## Обработка уже скачанного архива на Windows

Модель, Ollama, GPU и Torch для этого не требуются. Новый tools-пакет можно
распаковать отдельно от игры; актуальный код также находится в ветке PR3.
Выполнять из корня проекта либо распакованного tools-пакета:

```powershell
$rawArchive = "D:\Projects\DND-NCFU-data\datasets\fireball\raw\fireball-anonymized-nov-28-2022-kfdjl.tar.gz"
.\.venv\Scripts\python.exe -m training.fireball_raw --archive $rawArchive --canonical --link-index --max-output-mib 32768 --output "D:\Projects\DND-NCFU-data\fireball-raw-canonical-01"
```

Путь к архиву заменить, если он лежит в другой папке. Для отдельного tools-пакета
использовать `py -3.12` вместо пути к игровому `.venv`. Нужен диск со свободным
местом под результат;32768МиБ — верхний бюджет вывода, не обязательный расход
и не оценка размера результата. При достижении бюджета/резерва программа
останавливается с ошибкой, не выдавая незавершённый проход за COMPLETE.
Canonical-обёртки обычно объёмнее исходных сжатых событий. Платных операций нет.

Сначала можно выполнить только аудит и получить оценку исходного объёма:

```powershell
py -3.12 -m training.fireball_raw --archive $rawArchive --link-index --max-output-mib 240 --output "D:\Projects\DND-NCFU-data\fireball-raw-audit-01"
```

Не запускать оба режима в одну папку: source-binding фиксирует архив и режим.
Завершённые members при повторе сверяются по hash и не считаются повторно.
Полное чтение gzip/tar при возобновлении всё равно необходимо; произвольный
HTTP offset внутри внешнего gzip не является безопасным способом продолжения.
Если canonical-проход прерван внутри файла, `.partial` сохраняется под именем
`.interrupted-*`, после чего источник перечитывается. Состояние между commit
метаданных и rename восстанавливается только при совпадении ожидаемого SHA.
Оригинал и незавершённые копии автоматически не удаляются.

## Связи и подготовка дальнейшей разметки

После полного завершения индексного прохода:

```powershell
py -3.12 -m training.fireball_raw_links --root "D:\Projects\DND-NCFU-data\fireball-raw-audit-01" --output "D:\Projects\DND-NCFU-data\fireball-raw-links-01"
```

Связующий модуль проверяет каждый before/after/state/command index против
исходной последовательности соответствующего raw-боя. Сохраняет положения,
типы, роль/основание и автора, не угадывая DM по author_bot=False.
`native-filtered-reference-ledger.jsonl.gz` — полная очередь таких связей;
она не содержит тел raw-сообщений и не заменяет канонические данные.
Вывод ограничен128МБ с резервом192МБ; незавершённая очередь не имеет COMPLETE-report.

Необязательный `--hf-root` указывает каталог прежних наблюдений FIREBALL.
Совпадения нормализованного содержимого помечаются только кандидатами:
ни авторство, ни splits, ни approval прежнего HF автоматически не переписываются.
Native-пара raw/filtered имеет собственную прямую provenance по архиву и имени боя.

Отправлять весь7,2ГиБ архив в чат или GitHub не требуется. Для проверки локального
результата достаточно `report.json` и контрольной суммы исходного архива:

```powershell
Get-FileHash $rawArchive -Algorithm SHA256
```

Проверка файла пользователем не является человеческим одобрением игровых ответов.
Роли аккаунтов не доказывают авторство текста или качество рассказчика.
