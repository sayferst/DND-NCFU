## Реальные эпизоды

`training.capture_session` читает только явно выбранный JSON unified-save30/31.
До чтения нужны два флага: разрешение владельца кампании и соответствующих
участников. Нет фонового сбора, автоматической отправки или доступа к реальным
сейвам при запуске игры. Флаги допустимы лишь после фактического согласия.

Из PowerShell в папке проекта, после получения согласий:

```powershell
.\.venv\Scripts\python.exe -m training.capture_session --input ..\DND-NCFU-data\approved-save-copy.json --output ..\DND-NCFU-data\episodes-001.jsonl --detailed-episodes --confirm-owner-consent --confirm-participant-consent
```

Выходной файл должен быть новым. Источник не меняется. Коллектор проверяет полный
replay, восстанавливает состояние перед **каждой настоящей транзакцией**, затем
связывает narration по индексу хода с правильной квитанцией. Сохраняются публичный
контекст и ресурсы до/после, намерение, план, команда, D20, квитанция, отдельный
текст/модель и rule findings. Авторская private_plot и скрытые кошельки не
входят в публичный снимок. Свободный текст всё равно требует проверки на
персональные данные: фильтр не доказывает полной анонимности.

Без `--detailed-episodes` получаются кандидаты gm-sft-v1 с контекстом до/после.
Review остаётся pending, rights unknown. Непроверенные ответы DeepSeek или Faun
не становятся обучающими автоматически; fixture-модель явно помечается synthetic.
`training.schema` продолжает запрещать допуск синтетики и записей без
одобрения/прав. Повторная генерация прозы не создаёт вторую транзакцию.

## Автоматические предложения

[rule-suggestions-800-v2.jsonl](rule-suggestions-800-v2.jsonl) содержит ровно800
предложений для оставшихся после сбалансированной ручной выборки сценариев.
Происхождение RULE_LABELED/HUMAN_REVIEW_REQUIRED, uncertainty и sampling_version2
отделены от human_approved/train_admitted; оба флага всегда false.
Правила консервативны: синтетический текст условий не выдаётся за сериализованное
игровое состояние. Там, где есть реальный save, факты проверяются через replay
коллектора. Спорные и не реализованные механики остаются для ручной проверки.

Без модели, в новый файл:

```powershell
.\.venv\Scripts\python.exe -m training.suggest_annotations --output ..\DND-NCFU-data\suggestions-v2-001.jsonl
```

После отдельной установки Faun можно явно добавить `--local-model
hf.co/limloop/MN-12B-Faun-RP-RU-GGUF:Q4_K_M --limit 20` к той же команде.
Локальная оценка имеет отдельную закрытую схему, источник AI_SUGGESTED и
неопределённость. Она не меняет rule proposal и не подтверждает ревью человека.
Неустановленные/remote/cloud-модели не вызываются, pull и платного fallback нет.
В текущем артефакте реальных AI-предложений0 — Faun здесь не установлена.
