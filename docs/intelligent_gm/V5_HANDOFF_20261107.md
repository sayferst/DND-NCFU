## Важные ограничения

1. Корпус новый синтетический. Исходный индекс — происхождение/доступные названия,
   не реальные сыгранные эпизоды и не подтверждённые исполнения production Engine9.
   Все human_reviewed=false. Не скрывать это и не обещать идеальную литературность.
2. Исходной SQLite Engine9 на 27 426 записей нет. Реально доступна другая проектная
   `data/corpus_knowledge/cards.sqlite3`: 19 000 cards. В новом ZIP только индекс 2 400.
   `catalog.py` честно различает индекс и известную read-only схему проекта.
3. Предыдущий LoRA V1 реально обучался по DOCX: 55 шагов/880 train/1 эпоха,
   1413.9758 секунд, mean loss 1.3542982469905507, eval loss 1.193,
   peak allocated 23 772 716 544 байта. Оригинал 15/20, LoRA 14/20,
   runtime не одобрен. Первичных логов и адаптера RAR здесь нет: цифры из отчёта,
   их байты в этой сессии не проверены. Не писать «Faun ещё никогда не обучали».
4. База limloop/MN-12B-Faun-RP-RU, ревизия
   bdfc761b14feb9dd03ef158a4d337fc1cf5fd183. Новый адаптер начинать с базы, не V1.
5. Общие атомарные правила неизбежно пересекаются с историческими T02–T24;
   точные старые prompts держать отдельно, близкие сюжетные копии проверить.
   Регрессии уже использованы при разработке: это не независимая оценка новых способностей.
   T02–T04 восстановлены из описания DOCX, не точные исходные запросы; не смешивать
   их с историческими 20 бинарными оценками.
6. MinHash-поиск приближённый; нулевые совпадения не доказывают отсутствие всех утечек.
   Поверхностная проверка языка не заменяет смысловую редактуру. Ответы шаблонные;
   выборочная ручная проверка самим ассистентом ещё нужна для финальных текстов.
7. 5 эпох — верхний план, не обещание уложиться в 8 часов или 500 рублей.
   На масштабе 26 880 train старая скорость может дать около 12 часов на эпоху;
   это грубое масштабирование, реальная скорость V5 неизвестна. Не запускать оплату.
8. Не менять игру, сохранения и прежние релизы. Не запускать GPU без разрешения.
   Не скачивать большие модели и не передавать приватные данные наружу.

## Стартовые команды в распакованном пакете

В корне `DND_NCFU_V5_HANDOFF_20261107`:

```bash
python -m pytest -q tests/test_faun_v5.py
python -m training.faun_v5.validate --dataset dataset_working --output quality-recheck.json
python -m training.faun_v5.tokenize --dataset dataset_working --tokenizer tokenizer --output dataset_working/reports/tokenization.json --independent
python -m training.faun_v5.build --source inputs --output rebuilt_dataset
```

Токенизация требует CPU окружение Transformers 5.3.0 + tokenizers 0.22.2.
Полный hash-locked requirements-faun-cpu.lock в пакете. Для проверки без torch
можно задать USE_TORCH=0. Установка окружения — отдельно от игровой .venv.
Никакие команды в этом документе не разрешают старт платного GPU.
