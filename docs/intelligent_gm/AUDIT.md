# Интеллектуальный мастер: аудит 03.11.2026

Источник: рабочая ветка `feature/unified-rpg-automatic-gm`, актуальный checkout
получен из GitHub. Исходный `main` содержит только README; соседняя устаревшая
копия `DND-NCFU-public` не используется. Изменения продолжают действующий код.

Прямое поручение владельца от 03.11 отменяет исторические остановки между
этапами из AGENTS. Бюджет тестирования по новому ТЗ — до 1500 ₽/месяц,
но платных операций в этой работе не разрешено. Фактические расходы — 0 ₽.

Проверенные точки расширения:

- `UnifiedSession`: журнал разрешённых операций, атомарный откат и полный replay.
- `catalog_engine.Engine`: реальный инвентарь, физические ID, статусы и время.
- `gameplay_session.perform`: идемпотентность по request_id и ресурсный commit.
- `domain.receipts`: квитанция, которую рассказчик читает без повторного хода.
- `ui.narrator_panel`: локальные действия перед модельным планировщиком.
- `training`: существующие admission/split/PEFT/export/localhost serve сохранены.

Проверены актуальные FINAL_EXECUTION, ruleset, training README/schema/prepare/
train/evaluate/export/serve, Ollama и граница UI. Существующий train/serve
передаёт Qwen-specific `enable_thinking=False`; отдельный Faun-профиль необходим.
19000 RAG-карточек не являются SFT-корпусом. Обучение и качество живых моделей
в этой среде ещё не измерены. Ноутбук владельца недоступен инструментам среды.

Старые обработчики gameplay1–5, каталоги1/2, fixtures, ключи, шлюз, бюджеты,
сертификаты и сетевые настройки не меняются. Новая политика свободных действий
хранится в origin новых кампаний catalog3. При чтении старого origin применяется
policy0: исторические команды не переосмысливаются новым интерпретатором.
