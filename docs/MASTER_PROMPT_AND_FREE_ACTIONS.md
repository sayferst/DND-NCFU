# Инструкция мастера, пожелания к миру и свободные попытки

Пакет 1N.6, 19 октября 2026. Продолжение существующей игры, без новых зависимостей
или локальных весов. По умолчанию игра работает без облака. Генерация RouterAI
оплачивается отдельно; подписка ChatGPT Plus её не оплачивает.

## Модель и подключение

Для первой проверки выбран `deepseek/deepseek-v4-pro-0813` — ID со скриншота
пользователя. Это рекомендация для пробы, а не измеренное превосходство над Flash.
Вторая показанная модель — `deepseek/deepseek-v4-flash-latest`; она дешевле по
скриншоту, но alias latest может поменять версию. Сравнивать нужно один и тот же
диалог, соблюдение фактов, реакцию на отказ, время и фактическое списание.
Автоматической замены Pro на Flash или другого провайдера игра не делает.

Тарифы ниже переписаны со скриншотов, не подтверждены живым API. Реальный каталог
и кабинет имеют приоритет:

| Модель | Вход, ₽/млн | Выход, ₽/млн | Один запрос: 5000 входных + 800 выходных |
|---|---:|---:|---:|
| Pro 0813 | 34 | 102 | 0,2516 ₽ |
| Flash Latest | 5,98 | 11 | 0,0387 ₽ |

Это пример одного запроса, не цена игрового хода и не финансовая гарантия.
Некоторые попытки требуют подбора проверки и затем рассказа — два запроса.
Повтор отклонённого рассказа тоже расходует токены. Размышления модели могут
занимать часть выходного лимита. Прайс, маршрутизация и комиссии могут меняться.

Если ключ был опубликован в чате, отзовите его и создайте новый обычный ключ
RouterAI. В игре вводится только новый ключ; не мастер-ключ и не MCP-токен.
Установите у сервиса положительный месячный лимит до 2000 ₽, проверьте валюту
и отключите автопополнение. Приложение читает лимит перед каждым обращением,
но не заменяет биллинг сервиса. Не присылайте ключ или полный ответ аккаунта.

В игре откройте **Рассказчик**, включите мастера и свободный текст, выберите
**Облако: RouterAI**, загрузите модели/цены. Выберите Pro 0813, если он есть в
реальном каталоге. Вставьте ключ в скрытое поле, разрешите отправку сцены и
нажмите **Применить настройки облачного API**. Базовый адрес уже задан кодом:
`https://routerai.ru/api/v1`, без запятой. Только применение настроек не вызывает
модель. Дополнительная переменная окружения игры — `RPG_VKR_ROUTERAI_API_KEY`;
`ROUTERAI_API_KEY` из отдельного стартера ею не является.

## Текстовый файл поведения

Общая инструкция: `prompts/master_system_prompt.txt`. Она читается перед новым
запросом, без перезапуска окна. Для личных правок используйте
`prompts/master_system_prompt.local.txt`: он имеет приоритет и исключён из Git,
поэтому обновление проекта не перезапишет личную инструкцию.

```powershell
Set-Location D:\Projects\DND-NCFU
if (!(Test-Path .\prompts\master_system_prompt.local.txt)) {
    Copy-Item .\prompts\master_system_prompt.txt .\prompts\master_system_prompt.local.txt
}
notepad .\prompts\master_system_prompt.local.txt
```

Сохраните файл в UTF-8. Можно менять тон, роль, стиль и предпочтения повествования.
Пустой, слишком большой или некорректно закодированный файл останавливает запрос
с понятным сообщением; другого скрытого промпта вместо него не подставляется.
Инструкция — данные для модели, не исполняемый Python. Правила расчёта и проверки
состояния остаются в коде. В сохранённой прозе и диагностике есть SHA-256 базовой
системной инструкции, включая ограничения движка. Повтор исправления использует
ту же базу с добавлением причины отказа. Это настройка запросов, не обучение весов.

DeepSeek получает бюджет 900 выходных токенов на рассказ, 1200 на единственное
исправление. Предел текста сцены по-прежнему 1500 символов; нужен связный ответ
по существу, а не длинный монолог. Параметр лимита RouterAI передаётся только
при подтверждении его поддержки в загруженном каталоге.

## Герой и пожелания к миру

При создании героя теперь два независимых поля:

- биография, внешность и прошлое героя — до 6000 символов;
- мир, жанры и настроение — до 3000 символов, можно оставить пустым.

Пример пожеланий: «Приключенческое фэнтези, редкая магия, речные города,
торговля и интриги гильдий. Обычные люди со своими заботами, без пророчества».
Оба поля сохраняются в ячейке/экспорте SQLite и передаются отдельно от системной
инструкции. Пожелания не выдают предметы, способности или деньги и не стирают
установленные факты. Раздел Рассказчик показывает их в контексте. Анкета
прокручивается, а кнопки создания/отмены остаются доступны.

Этот пакет **ещё не создаёт новый мир целиком**: стартовая деревня и список мест
сохраняются. Пожелания влияют на доступное повествование. Следующий этап — отдельный
генератор структурированного мира, регистрация новых NPC/локаций, постоянная память
и постепенное раскрытие секретов. Одного разрешения «придумывать всё» в промпте
для корректного изменения мира недостаточно.

## Попытка, проверка и результат

Ввод остаётся свободным. Явные распознаваемые атаки прежде всего идут в боевой
движок. Формы «вонзаю», «убиваю», «добиваю» теперь также распознаются. Для проверки
создайте разведчика с ножом и напишите «вонзаю нож стражнику в горло». Подтверждение
нападения сообщает о начале схватки; моральное оправдание не требуется.
Броски определяют попадание/урон/ответ. Текст о намерении убить не гарантирует
победу; отдельные смерть/труп/обыск всё ещё не реализованы.

Для некоторых других попыток предлагается проверка с возможностью отмены:

| Пример | Характеристика | Сложность |
|---|---|---:|
| Взобраться на стену, сдвинуть тяжесть | Сила | 15 |
| Перепрыгнуть канаву | Ловкость | 15 |
| Выдержать холод или нагрузку | Телосложение | 15 |
| Расшифровать надпись | Интеллект | 15 |
| Вспомнить сведения | Интеллект | 10 |
| Прислушаться | Мудрость | 10 |
| Изложить убедительные доводы | Харизма | 15 |

Это авторское назначение категории/сложности. Формула кубик + модификатор
характеристики опирается на реализованное подмножество SRD 5.2.1. Полные владения
навыками, помеха/преимущество и все правила SRD здесь не добавлены.

Для нетипичной формулировки попытки в облачном профиле DeepSeek возможен смысловой
подбор: «пытаюсь протиснуться между створками». Модель предлагает только категорию
из допустимых, например Ловкость. Приложение назначает сложность и просит разрешить
бросок. Обычная беседа и распознанные простые действия не требуют этого этапа.
Если модель не предлагает проверку, продолжается обычный рассказ. Неверный формат
или категория останавливает запрос и возвращает текст; автоматического повтора
этого этапа нет. Отмена/смена сессии исключает применение запоздавшего предложения.

Отказ от броска сохраняет черновик и RNG. Подтверждение даёт один локальный бросок:
итог виден сразу, арифметика справа. Рассказ затем получает уже рассчитанный исход.
Повтор генерации или загрузка не бросают заново. Во время боя такими проверками
нельзя заменить боевое действие. Успех убеждения не является автоматической сделкой,
успех общей проверки не создаёт добычу, новый переход или предмет.

Полное понимание любого текста и механика любого замысла не гарантированы.
Генерируемый мир, произвольная магия, кража, добыча и долгосрочные планы фракций
требуют следующих модулей. Модель не получает права создавать их последствия прозой.

## Обновление локальной папки

Сохраните игру в ячейку и закройте окно. В PowerShell:

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location D:\Projects\DND-NCFU
    $saveDir = 'D:\Projects\DND-NCFU-data\saves'
    if (Test-Path $saveDir) {
        $backupRoot = 'D:\Projects\DND-NCFU-data\backups'
        New-Item -ItemType Directory -Path $backupRoot -Force | Out-Null
        $backupDir = Join-Path $backupRoot ('before-master-config-' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff'))
        Copy-Item -LiteralPath $saveDir -Destination $backupDir -Recurse
    }
    git switch setup/development-environment
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось переключить ветку.' }
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Обновление не получено. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\repair_fixture_checkout.py
    if ($LASTEXITCODE -ne 0) { throw 'Эталон не восстановлен. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\check.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка не прошла. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\run_game.py
}
```

SQLite читает12–17. Старые файлы/факты/проза/имена/RNG сохраняются; fixture16
создана неизменённым ff11c31 до правок. Отдельный стартер не заменяет игру, его SDK
устанавливать в игровое окружение не нужно. Три оригинальных документа и их хеши
сохранены в docs/research/routerai_starter; их сведения о старой версии8 исторические.

Автотесты используют синтетические ответы HTTP, а не настоящую модель. Скорость,
грамматика и списание DeepSeek требуют реального ручного теста с новым ключом.
