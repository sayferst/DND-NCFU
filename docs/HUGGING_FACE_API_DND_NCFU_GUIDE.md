# Hugging Face API для DND-NCFU: пошаговая инструкция

**Дата проверки:** 3 ноября 2026. **Среда:** Windows 10/11, PowerShell 5.1+.
**Цель:** безопасно проверить доступность моделей Qwen, возможность запросов через Hugging Face, расходы и последующее подключение к игре. Документ не означает, что новая интеграция уже реализована.

## 1. Главное о бесплатности

**Hugging Face Hub и Hugging Face Inference Providers — разные услуги.**

- Скачать открытые веса моделей Qwen можно бесплатно при соблюдении лицензии.
- Вызов модели через облачный API выполняется на чужих вычислительных мощностях и обычно оплачивается.
- **По официальной документации на 03.11.2026, Free-аккаунты не получают ежемесячных включённых кредитов Inference Providers.** Ранее упоминавшиеся $0,10 для Free уже не актуальны.
- В PRO включены $2 в месяц, но сама подписка платная. Team и Enterprise получают $2 на пользователя в месяц в рамках своих подписок.
- Иногда у конкретного провайдера бывает временный признак `is_free=true`, но это не обещание бесплатной постоянной работы.
- Чтобы воспользоваться маршрутизацией с оплатой через Hugging Face, требуются соответствующие кредиты. При использовании своего ключа внешнего провайдера оплата идёт ему, и кредиты Hugging Face не применяются.

Официальные тарифы: https://huggingface.co/docs/inference-providers/pricing

## 2. Выбор модели для DND-NCFU

| Модель | Открытые веса | Доступность Inference Providers | Рекомендация |
| --- | --- | --- | --- |
| Qwen/Qwen3.5-4B | Да, Apache-2.0 | Не подтверждена; проверить каталог API | Основной кандидат для дальнейшего обучения LoRA и локального запуска |
| **Qwen/Qwen3.5-9B** | Да, Apache-2.0 | Подтверждена у DeepInfra, Together, OVHcloud | Кандидат для облачного сравнения качества |
| Текущий DeepSeek в DND-NCFU | Используется через RouterAI | HF API не нужен для текущей игры | Сохранить как эталон литературного качества |

Ссылки: https://huggingface.co/Qwen/Qwen3.5-4B и https://huggingface.co/Qwen/Qwen3.5-9B .

**Не путайте доступность карточки модели на Hub с возможностью вызова через облачный API.** Провайдер может добавить или убрать размещённую модель в любое время.

## 3. Пример стоимости Qwen3.5-9B

По публичной таблице Inference Providers у DeepInfra на момент проверки: вход $0,10 / 1 млн токенов, выход $0,15 / 1 млн токенов. Провайдеры могут предлагать другие ставки.

Условный ход игры: 8 000 входных + 1 000 выходных токенов.

`C = (8000/1 000 000)·$0,10 + (1000/1 000 000)·$0,15 = $0,00095`.

Это **теоретическая стоимость**, не гарантированный расход. Длинный контекст, ответы с рассуждениями, дополнительные вызовы и смена модели увеличивают затраты. Фактическое списание сверять в Billing.

Актуальные модели и ставки: https://huggingface.co/inference/models?model=Qwen%2FQwen3.5-9B .

## 4. Создание аккаунта и безопасного токена

1. Откройте https://huggingface.co/join и зарегистрируйтесь.
2. Откройте https://huggingface.co/settings/billing . Проверьте доступный баланс. Если у вас Free, не предполагайте наличия бесплатных кредитов.
3. Откройте https://huggingface.co/settings/tokens .
4. Создайте **Fine-grained** токен с минимальным правом **Make calls to Inference Providers**.
5. Не выдавайте права записи в репозитории.
6. Никогда не отправляйте токен тестировщикам и в чат. Не записывайте его в Git, скриншоты, Setup или файл настроек, включённый в дистрибутив.
7. Для отмены токена используйте Revoke на странице токенов.

## 5. Проверка без генерации и расходов

Откройте Windows PowerShell. Следующий код проверяет аутентификацию и читает список доступных моделей. **Он не отправляет запрос на генерацию текста.**

```powershell
$ErrorActionPreference = "Stop"

$secure = Read-Host "Вставьте HF API-токен (ввод скрыт)" -AsSecureString
$ptr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure)
try {
    $token = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($ptr)
} finally {
    [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($ptr)
}

try {
    $headers = @{ Authorization = "Bearer $token" }

    # Проверяем токен. Не показываем персональные поля аккаунта.
    $null = Invoke-RestMethod -Uri "https://huggingface.co/api/whoami-v2" -Headers $headers -Method Get -TimeoutSec 30
    Write-Host "Токен принят."

    # Список активных chat-моделей. Не запускает генерацию.
    $catalog = Invoke-RestMethod -Uri "https://router.huggingface.co/v1/models" -Headers $headers -Method Get -TimeoutSec 30

    foreach ($id in @("Qwen/Qwen3.5-4B", "Qwen/Qwen3.5-9B")) {
        $item = @($catalog.data | Where-Object { $_.id -eq $id }) | Select-Object -First 1
        if ($null -eq $item) {
            Write-Host "$id отсутствует в каталоге API"
            continue
        }
        Write-Host "$id найден"
        $item.providers | Where-Object { $_.status -eq "live" } | Select-Object provider, status, pricing, is_free | Format-List
    }
} finally {
    Remove-Variable token, headers, secure -ErrorAction SilentlyContinue
}
```

**Как понимать ответ:** найденный токен означает корректную аутентификацию, но **не подтверждает наличие денежных кредитов**. Поле `status=live` означает опубликованную доступность провайдера, но не гарантию успешного вызова. Поле `pricing` даёт опубликованные тарифы. `is_free` может отсутствовать; значение `true` относится к конкретному предложению провайдера.

Источники: https://huggingface.co/docs/inference-providers/hub-api и https://huggingface.co/docs/hub/security-tokens .

## 6. Проверка реального ответа — только с согласия на списание

Выполняйте следующий этап **только после проверки баланса и если готовы оплатить хотя бы один запрос**. Код не делает автоматических повторов. Для модели Qwen3.5-9B выбран конкретный провайдер DeepInfra; сначала подтвердите его `status=live` через предыдущий шаг.

```powershell
$ErrorActionPreference = "Stop"
$ok = Read-Host "Запрос может стоить денег. Для продолжения введите ОПЛАТИТЬ"
if ($ok -ne "ОПЛАТИТЬ") {
    Write-Host "Отмена. Платный запрос не отправлен."
} else {
    $secure = Read-Host "HF API-токен (ввод скрыт)" -AsSecureString
    $ptr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure)
    try {
        $token = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($ptr)
    } finally {
        [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($ptr)
    }

    try {
        $request = @{
            model = "Qwen/Qwen3.5-9B:deepinfra"
            messages = @(
                @{ role = "system"; content = "Ты рассказчик фэнтезийной RPG. Не изменяй подтверждённые факты мира и не запрещай логически возможные эксперименты просто из-за их нецелесообразности. Обозначай риски и цену попытки. Не объявляй успех до расчёта движка." },
                @{ role = "user"; content = "Герой владеет луком. Он хочет снять тетиву и сделать удочку. Какие варианты и последствия доступны? Ответь кратко по-русски." }
            )
            max_tokens = 200
            stream = $false
        } | ConvertTo-Json -Depth 8

        $result = Invoke-RestMethod -Uri "https://router.huggingface.co/v1/chat/completions" -Method Post -Headers @{ Authorization = "Bearer $token" } -ContentType "application/json; charset=utf-8" -Body ([Text.Encoding]::UTF8.GetBytes($request)) -TimeoutSec 90

        Write-Host "Ответ модели:"
        Write-Host $result.choices[0].message.content
        Write-Host "Использование токенов:"
        $result.usage | Format-List
    } finally {
        Remove-Variable token, secure, request, result -ErrorAction SilentlyContinue
    }
}
```

Qwen3.5 может использовать режим рассуждения, поэтому короткий лимит ответа способен оставить мало места для художественного текста. При обрезанном ответе сначала проверьте режим thinking, не повышая расходы автоматически.

После вызова откройте https://huggingface.co/settings/billing и зафиксируйте фактический расход. Статистика может обновляться с задержкой.

## 7. Частые ошибки

| Код / симптом | Вероятная причина и действие |
| --- | --- |
| HTTP 401 | Токен неверный, отозван или не подходит. Выпустите новый Fine-grained токен. |
| HTTP 403 | Недостаточно прав; модель/регион/провайдер ограничены. Проверьте доступ без выключения TLS. |
| HTTP 402 / insufficient credits | Нет доступных кредитов. Не выполняйте бесконечные повторы. |
| HTTP 404 | Неверный идентификатор модели или провайдера. Проверьте `/v1/models`. |
| HTTP 429 | Превышение лимита скорости. Уменьшите число тестов. |
| HTTP 500–504 | Ошибка или перегрузка удалённого сервиса. Не повторяйте платный POST автоматически. |
| Тайм-аут или TLS | Проверить интернет, системное время, сертификаты и прокси. Не отключать проверку сертификатов. |
| Модель есть в Hub, нет в API | Её можно скачать, но провайдер пока не обслуживает этот model ID. |
| Пустой ответ | Возможное обрезание thinking-ответа или нарушение формата; проверьте поля результата. |

Для диагностики достаточно HTTP-кода, ID модели, даты и обезличенной причины. Не присылайте полный заголовок Authorization.

## 8. Как добавить провайдера в DND-NCFU

**Нынешний мастер DeepSeek через RouterAI должен остаться рабочим.** Не меняйте ему URL вручную и не удаляйте защищённые ключи.

План изменений в проекте:

1. Новый серверный провайдер `huggingface` с базовым URL `https://router.huggingface.co/v1`.
2. Токен сохранять только на машине владельца, используя защищённое хранение Windows; не включать его в персональный Setup.
3. Перед использованием проверять список актуальных моделей и провайдеров.
4. Ввести явно выбранный `model_id`, ограничения контекста и максимальных выходных токенов.
5. Различать модель-сказителя и математический Conflict Engine. Python вычисляет фактические ресурсы, D20, полезности, риски, действия NPC и последствия.
6. Логировать request ID, модель, провайдера, количество токенов, ответ, отказ и неопределённые расходы. Не сохранять секреты в логах.
7. Выдерживать общий бюджет тестирования 1500 ₽/месяц на сервере, с отдельной квотой на тестировщика.
8. Сначала тестировать новую интеграцию в режиме сравнения без изменения кампании. Только после тестов разрешить использовать HF как альтернативного мастера.

Не путайте **дообученную локальную Qwen** с публичной Qwen у Hugging Face: обученный адаптер не появится сам собой у провайдера. Для него понадобится свой процесс инференса или отдельное платное развёртывание.

## 9. Как проверить, подходит ли Qwen для игрового мастера

Подготовьте 20–30 воспроизводимых сцен DND-NCFU. На одинаковых исходных данных сравните DeepSeek и Qwen:

- Рукавица: предмет описан мастером и не должен бесследно исчезать при попытке его взять.
- Лук → удочка: допустимая попытка должна иметь цену и возможные частичные результаты.
- Путешествие к поселению: каждый ход должен соответствовать перемещению в мире; нельзя бесконечно повторять описание дороги.
- Тренировка: нельзя бесплатно увеличивать Силу словами; действует система прогрессии.
- Торговля: деньги и товары принадлежат реальным участникам.
- Продовольственный кризис: разные решения изменяют снабжение, безопасность, казну и отношения с NPC.
- Переговоры фракций: предложение должно учитывать интересы обеих сторон.

Для каждой сцены зафиксируйте: соответствие фактам, число необоснованных отказов, качество русского текста, скорость, цену, количество токенов, наблюдаемые последствия и оценку тестировщиков.

Переходить на Qwen только при достаточных результатах измерений. Художественный стиль и математическая корректность оцениваются отдельно.

## 10. Обучение и запуск на ваших компьютерах

**Основной ноутбук:** Intel i5-1135G7, 16 ГБ RAM, Intel Iris Xe. Годится для разработки, проверки API и экспериментов с небольшим квантованным GGUF. Для обычного обучения больших LLM на CUDA это неподходящая машина.

**Компьютер друга:** предпочтителен для LoRA/QLoRA, если имеется достаточно VRAM на GPU. До выбора 4B или 9B узнать точное название видеокарты, VRAM и доступность GPU. Для обучения брать исходные веса Qwen и проверенный датасет, не GGUF-квантовку.

**Старый ноутбук:** можно использовать как хост шлюза DND-NCFU, SQLite и математического Conflict Engine; языковую модель запускать там только после измерения RAM, задержки и длительной стабильности. Нельзя выставлять незащищённый LLM API в интернет.

**Стратегия:** сохраняем DeepSeek как качественного рассказчика; экспериментируем с Qwen и обученным агентом; математический движок конфликтов делаем на Python без обязательных платных LLM-вызовов.

## 11. Итоговый порядок действий

1. Зарегистрироваться на HF и посмотреть Billing, не покупая подписку автоматически.
2. Создать узкоправный Fine-grained токен.
3. Выполнить только GET-проверки из раздела 5.
4. Если есть подходящие кредиты и пользователь готов к расходу, сделать один POST-тест раздела 6.
5. Сравнить ответы Qwen с DeepSeek на фиксированных игровых сценах.
6. Начать с загрузки и локальной проверки Qwen3.5-4B GGUF.
7. Уточнить характеристики GPU друга и подготовить обучение LoRA/QLoRA.
8. Разработать математический Conflict Engine независимо от выбора языковой модели.
9. После обучения выбрать лучший вариант инференса: собственный ПК, старый ноутбук, сервер друга или оплата облака.
