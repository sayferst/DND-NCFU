# Хост и сборки владельца

Все BAT запускаются в исходной папке `Команды`, не из перемещённых копий.

| Файл | Назначение | Результат |
| --- | --- | --- |
| START_HOST.bat | Запуск шлюза и ngrok | Открытая консоль; дождаться трёх HTTPS-проверок |
| BUILD_SETUP.bat | Аккаунтная сборка для тестировщика | dist/Release/setup.exe |
| BUILD_EXE.bat | Личный admin EXE с привязкой владельца | dist/Owner-…; передавать всю папку только владельцу |
| UPDATE_NGROK.bat | Обновление частной копии ngrok | Проверенный официальный агент |

Сначала остановите хост Ctrl+C, обновите исходники через git pull --ff-only,
затем запустите START_HOST и дождитесь готовности. Во втором окне запустите BUILD_SETUP.
Тестировщику отправляйте Setup и контрольную сумму, профиль — отдельным приватным каналом.
Не публикуйте owner EXE, привязки, ключи, account-mode.json и данные сервера.

update_and_build.ps1 проверяет текущую release-ветку, fetch/fast-forward,
сохраняет локальные изменения и запрещает замену кода под работающим хостом.
build_windows.ps1 запускает проверки, PyInstaller и Inno Setup;
tester_host.py управляет доступом, хостом и аккаунтной упаковкой. Новых сборщиков нет.
Имена бюджетов/паролей не задаются публичной документацией.

Последняя подтверждённая владельцем работа хоста: ngrok3.39.13, подписанный адрес,
три HTTPS-проверки. Доступность текущего хоста этим документом не гарантируется.
