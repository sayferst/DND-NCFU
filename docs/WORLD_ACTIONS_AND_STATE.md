# Действия меняют мир, а мастер рассказывает результат

Пакет 1N.7, 19 октября 2026. Дополняет
[TXT мастера и пожелания к миру](MASTER_PROMPT_AND_FREE_ACTIONS.md).

Присланный диалог Flash показал расхождение: рассказ описывал украденные яблоки
и бегство, но ни инвентарь, ни место, ни отношения не менялись. Это дефект
связи рассказчика с состоянием игры; красивый текст или обучение весов сами
по себе его не исправляют. Старую прозу нельзя превратить в достоверные вещи
задним числом: она могла противоречить сама себе.

## Как теперь выполняется ход

1. DeepSeek предлагает структурированный план по вашему обычному сообщению.
2. Движок проверяет предметы, количество, доступность, контейнеры и путь.
3. Для завладения чужой вещью при владельце/страже предлагается бросок.
   Отмена сохраняет ввод и не расходует кубик. Уже выполненный запрос модели
   при отмене всё равно может быть платным.
4. Подтверждённая цепочка целиком меняет вещи, место и отношения свидетелей.
5. Мастер получает обновлённое состояние и оформляет результат прозой.

Неверный второй шаг не применяет первый. При неудачной проверке вся физическая
цепочка остаётся невыполненной, но живые свидетели становятся враждебными.
Ошибка рассказа не отнимает уже полученные вещи и не бросает кубик повторно.
Пустой план на явное «беру и убегаю» останавливает ход с сохранением ввода.
Непривычная формулировка может потребовать подтверждения понятого плана,
а не ввода заранее заданной команды. Отрицание, вопрос и цитата не разрешают
модели незаметно выполнить перенос или уход.

## Поддержанные операции

Это общие операции над зарегистрированными предметами, а не команда кражи яблок:

| Действие | Изменение состояния |
|---|---|
| Взять вещь/часть стопки/всё содержимое | Новый держатель и точное количество |
| Переложить | Содержимое оказывается в доступном контейнере |
| Передать NPC рядом | Меняется держатель; подарок своей вещи меняет владельца |
| Бросить/оставить | Вещь остаётся в текущем месте, вместе с оставшимся содержимым |
| Перейти | Связный путь по соседним местам; прежние NPC остаются позади |
| Осмотреть контейнер | Реальное содержимое, без появления новых предметов |
| Посмотреть инвентарь | Сохранённые вещи и количества, без выдумывания моделью |

Держатель и собственник различаются: кража не делает чужую вещь законным подарком.
Один бросок Ловкости со сложностью 15 проверяет рискованную цепочку. Это упрощённое
авторское правило (homebrew), не полная система кражи/погони SRD. Мир не моделирует
автономное преследование. Враждебность свидетелей сохраняется, автоматическая
смерть или схватка не назначаются рассказом.

Мастер может зарегистрировать до двух новых соседних мест по заявленному пути,
например лесную тропу за дорогой. В цепочке до шести шагов; переходы проверяются
по соседству. Это расширение текущего района, а не случайный новый мир при старте.
Известные оставленные вещи сохраняются с местом; их доступность проверяется
при возвращении. Старый собеседник не остаётся рядом после ухода героя.

Стартовые 12 яблок и плетёная корзина — авторские данные пилота. Отдельный тест
применяет те же операции к сумке с семью письмами и переносит часть содержимого.
Новые предметы/NPC из одного художественного упоминания не возникают.
Старые бинты, золото, классовый комплект и корзина поручения пока обслуживаются
прежними правилами; их произвольный перенос этим пакетом не унифицирован.
Торговля, магия, смерть/обыск, генератор новых NPC и ConflictSolver требуют
отдельных моделей состояния. Полная механика любого замысла пока не заявляется.

## Включение и проверка Windows

Сохраните текущую игру в ячейку и закройте окно. Этот блок получает изменения
с GitHub именно в локальные файлы на D:, создаёт копию сохранений и запускает
проверки. Ошибка останавливает дальнейший запуск.

```powershell
& {
    $ErrorActionPreference = 'Stop'
    Set-Location D:\Projects\DND-NCFU
    $saveDir = 'D:\Projects\DND-NCFU-data\saves'
    if (Test-Path $saveDir) {
        $backupRoot = 'D:\Projects\DND-NCFU-data\backups'
        New-Item -ItemType Directory -Path $backupRoot -Force | Out-Null
        $backupDir = Join-Path $backupRoot ('before-world-actions-' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff'))
        Copy-Item -LiteralPath $saveDir -Destination $backupDir -Recurse
    }
    git switch setup/development-environment
    if ($LASTEXITCODE -ne 0) { throw 'Не удалось переключить ветку.' }
    git pull --ff-only
    if ($LASTEXITCODE -ne 0) { throw 'Обновление не получено. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\repair_fixture_checkout.py
    if ($LASTEXITCODE -ne 0) { throw 'Эталон не восстановлен. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\check.py
    if ($LASTEXITCODE -ne 0) { throw 'Проверка не прошла. Сохраните вывод.' }
    .\.venv\Scripts\python.exe scripts\run_game.py
}
```

В разделе **Рассказчик** выберите **Облако: RouterAI** и
`deepseek/deepseek-v4-flash-latest`. Flash теперь предложен по умолчанию на основе
вашего положительного отзыва о прозе; сравнительное превосходство не измерялось.
Загрузите каталог, введите обычный ключ, разрешите отправку сцены и примените
настройки. Включите мастера, свободный текст и **«DeepSeek: применять действия
через проверяемый план мира»**. В обычном окне последняя опция включена заранее,
но сама по себе не включает облако и не отправляет запросы.

Опубликованный ранее ключ отзовите; новый вводите только в скрытое поле игры.
У сервиса задайте положительный месячный лимит не выше 2000 ₽. Адрес уже задан:
`https://routerai.ru/api/v1`, без запятой. ChatGPT Plus этот API не оплачивает.
Приложение проверяет данные ограниченного ключа перед каждым модельным POST;
это не независимый биллинг и не гарантия комиссии/последнего пограничного списания.

Для чистой проверки создайте нового героя, сохранив прежние ячейки. Введите
обычными словами взятие корзины и уход в лес. Согласитесь на проверку; успех
не гарантирован. При успехе проверьте:

- в таблице есть плетёная корзина и 12 яблок;
- место — лесная тропа, жительницы и стражника рядом нет;
- взятие яблок из корзины и выбрасывание корзины оставляет 12 яблок при герое;
- пустая корзина остаётся на тропе, возврат и подбор возможны;
- после сохранения и загрузки вещи, место и отношения прежние;
- «осмотреть свой инвентарь» читает реальные данные без обращения к модели.

При неудаче вещи/переход остаются прежними; виден результат броска, свидетели
реагируют враждебно. Сообщите неожиданный исход с техническим ответом, без ключа.
Исторические выдуманные яблоки автоматически не восстанавливаются.

Обычный ход агента может стоить двух запросов: план и рассказ; исправление
рассказа — ещё один. Пустой план, отмена или ошибка тоже могут оставить стоимость
уже сделанной генерации. Скриншоты цен не являются текущим прайсом. Тарифы,
реальную задержку и расход смотрите в каталоге/кабинете сервиса.
