# Интерфейс прототипа — этап 1D

Пакет завершает базовую навигацию текущего эпизода. Это ещё не интерфейс всей игры:
боевой экран, отношения NPC, формальные конфликты и исследовательский режим появятся
вместе с соответствующими механиками. Новых зависимостей и сетевых обращений нет.

## Вкладки

- **Приключение** — журнал, поиск, быстрые действия и свободный ввод.
- **Герой** — имя, характеристики, новый герой и редактор песочницы.
- **Инвентарь** — предметы, применение, покупка и продажа бинтов.
- **Задание** — текст поручения, прогресс и действие «Взять» / «Доставить».
- **Команды** — поиск по фразам и описаниям. «Подставить» переносит выбранную
  команду в поле действия; только «Отправить» выполняет её. Замена черновика требует
  подтверждения. Условия места/ресурсов проверяет прежний игровой движок.
- **Настройки** — размер текста журнала 9–20, системная/светлая/тёмная тема и сброс.
- **Сохранения** — три прежние ячейки с сохранением, загрузкой и удалением.

Сверху показаны ресурсы и текущее место; снизу — активная ячейка и наличие изменений.
Звёздочка в заголовке означает изменения игровой сессии после сохранения.
Черновик обозначен отдельно: он не входит в файл сессии.

## Клавиатура и журнал

| Комбинация | Действие |
|---|---|
| Enter в поле действия | Отправить действие |
| Стрелки вверх / вниз в поле действия | История последних 100 отправленных команд и возврат к черновику |
| Ctrl+S | Сохранить в активную ячейку; если её нет — выбрать одну из трёх |
| Ctrl+O | Выбрать занятую ячейку для загрузки |
| Ctrl+N | Создать нового героя |
| Ctrl+F | Перейти к поиску в журнале |
| Ctrl+E | Экспортировать журнал в текстовый файл |

Меню **«Сессия»** дублирует сочетания клавиш. Перезапись, удаление и потеря
несохранённой сессии по-прежнему подтверждаются с безопасным ответом «Нет» по умолчанию.
Ctrl+S не отменяет подтверждение перезаписи. Автосохранения нет.
История команд восстанавливается из загруженного журнала, без системных записей
редактора. Новый герой очищает историю, сохраняя файлы трёх ячеек.

Поиск в журнале не учитывает регистр и после конца ищет с начала. «Найти далее»
и Enter в поиске выделяют совпадение; отсутствие совпадения показано в строке состояния.
Журнал и свободный ввод остаются простым текстом — HTML не исполняется.

Экспорт — читаемый UTF-8 `.txt`, **не сохранение для продолжения игры и не набор
данных научного эксперимента**. Текст не содержит отдельной конфигурации RNG и мира.
Диалог предлагает выбрать файл; отмена ничего не меняет. Отказ записи оставляет
предыдущий файл и сессию. Экспорт в папку ячеек или файл настроек запрещён.
Экспорт не снимает признак несохранённых игровых изменений.

## Настройки чтения

По умолчанию: `D:\Projects\DND-NCFU-data\reading.json`, рядом с папкой `saves`.
При `RPG_VKR_DATA_DIR` используется этот каталог. Настройки записываются только
при изменении, вне Git и вне JSON игровых ячеек. Шрифт меняет журнал, тема — окно.
Удаление игровой ячейки не сбрасывает тему, загрузка ячейки её не меняет.

Нет доступа или файл повреждён — применяются стандартные настройки с сообщением
на вкладке. Исходный повреждённый файл при запуске не переписывается. При отказе
записи выбор действует до закрытия окна; следующая успешная настройка сохранит его.
Одновременно используйте одно окно игры.

## Ручная проверка Windows

1. Сохранить игру, закрыть старое окно. В PowerShell по одной команде:

   ```powershell
   Set-Location D:\Projects\DND-NCFU
   git pull --ff-only
   .\.venv\Scripts\python.exe scripts\check.py
   .\.venv\Scripts\python.exe scripts\run_game.py
   ```

   При ошибке остановиться. Ожидается 174 passed и успешные pip/Ruff.
2. Проверить семь вкладок и кнопки. Найти «продать бинт» в «Команды», подставить:
   журнал ещё не меняется. Отправить команду; вне рынка движок объяснит ограничение.
3. Отправить две команды, набрать черновик, нажать вверх/вниз: черновик возвращается.
4. Поставить крупный шрифт и тёмную тему; проверить чтение в своём масштабе Windows.
   Уменьшить окно, убедиться, что ввод и журнал доступны. При узком окне вкладки
   прокручиваются стрелками Qt.
5. Ctrl+S выбрать пробную ячейку: активная ячейка показана снизу и на вкладке.
   Отправить действие: появятся «есть изменения» и `*`. Повторить Ctrl+S,
   сначала отменить перезапись, затем подтвердить. Проверить Ctrl+O.
6. Ctrl+F найти слово, затем следующее совпадение. Ctrl+E сохранить текст вне папки
   ячеек и открыть его в Блокноте: кириллица и журнал читаются.
7. Закрыть и снова запустить игру: тема/шрифт восстановлены, а сессию нужно загрузить
   из ячейки. Проверить вкладки задания/инвентаря после загрузки, затем пройти
   docs/EPISODE.md. Повторить основной цикл без интернета.

Автотесты offscreen в Linux не заменяют эту проверку. После приёмки можно измерять
запуск, длинный журнал и потребление памяти на ноутбуке, оптимизируя по измерениям.
