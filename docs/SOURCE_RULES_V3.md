# Проверяемые программы исходных особенностей, версия 3

Это реализация нового блока движка, а не заявление полного исполнения сайтов.
Число шаблонов осталось 27 426: новые правила добавлены к существующим ID.
Все 3 920 исходных существ повторно сопоставлены с 13 закреплёнными ресурсами.
SHA источника обязан совпасть; JavaScript не исполняется. Чужая проза в seed
не добавлена. Описания тестовых существ написаны для проекта.

## Что исполняется

| Программа | Количество |
| --- | ---: |
| Сопротивление магии | 469 существ |
| Легендарное сопротивление | 225 существ |
| Тактика стаи | 57 существ |
| Способности со спасброском | 211 |
| Из них перезаряжаемые | 153 |
| Из них с запасом X/день | 9 |
| Эффекты после попадания | 39 |
| Точные мультиатаки | 272 существ |
| Легендарные действия с проверенной атакой | 29 |
| Парирование | 72 существ |

Схема замкнута: только известные операции, типы, диапазоны и ссылки на атаки.
Отрицательные числа, неизвестные характеристики и отсутствующие ссылки
отклоняются. Спасброски используют шесть характеристик, исходные бонусы,
преимущество/помеху и правила владельца R01 при их включении.
Сложности 31–40 сохраняют штраф истощения и исходный итог броска.

Легендарное сопротивление расходуется после неудачи и не сбрасывается
полночью. Перезарядка проверяется d6 в начале хода, только после использования.
Запас X/день восстанавливается после завершённого длительного отдыха.
Отдых героя восстанавливает запас сопровождающих из последней группы,
если они живы и находятся в той же сцене; отдельного расписания отдыха
каждого вражеского NPC пока нет.

Парирование использует одну реакцию и не тратится на неизбежное попадание.
Легендарное действие выполняется в конце чужого хода, расходует указанный
бюджет и возвращает его в начале собственного. Тактика стаи проверяет
реального союзника, его HP/дееспособность и расстояние до цели.

Автоматически извлекаются только конечные простые варианты ослепления,
отравления, паралича и ошеломления. Поддержаны иммунитеты, повторные
спасброски и ограниченная длительность. Сложные переходы/несколько условий/
неоднозначные дополнительные эффекты остаются в неподдержанном списке.
Наличие служебного имени другого состояния в Python не означает его
полного извлечения и исполнения.

Конусы, линии и сферы считаются в целых футах в трёх измерениях.
Проверки границ обходятся без плавающей арифметики. Урон области бросается
один раз, спасброски и защита применяются отдельно к каждому существу.
Союзники внутри области также получают эффект. Комбинация базового урона
и эффекта после попадания делает один переход HP/счётчиков смерти.
Версия 3 ограничивает дистанцию, перемещение и вертикальный подъём.
Наземное существо не поднимается к летящей цели без способности полёта.

## Совместимость и фактические границы

Версии 1 и 2 не переключаются автоматически. В репозитории сохранён снимок,
созданный прежним кодом a7cc7e4, с SHA-256
b492f726c5132d86184cfd47e56ef6f5932f99e3d8f927b2c8109f566830b8b7.
Тест загружает его прежним replay-путём и сравнивает состояние/RNG.
Новые правила закрепляются в определении и не требуют глобальной БД при загрузке.
Миграция003 добавляет реестр схем программ, не меняя checksum001/002.

Позиции отсутствуют в старой модели сцены: для новой версии движок сохраняет
исходную расстановку с меткой scene-default/homebrew. Это не исходные координаты.
Неизвестные дистанции оружия также обозначены homebrew. Размеры тел, преграды,
полное укрытие, линия видимости, внезапность, провоцированные атаки, все виды
движения, точные границы состояния на каждом подходе инициативы и короткий отдых
ещё не образуют полную модель SRD. Концентрация, произвольные заклинания,
призывы, логова, мифические стадии и сложная регенерация остаются без обработчиков.
Часть стоимости ST/боеприпасов сохраняет существующую homebrew-модель игры.

Основная справочная сверка:
[Monsters / Limited Usage / Legendary Actions, Basic Rules 2014](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/monsters),
[Spellcasting / Areas of Effect](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/spellcasting).
Использованы факты о восстановлении применений, фазах хода и форме областей.
Это не переключение всей игры с правил владельца и SRD5.2.1 на редакцию2014.
