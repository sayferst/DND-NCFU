## Что намеренно не объявлено выполненным

Публичный Release0.4.0 и новый тег не созданы. Стабильность не объявлена.
Точный публичный tester Setup не предоставлен и не может подменяться developer
CI-установщиком. Поэтому его SHA256/тесты входа в реальный шлюз не выдуманы.
Новая сборка ради текстового оформления не запускается. Цепочка публикации
подготовлена как контролируемый чек-лист, без автоматического релиза feature-push.
Сохранён действующий сборщик и AppId, пользовательские данные не удаляются.
Источник старого upgrade-установщика всё ещё временный CI-артефакт — требуется
постоянный файл с совпадающим проверенным хэшем. Не сделана опасная замена на
произвольный опубликованный preview.

main/default branch, About/topics, branch protection и social preview не изменены.
Подключённые GitHub tools не предоставляют такие настройки; подготовлены точные
поля/действия Settings. Существующие ветки/PR/теги/релизы не удалены и не изменены.
На момент подготовки отчёта новая ветка/PR ещё не отправлены. Владелец разрешил
публикацию ветки и создание PR в feature/unified-rpg-automatic-gm без слияния.
По отдельному решению владельца собственный код пока остаётся без открытой лицензии.
Сторонние уведомления сохраняются.
