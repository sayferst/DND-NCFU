# Разработка

Python 3.12 и `.venv`; установка `pip install --require-hashes -r requirements-dev.lock`.
Запуск `python scripts/run_game.py`, проверки `python scripts/check.py` из окружения.
Отдельно: `python -m pytest`, `python -m ruff check .`, `python -m ruff format --check .`.
Используйте тестовые данные и loopback-серверы, не реальные API-ключи.

Новые правила и изменения состояния должны иметь независимые тесты инвариантов.
Не подменяйте математический исход текстом модели. При изменении схем сохраняйте
миграции и исходные bytes fixtures. `.gitattributes` защищает JSON от CRLF-конверсии.
Параметризованные тесты должны иметь короткие IDs, совместимые с Windows.

Настройки и ресурсы должны работать независимо от текущей рабочей папки и
оставлять данные вне каталога установленного приложения. Локальный пароль
разработчика открывает настройки GUI, но не даёт прав на серверную квоту.

Коммиты публикационной ветки описывают перенос конечного состояния из разработки,
а не имитируют историю первоначальной реализации. Исследовательские измерения
и личные отчёты не добавляются в эту ветку как тестовые результаты.
