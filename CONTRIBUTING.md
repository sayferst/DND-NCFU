# Участие в разработке

Сначала откройте Issue с воспроизведением ошибки или описанием игровой задачи.
Исходный код пока не имеет выбранной открытой лицензии: для передачи существенного
вклада согласуйте права с владельцем. Сторонние лицензии не меняются.

Используйте короткую ветку feature/*, fix/* или docs/* и Pull Request.
Опишите поведение, риски, тесты и влияние на сохранения. Для интерфейса приложите
настоящий снимок без персональных данных. Не включайте модели, ключи, сырые игровые
архивы, локальные настройки и игровые сохранения пользователя.

[Подготовка окружения и проверки](docs/development.md). Опубликованную историю,
теги и старые fixtures не переписывать. Публичный выпуск требует приёмки владельца.
