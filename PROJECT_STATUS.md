## Ожидается ручная проверка пользователя

Получить обновления в той же ветке, установить lockfile, выполнить `scripts/check.py`
и запустить `scripts/run_game.py` по README. Проверить «помочь», неизвестный ввод,
закрытие и повторное открытие. Отдельно повторить без интернета.
**Ручная проверка нового окна на Windows ещё не подтверждена.**

После приёмки 0B следующая отдельная задача — небольшой проверяемый игровой state
и одна механика по официальному SRD 5.2.1. Пока не переходить к полному бою,
импорту справочника или интеграции LLM.

## Возобновление агентом

Прочитать AGENTS, мастер, статус, DECISIONS/RESEARCH_LOG/TEST_PLAN. Проверить git status,
использовать существующий checkout и `.venv`. Не создавать worktree без просьбы.
Облачные install_script/start_skill должны соответствовать этапу 0B; процессы не
сохраняются между задачами. Публикация и восстановление снимка требуют отдельной проверки.
После каждого шага сохранять реальные результаты и остановиться для проверки пользователя.
