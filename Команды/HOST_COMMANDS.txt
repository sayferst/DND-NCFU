DND-NCFU — команды владельца
Папка: D:\Projects\DND-NCFU\Команды

ЛИЧНАЯ ПРОВЕРКА ИГРЫ БЕЗ ХОСТА

BUILD_EXE.bat
  Проверяет обновления GitHub, обновляет исходники и собирает личный EXE.
  Хост, ngrok, логин/пароль и Inno Setup для этого не нужны.
  Ключ читается из локального сохранённого ключа admin.
  При запуске автоматически включены профиль admin, Мастер и Художник.
  Результат: dist\Owner-НОМЕР\DND-NCFU.exe. Нужна вся папка Owner.
  Сборка привязана к ПК и пользователю Windows, под которым её собрали.
  Перед сборкой закройте игру. BAT собирает новую версию, а не запускает старую.
  После успешной сборки откроется dist — зайдите в новую папку Owner.

ОБЩИЙ УСТАНОВЩИК ДЛЯ ИГРОКОВ

BUILD_SETUP.bat
  Проверяет обновления и создаёт один Setup с входом admin/tester.
  Сначала запустите START_HOST.bat и дождитесь готовности.
  Результат: dist\Release\setup.exe. Передавайте этот файл игроку.
  Пароли и API-ключи в Setup не входят. Хост должен работать во время игры.
  Установка новой версии у игрока выполняется вручную, его локальные файлы
  сами не обновляются после вашей пересборки.

КЛЮЧИ И УЧЁТНЫЕ ЗАПИСИ

CHANGE_ADMIN_API.bat
  Запрашивает и сохраняет API-ключ admin в Windows DPAPI.
  Этот ключ используют admin в общем Setup и ваш личный EXE.
  Пароли/расходы не меняет. После смены перезапустите игру и работающий хост.

CHANGE_TESTER_API.bat
  Запрашивает и сохраняет только API-ключ tester в Windows DPAPI.
  Личный EXE и ключ admin не меняет. После смены перезапустите хост.

SETUP_ACCOUNTS.bat
  Задаёт/меняет пароли admin и tester на хосте.
  Сначала сохраните оба ключа двумя BAT выше и остановите хост.
  Срок допуска — 30 дней от первоначальной настройки.
  Повторная настройка пароля не сбрасывает расходы и срок.
  Для личного EXE этот шаг не нужен: он запускается без входа.

ХОСТ И ТУННЕЛЬ

START_HOST.bat
  Запускает хост с сохранёнными настройками.
  Дождитесь «Устойчивость подтверждена тремя HTTPS-проверками».
  Оставьте окно и ПК включёнными, пока игрок использует общий Setup.
  Остановка: Ctrl+C, затем Y и Enter, если Windows спросит подтверждение.
  Для вашего личного EXE этот BAT не требуется.

UPDATE_NGROK.bat
  Обновляет отдельную копию ngrok через штатный updater.
  Перед обновлением остановите хост; после успеха START_HOST.bat.
  Ключи, пароли и расходы сохраняются; игра и Setup не пересобираются.
  Запускайте при сообщении об устаревшем ngrok, не перед каждой игрой.

ПОРЯДОК ДЕЙСТВИЙ

Только проверить игру у себя:
  CHANGE_ADMIN_API (один раз) -> BUILD_EXE -> новый EXE в dist\Owner-НОМЕР.

Впервые подготовить доступ игроку:
  CHANGE_ADMIN_API -> CHANGE_TESTER_API -> SETUP_ACCOUNTS ->
  START_HOST -> дождаться готовности -> BUILD_SETUP -> передать setup.exe.

Обычный следующий запуск игрока:
  Только START_HOST. Пересобирать Setup не нужно.

После изменения кода:
  Для себя BUILD_EXE; для игрока BUILD_SETUP и передать новый setup.exe.

ОБНОВЛЕНИЕ И РАСХОДЫ

Оба сборщика проверяют GitHub перед сборкой. Без сети сборка останавливается.
Если новые коммиты мешает получить работающий хост или локальные правки,
сборка останавливается с объяснением. Файлы и ваши изменения не удаляются.
Перед получением обновлений остановите хост. Дополнительные локальные правки
включаются в сборку, когда все коммиты GitHub уже получены.

В общем Setup сервер ограничивает tester до 100 рублей и admin до 500 рублей
на допуск, плюс общий бюджет хоста. Оба вида генерации используют бюджет роли.
Личный EXE обращается прямо к RouterAI, его запросы не учитываются сервером.
Поэтому лимит admin-ключа задавайте также в кабинете RouterAI.
Без хоста не означает без интернета: RouterAI и баланс ключа необходимы.

Все BAT должны оставаться в папке «Команды» внутри проекта.
Личный EXE не публикуйте как общий Setup. На другом ПК или другом пользователе
Windows привязка и расшифровка ключа не пройдут. Это защита обычного запуска
и копирования, а не абсолютная защита от модификации программы.
После переустановки Windows личную сборку нужно создать заново.

BUILD_TESTER_SETUP, UPDATE_AND_BUILD_SETUP, CHANGE_HOST_KEY удалены
как дублирующие команды. Используйте семь BAT, перечисленных выше.
